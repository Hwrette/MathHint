## 현재 승인 상태

사용자가 직전의 소단원 군집·정수 반올림·세 조건 Gemini 실험 요청을 명시적으로 취소했다. 새 최종 요구사항은 아직 제공되지 않았다. 새 지시를 받기 전에는 그 실험을 재개하거나 미완료 최종 작업으로 간주하지 않는다.

이 문서가 승인된 새 요구사항과 검증 가능한 완료 기준으로 갱신되기 전까지 자동화는 상태 확인과 진행 기록 저장만 수행한다. 승인 상태를 자동으로 true로 바꾸지 않는다.

## 승인된 자동 진행 규칙

1. 매 실행에서 이 문서와 `docs/WORK_PROGRESS.md`를 읽고 실제 저장소 경로·브랜치·HEAD·작업 트리·기존 결과를 확인한다.
2. 승인된 최종 요구사항이 있으면 완료 근거가 없는 항목부터 진행한다. 대화의 옛 요청으로 현재 명세를 대체하지 않는다.
3. 긴 작업 전후, 각 검증 단계 후에 진행 상태·산출물 경로·해시·다음 행동을 저장한다. 코드 변경과 결과를 검토 가능한 작은 체크포인트로 Git에 남긴다. 세션이 강제로 종료되기 직전의 미저장 상태까지 보장할 수는 없으므로 중간 저장을 자주 한다.
4. 완료된 실험은 데이터·설정·산출물 해시가 같은지 확인해 재사용한다. Gemini는 문항 ID·조건·입력 해시·모델·생성 설정이 같은 성공 응답을 재요청하지 않는다. 호출 전 intent와 호출 후 응답·사용량을 즉시 저장한다. 중단 시 성공 여부가 불명확한 요청은 확인 없이 자동 반복하지 않는다.
5. 미완료이면 기존 자동화의 다음 예약을 확인하고 기록한다. 중복 자동화를 새로 만들지 않는다. 실제 사용량 초기화 시각을 확인할 수 있으면 근거와 시각을 기록하고 그 이후로 조정한다. 조회할 수 없으면 시간 기반 예약을 유지한다.
6. 모든 승인 요구사항의 완료 근거와 검사 결과가 있고 게시할 결과까지 확인되면, 이 자동화를 `is_enabled=false`로 중지하고 도구 응답으로 중지를 검증한다.
7. 도구 연결·재인증·승인이 필요하면 그 지점에서 대기하고 원인을 기록한다. 실행·예약·게시·자동화 중지가 확인되지 않은 상태를 성공했다고 쓰지 않는다.

## 사용자가 미리 허용한 작업 범위

승인된 MathHint 최종 명세를 수행하는 데 필요한 프로젝트 파일 수정, 검사, 실험 결과 저장, 정상적인 Git 커밋·푸시, 필요한 Gemini API 이용을 진행한다. 확정되지 않은 실험 조건이나 취소된 요구사항에 대한 API 호출은 허용된 것으로 해석하지 않는다.

이 사전 의사는 플랫폼의 보안 정책·개별 승인·재인증 요구를 무시하거나 사용량 한도를 변경하는 권한이 아니다. 비밀키는 `.env` 또는 환경변수로 읽고 코드·진행 문서·로그에 기록하지 않는다. 강제 푸시나 관련 없는 작업 덮어쓰기는 하지 않는다.

## 새 최종 지시를 받은 뒤 채울 항목

- 최종 산출물과 작업 범위
- 유지할 데이터·분할·모델·실험 조건
- 기존 결과의 재사용 기준과 필요한 신규 API 조건
- 각 요구사항의 검증 방법과 완료 기준
- 최종 결과 게시 위치

현재는 위 항목이 확정되지 않았으므로 실행하지 않는다.
