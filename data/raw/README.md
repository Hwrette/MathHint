# 원본 자료: HML과 PDF

HML은 기존 전처리에 사용한 자료이며, PDF는 사용자가 제공한 한글 자료의 PDF 버전이다. 발표용 PPT에 문제 이미지를 넣을 때 아래 PDF를 열어 필요한 부분을 캡처할 수 있다.

PDF 합계: **6개 · 160쪽**.

PDF 내용은 변환·압축·편집하지 않고 첨부 파일과 동일한 바이트로 보존했다. 파일명만 기존 HML과 같은 이름으로 맞췄다. 파일명 대응은 같은 자료군을 뜻하며, PDF의 모든 문항이 현재 확정된 265문항과 일대일로 일치한다고 검증한 것은 아니다.

연구 문항 ID는 삭제 전 원래 번호를 포함한다. PDF의 쪽수·현재 문항 번호와 연결할 때는 [문항 메타데이터](../processed/metadata.json)와 [출처·번호 대조 자료](../provenance/)를 함께 확인한다.

기존 전처리 입력은 `*.hml`이며 이 PDF를 추가해도 기존 어휘·벡터·분할·모델·실험 결과는 바뀌지 않는다.
