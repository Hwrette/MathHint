[문제]
함수
$f \left( x \right) = \left\{\begin{array}{lll}x^{2} + a &  & \left( x < 3 \right) \\ x + 2 a &  & \left( x \ge 3 \right)\end{array}\right.$
이 실수 전체의 집합에서 연속일 때, 상수 $a$의 값은?
① $6$		② $7$		③ $8$
④ $9$		⑤ $10$

[원본 정답·해설]
[정답] ①

[해설]
$\lim_{x \rightarrow 3 -} f \left( x \right) = \lim_{x \rightarrow 3 -} \left( x^{2} + a \right) = 9 + a$
$\lim_{x \rightarrow 3 +} f \left( x \right) = \lim_{x \rightarrow 3 +} \left( x + 2 a \right) = 3 + 2 a$
$f \left( 3 \right) = 3 + 2 a$
함수 $f \left( x \right)$가 $x = 3$에서 연속이므로
$\lim_{x \rightarrow 3 -} f \left( x \right) = \lim_{x \rightarrow 3 +} f \left( x \right) = f \left( 3 \right)$
$9 + a = 3 + 2 a$, $a = 6$
