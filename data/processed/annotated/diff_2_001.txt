[문제]
함수 $f \left( x \right)$가 $x > \frac{1}{2}$인 모든 실수 $x$에 대하여
$\frac{3}{2 x + 1} < f \left( x \right) < \frac{3}{2 x - 1}$
을 만족시킬 때, $\lim_{x \rightarrow \infty} x f \left( x \right)$의 값은?
① $\frac{3}{2}$		② $\mathrm{2}$		③ $\frac{5}{2}$
④ $\mathrm{3}$		⑤ $\frac{7}{2}$

[원본 정답·해설]
[정답] ①

[해설]
$x > \frac{1}{2}$인 모든 실수 $x$에 대하여
$\frac{3}{2 x + 1} < f \left( x \right) < \frac{3}{2 x - 1}$이므로
$\frac{3 x}{2 x + 1} < x f \left( x \right) < \frac{3 x}{2 x - 1}$
이때 $\lim_{x \rightarrow \infty} \frac{3 x}{2 x + 1} = \lim_{x \rightarrow \infty} \frac{3 x}{2 x - 1} = \frac{3}{2}$이므로
함수의 극한의 대소 관계에 의하여 $\lim_{x \rightarrow \infty} x f \left( x \right) = \frac{3}{2}$
