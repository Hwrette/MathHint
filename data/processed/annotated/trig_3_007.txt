[문제]
함수 $f (x) = a \sin b x + c (a > 0 , b > 0)$의 최댓값은 $\mathrm{4}$, 최솟값은 $- 2$이다. 모든 실수 $x$에 대하여 $f (x + p) = f (x)$를 만족시키는 양수 $p$의 최솟값이 $\pi$일 때, $a b c$의 값은?
(단, $a$, $b$, $c$는 상수이다.)
① $\mathrm{6}$		② $\mathrm{8}$		③ $\mathrm{10}$
④ $\mathrm{12}$		⑤ $\mathrm{14}$

[원본 정답·해설]
[정답] ①

[해설]
최대, 최소에서 $a + c = 4$, $- a + c = - 2$이므로 $a = 3$, $c = 1$이고 주기에서 $b = 2$이다.
$\therefore \quad a b c = 6$
