[문제]
다항함수 $f (x)$에 대하여 함수 $g (x)$를
$g \left( x \right) = \left( x^{2} - 2 x \right) f \left( x \right)$
라 하자. $g' (0) + g' (2) = 16$일 때, $f (2) - f (0)$의 값은?
① $\mathrm{6}$		② $\mathrm{8}$		③ $\mathrm{10}$
④ $\mathrm{12}$		⑤ $\mathrm{14}$

[원본 정답·해설]
[정답] ②

[해설]
$g \left( x \right) = \left( x^{2} - 2 x \right) f \left( x \right)$의 양변을 $x$에 대하여 미분하면
$g' \left( x \right) = \left( 2 x - 2 \right) f \left( x \right) + \left( x^{2} - 2 x \right) f' \left( x \right)$
$g' \left( 0 \right) = - 2 f \left( 0 \right)$, $g' \left( 2 \right) = 2 f \left( 2 \right)$
$g' \left( 0 \right) + g' \left( 2 \right) = 2 \left\{ - f \left( 0 \right) + f \left( 2 \right) \right\} = 16$
따라서 $f \left( 2 \right) - f \left( 0 \right) = 8$
