[정답] ②

[해설]
$\lim_{x \rightarrow 0} \frac{f \left( x \right)}{x} = 1$에서 $x \rightarrow 0$이면 (분모)$\rightarrow 0$이고 극한값이 존재하므로 (분자)$\rightarrow 0$이어야 한다.
따라서 $f \left( 0 \right) = 0$
같은 방법으로 $\lim_{x \rightarrow 1} \frac{f \left( x \right)}{x} - 1 = 1$에서 $f \left( 1 \right) = 0$
따라서 삼차함수 $f \left( x \right)$를 $f \left( x \right) = x \left( x - 1 \right) \left( a x + b \right)$ ($a , b$는 상수)로 놓을 수 있다.
$\lim_{x \rightarrow 0} \frac{f \left( x \right)}{x} = \lim_{x \rightarrow 0} {\left( x - 1 \right) \left( a x + b \right)} = - b$
이므로 $b = - 1$
$\lim_{x \rightarrow 1} \frac{f \left( x \right)}{x} - 1 = \lim_{x \rightarrow 1} {x \left( a x + b \right)} = a + b$
이므로 $a + b = 1$
따라서 $a = 2$이므로
$f \left( x \right) = x \left( x - 1 \right) \left( 2 x - 1 \right)$
따라서 $f \left( 2 \right) = 2 \times 1 \times 3 = 6$

[다른 풀이]
$\lim_{x \rightarrow 0} \frac{f \left( x \right)}{x} = 1$에서 $x \rightarrow 0$이면 (분모)$\rightarrow 0$이고 극한값이 존재하므로 (분자)$\rightarrow 0$이어야 한다.
따라서 $f \left( 0 \right) = 0$
이때 $\lim_{x \rightarrow 0} \frac{f \left( x \right)}{x} = f' \left( 0 \right) = 1$
같은 방법으로 $\lim_{x \rightarrow 1} \frac{f \left( x \right)}{x} - 1 = 1$에서 $f \left( 1 \right) = 0 , f' \left( 1 \right) = 1$
함수 $f \left( x \right)$는 삼차함수이고 $f' \left( 0 \right) = f' \left( 1 \right) = 1$이므로
$f' \left( x \right) = a x \left( x - 1 \right) + 1$
즉 $f' \left( x \right) = a x^{2} - a x + 1$이라 놓으면
$f \left( x \right) = \frac{a}{3} x^{3} - \frac{a}{2} x^{2} + x + C$ ($C$는 적분상수)
$f \left( 0 \right) = 0$에서 $C = 0$
$f \left( 1 \right) = 0$에서 $\frac{a}{3} - \frac{a}{2} + 1 = 0$
$a = 6$이므로 $f \left( x \right) = 2 x^{3} - 3 x^{2} + x$
$\therefore$$f \left( 2 \right) = 6$
