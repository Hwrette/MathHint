주어진 두 극한 조건을 이용하여 다항함수 $f(x)$를 구합니다.

1. 첫 번째 조건: $\lim_{x \rightarrow \infty} \frac{f(x)}{2x^2} = 1$
이 식으로부터 $f(x)$는 이차항의 계수가 $2$인 이차함수임을 알 수 있습니다. 따라서 $f(x) = 2x^2 + ax + b$라고 둘 수 있습니다.

2. 두 번째 조건: $\lim_{x \rightarrow 1} \frac{f(x) - 3}{(x - 1)(x - 2)} = 4$
$x \rightarrow 1$일 때 분모가 $0$으로 가므로, 극한값이 존재하려면 분자도 $0$이어야 합니다.
즉, $f(1) - 3 = 0$에서 $f(1) = 3$입니다.
$f(1) = 2(1)^2 + a(1) + b = 2 + a + b = 3$이므로, $a + b = 1$ 즉, $b = 1 - a$입니다.

이제 $f(x) = 2x^2 + ax + 1 - a$를 극한식에 대입합니다.
$f(x) - 3 = 2x^2 + ax + 1 - a - 3 = 2x^2 + ax - a - 2$
$= 2(x^2 - 1) + a(x - 1) = 2(x - 1)(x + 1) + a(x - 1)$
$= (x - 1)(2x + 2 + a)$

이를 극한식에 대입하면:
$\lim_{x \rightarrow 1} \frac{(x - 1)(2x + 2 + a)}{(x - 1)(x - 2)} = \lim_{x \rightarrow 1} \frac{2x + 2 + a}{x - 2} = 4$
$\frac{2(1) + 2 + a}{1 - 2} = \frac{4 + a}{-1} = 4$
$4 + a = -4$ 이므로 $a = -8$입니다.

$b = 1 - a = 1 - (-8) = 9$이므로,
$f(x) = 2x^2 - 8x + 9$입니다.

3. $f(4)$의 값 구하기:
$f(4) = 2(4)^2 - 8(4) + 9$
$f(4) = 2(16) - 32 + 9$
$f(4) = 32 - 32 + 9 = 9$

최종정답: 9
