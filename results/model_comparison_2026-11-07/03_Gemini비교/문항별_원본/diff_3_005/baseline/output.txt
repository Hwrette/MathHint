주어진 두 극한 조건을 이용하여 다항함수 $f(x)$를 구합니다.

**1. 첫 번째 조건 분석:**
$\lim_{x \rightarrow \infty} \frac{f(x)}{2x^2} = 1$
이 식에서 $x \rightarrow \infty$일 때 $f(x)$는 $2x^2$과 차수가 같고 최고차항의 계수가 2임을 알 수 있습니다. 따라서 $f(x)$는 이차함수이며, 다음과 같이 설정할 수 있습니다.
$f(x) = 2x^2 + ax + b$

**2. 두 번째 조건 분석:**
$\lim_{x \rightarrow 1} \frac{f(x) - 3}{(x - 1)(x - 2)} = 4$
분모가 $x \rightarrow 1$일 때 0으로 가므로, 극한값이 존재하려면 분자도 0이어야 합니다.
$f(1) - 3 = 0 \implies f(1) = 3$
$f(1) = 2(1)^2 + a(1) + b = 3 \implies a + b = 1$  --- (식 1)

이제 로피탈의 정리를 사용하거나 식을 대입하여 극한값을 계산합니다.
$\lim_{x \rightarrow 1} \frac{f'(x)}{(x-2) + (x-1)} = \lim_{x \rightarrow 1} \frac{4x + a}{2x - 3} = 4$
$x = 1$을 대입하면:
$\frac{4(1) + a}{2(1) - 3} = 4$
$\frac{4 + a}{-1} = 4$
$4 + a = -4 \implies a = -8$

**3. 상수 $b$ 구하기:**
(식 1)에 $a = -8$을 대입하면:
$-8 + b = 1 \implies b = 9$

따라서 $f(x) = 2x^2 - 8x + 9$입니다.

**4. $f(4)$ 구하기:**
$f(4) = 2(4)^2 - 8(4) + 9$
$f(4) = 2(16) - 32 + 9$
$f(4) = 32 - 32 + 9 = 9$

최종정답: 9
