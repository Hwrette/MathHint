함수 $f(x) = 2a \cos x + a$에서 $a > 0$이므로, 주어진 범위 $\frac{\pi}{3} \le x \le \frac{4}{3} \pi$에서 $\cos x$의 값의 범위를 구합니다.

1. **$\cos x$의 범위 구하기:**
   $x$의 범위가 $\frac{\pi}{3} \le x \le \frac{4}{3} \pi$일 때, 코사인 함수의 그래프를 고려하면:
   - $x = \frac{\pi}{3}$일 때, $\cos \frac{\pi}{3} = \frac{1}{2}$
   - $x = \pi$일 때, $\cos \pi = -1$
   - $x = \frac{4}{3} \pi$일 때, $\cos \frac{4}{3} \pi = -\frac{1}{2}$
   따라서, $-1 \le \cos x \le \frac{1}{2}$입니다.

2. **$f(x)$의 최댓값과 최솟값 구하기:**
   $f(x) = 2a \cos x + a$이고 $a > 0$이므로,
   - 최댓값 $M = f(\frac{\pi}{3}) = 2a(\frac{1}{2}) + a = a + a = 2a$
   - 최솟값 $m = f(\pi) = 2a(-1) + a = -2a + a = -a$

3. **$a$의 값 구하기:**
   최댓값과 최솟값의 곱이 $-8$이라고 하였으므로,
   $M \times m = (2a) \times (-a) = -2a^2$
   $-2a^2 = -8$
   $a^2 = 4$
   $a > 0$이므로 $a = 2$입니다.
