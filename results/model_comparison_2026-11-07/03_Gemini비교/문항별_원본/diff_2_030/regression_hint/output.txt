삼차함수 $f(x) = ax^3 + bx + a$에 대하여, $f(x)$가 $x=1$에서 극소이므로 $f'(1) = 0$이어야 합니다.

먼저 $f(x)$를 미분하면
$f'(x) = 3ax^2 + b$
입니다. $f'(1) = 3a + b = 0$이므로 $b = -3a$입니다.

이를 $f(x)$에 대입하면
$f(x) = ax^3 - 3ax + a$
가 됩니다. $x=1$에서 극솟값이 $-2$이므로
$f(1) = a(1)^3 - 3a(1) + a = -2$
$a - 3a + a = -2$
$-a = -2$
따라서 $a = 2$이고, $b = -3(2) = -6$입니다.

이제 함수는 $f(x) = 2x^3 - 6x + 2$가 됩니다.
극값을 찾기 위해 $f'(x)$를 구하면
$f'(x) = 6x^2 - 6 = 6(x^2 - 1) = 6(x-1)(x+1)$
$f'(x) = 0$이 되는 $x$는 $x=1$ 또는 $x=-1$입니다.

$x=1$에서 극솟값을 가지므로, $x=-1$에서 극댓값을 가집니다.
극댓값은 $f(-1)$이므로
$f(-1) = 2(-1)^3 - 6(-1) + 2$
$f(-1) = -2 + 6 + 2 = 6$

따라서 함수 $f(x)$의 극댓값은 $6$입니다.
