삼차함수 $f(x) = ax^3 + bx + a$가 $x=1$에서 극소이므로, 미분계수 $f'(1) = 0$이어야 합니다.

1. **도함수 구하기:**
   $f'(x) = 3ax^2 + b$

2. **$f'(1) = 0$ 조건 이용:**
   $f'(1) = 3a(1)^2 + b = 3a + b = 0$
   따라서 $b = -3a$입니다.

3. **$f(x)$ 식에 대입:**
   $f(x) = ax^3 - 3ax + a$
   $f'(x) = 3ax^2 - 3a = 3a(x^2 - 1) = 3a(x-1)(x+1)$
   $f'(x) = 0$이 되는 $x$는 $x=1$ 또는 $x=-1$입니다.

4. **극솟값 조건 이용:**
   $x=1$에서 극솟값이 $-2$이므로, $f(1) = -2$입니다.
   $f(1) = a(1)^3 - 3a(1) + a = a - 3a + a = -a$
   $-a = -2$ 이므로 $a = 2$입니다.
   $a=2$이면 $b = -3(2) = -6$입니다.

5. **극댓값 구하기:**
   $f(x) = 2x^3 - 6x + 2$
   극댓값은 $x=-1$에서 발생합니다.
   $f(-1) = 2(-1)^3 - 6(-1) + 2$
   $f(-1) = -2 + 6 + 2 = 6$

따라서 함수 $f(x)$의 극댓값은 6입니다.

최종정답: 6
