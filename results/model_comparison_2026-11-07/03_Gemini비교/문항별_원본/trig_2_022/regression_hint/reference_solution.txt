[정답] ③

[해설]
$2 \cos^{2} x - \sin \left( \pi + x \right) - 2$$= 2 \left( 1 - \sin^{2} x \right) + \sin x - 2$
$= - 2 \sin^{2} x + \sin x$
$= - \sin x \left( 2 \sin x - 1 \right)$$= 0$
$\sin x = 0$또는 $\sin x = \frac{1}{2}$
$0 < x < 2 \pi$이므로
$\sin x = 0$에서 $x = \pi$
$\sin x = \frac{1}{2}$에서 $x = \frac{\pi}{6}$또는 $x = \frac{5}{6} \pi$
따라서 모든 해의 합은 $2 \pi$이다.
