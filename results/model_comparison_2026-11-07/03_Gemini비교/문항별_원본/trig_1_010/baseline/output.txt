이차방정식 $5x^2 + x + k = 0$의 두 실근이 $\sin t, \cos t$이므로, 근과 계수의 관계에 의해 다음이 성립합니다.

1) $\sin t + \cos t = -\frac{1}{5}$
2) $\sin t \cos t = \frac{k}{5}$

첫 번째 식의 양변을 제곱하면:
$(\sin t + \cos t)^2 = \left(-\frac{1}{5}\right)^2$
$\sin^2 t + \cos^2 t + 2\sin t \cos t = \frac{1}{25}$

$\sin^2 t + \cos^2 t = 1$이므로:
$1 + 2\left(\frac{k}{5}\right) = \frac{1}{25}$
$1 + \frac{2k}{5} = \frac{1}{25}$
$\frac{2k}{5} = \frac{1}{25} - 1 = -\frac{24}{25}$
$k = -\frac{24}{25} \times \frac{5}{2} = -\frac{12}{5}$

이제 $\sin t \cos t = \frac{k}{5} = \frac{-12/5}{5} = -\frac{12}{25}$입니다.
$\sin t$와 $\cos t$는 $x^2 - (\sin t + \cos t)x + \sin t \cos t = 0$의 근이므로,
$x^2 + \frac{1}{5}x - \frac{12}{25} = 0$
$25x^2 + 5x - 12 = 0$
$(5x - 3)(5x + 4) = 0$
따라서 $x = \frac{3}{5}$ 또는 $x = -\frac{4}{5}$입니다.

$\frac{\pi}{2} < t < \pi$ 범위에서 $\sin t > 0$이고 $\cos t < 0$이므로,
$\sin t = \frac{3}{5}$, $\cos t = -\frac{4}{5}$가 됩니다.

이때 $\tan t = \frac{\sin t}{\cos t} = \frac{3/5}{-4/5} = -\frac{3}{4}$입니다.

구하고자 하는 값은 $k \times \tan t$이므로:
$k \times \tan t = \left(-\frac{12}{5}\right) \times \left(-\frac{3}{4}\right) = \frac{36}{20} = \frac{9}{5}$
