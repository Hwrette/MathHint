주어진 조건들을 정리하면 다음과 같습니다.

1. 곡선 $y = f(x)$ 위의 점 $(3, 2)$에서의 접선의 기울기가 4이므로,
   $f(3) = 2$
   $f'(3) = 4$

2. 함수 $g(x) = (x + 2)f(x)$를 미분하면 곱의 미분법에 의해 다음과 같습니다.
   $g'(x) = (x + 2)' f(x) + (x + 2) f'(x)$
   $g'(x) = 1 \cdot f(x) + (x + 2) f'(x)$
   $g'(x) = f(x) + (x + 2) f'(x)$

3. $g'(3)$의 값을 구하기 위해 $x = 3$을 대입합니다.
   $g'(3) = f(3) + (3 + 2) f'(3)$
   $g'(3) = f(3) + 5 f'(3)$

4. 위에서 구한 값 $f(3) = 2$와 $f'(3) = 4$를 대입합니다.
   $g'(3) = 2 + 5 \times 4$
   $g'(3) = 2 + 20$
   $g'(3) = 22$

최종정답: 22
