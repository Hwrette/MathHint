함수 $f(x) = a \cos bx$ ($a > 0, b > 0$)의 주기가 $6\pi$이므로,
$$\frac{2\pi}{b} = 6\pi$$
이를 풀면 $b = \frac{2\pi}{6\pi} = \frac{1}{3}$입니다.

이제 함수는 $f(x) = a \cos \left( \frac{1}{3}x \right)$가 됩니다.
닫힌구간 $[\pi, 4\pi]$에서 $x$의 범위를 구하면,
$$\pi \le x \le 4\pi \implies \frac{\pi}{3} \le \frac{x}{3} \le \frac{4\pi}{3}$$
이 범위에서 $\cos \left( \frac{x}{3} \right)$의 값의 범위를 구합니다.
$\cos \left( \frac{\pi}{3} \right) = \frac{1}{2}$이고, $\cos \left( \frac{4\pi}{3} \right) = -\frac{1}{2}$입니다.
또한, 구간 내에 $\frac{\pi}{2}$가 포함되어 있으므로 $\cos \left( \frac{x}{3} \right)$의 최댓값은 $\cos \left( \frac{\pi}{3} \right) = \frac{1}{2}$이고, 최솟값은 $\cos \left( \frac{4\pi}{3} \right) = -\frac{1}{2}$입니다.

따라서 $f(x) = a \cos \left( \frac{x}{3} \right)$의 최댓값은 $a \times \frac{1}{2}$이 됩니다.
문제에서 최댓값이 $1$이라고 하였으므로,
$$\frac{1}{2}a = 1 \implies a = 2$$

구하는 값은 $a + b$이므로,
$$a + b = 2 + \frac{1}{3} = \frac{6}{3} + \frac{1}{3} = \frac{7}{3}$$
