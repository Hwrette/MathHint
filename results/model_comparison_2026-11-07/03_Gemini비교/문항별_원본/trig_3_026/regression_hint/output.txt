주어진 방정식 $\cos^{2} x - \sin x = 1$을 $0 < x < 2\pi$ 범위에서 풀어보겠습니다.

1. **삼각함수의 기본 성질 이용:**
   $\cos^{2} x = 1 - \sin^{2} x$이므로, 이를 방정식에 대입합니다.
   $(1 - \sin^{2} x) - \sin x = 1$

2. **방정식 정리:**
   양변에서 1을 빼고 정리하면 다음과 같습니다.
   $-\sin^{2} x - \sin x = 0$
   $\sin^{2} x + \sin x = 0$
   $\sin x (\sin x + 1) = 0$

3. **근 구하기:**
   따라서 $\sin x = 0$ 또는 $\sin x = -1$입니다.
   - $0 < x < 2\pi$ 범위에서 $\sin x = 0$을 만족하는 $x$는 $x = \pi$입니다.
   - $0 < x < 2\pi$ 범위에서 $\sin x = -1$을 만족하는 $x$는 $x = \frac{3}{2}\pi$입니다.

4. **근의 합 계산:**
   모든 실근의 합은 $\pi + \frac{3}{2}\pi = \frac{5}{2}\pi$입니다.
   문제에서 합이 $\frac{q}{p}\pi$라고 하였으므로, $p=2, q=5$입니다.
   ($p, q$는 서로소인 자연수 조건을 만족합니다.)

5. **최종 결과:**
   $p + q = 2 + 5 = 7$

최종정답: 7
