주어진 방정식 $\left| \cos x + \frac{1}{4} \right| = k$ ($0 \le x < 2\pi$)가 서로 다른 3개의 실근을 갖기 위한 조건을 구합니다.

1. **함수 $f(x) = \cos x + \frac{1}{4}$의 그래프 분석:**
   $0 \le x < 2\pi$에서 $\cos x$의 값은 $-1$에서 $1$ 사이의 값을 가집니다.
   따라서 $f(x) = \cos x + \frac{1}{4}$의 값의 범위는 $-\frac{3}{4} \le f(x) \le \frac{5}{4}$입니다.

2. **절댓값 함수 $g(x) = |f(x)| = \left| \cos x + \frac{1}{4} \right|$의 그래프 분석:**
   - $f(x) = 0$이 되는 지점은 $\cos x = -\frac{1}{4}$일 때입니다. 이 방정식은 $0 \le x < 2\pi$ 범위에서 서로 다른 두 실근을 갖습니다.
   - $f(x)$의 최솟값은 $-\frac{3}{4}$이므로, $|f(x)|$의 최솟값은 $0$입니다.
   - $f(x)$의 최댓값은 $\frac{5}{4}$이므로, $|f(x)|$의 최댓값은 $\frac{5}{4}$입니다.
   - $f(x)$가 $-\frac{3}{4}$일 때 $|f(x)| = \frac{3}{4}$이 됩니다.

3. **실근의 개수와 $k$의 관계:**
   - $k > \frac{5}{4}$이면 실근은 0개입니다.
   - $k = \frac{5}{4}$이면 $\cos x + \frac{1}{4} = \frac{5}{4}$ 또는 $-\frac{5}{4}$인데, $\cos x = 1$ (1개) 또는 $\cos x = -\frac{3}{2}$ (0개)이므로 실근은 1개입니다.
   - $\frac{3}{4} < k < \frac{5}{4}$이면 실근은 2개입니다.
   - **$k = \frac{3}{4}$**이면:
     $\left| \cos x + \frac{1}{4} \right| = \frac{3}{4}$
     $\cos x + \frac{1}{4} = \frac{3}{4} \implies \cos x = \frac{1}{2}$ (2개의 실근: $x = \frac{\pi}{3}, \frac{5\pi}{3}$)
     $\cos x + \frac{1}{4} = -\frac{3}{4} \implies \cos x = -1$ (1개의 실근: $x = \pi$)
     따라서 총 **3개의 실근**을 갖습니다.
   - $0 < k < \frac{3}{4}$이면 실근은 4개입니다.
   - $k = 0$이면 실근은 2개입니다.

4. **결론:**
   서로 다른 3개의 실근을 갖게 하는 $k$의 값은 $\alpha = \frac{3}{4}$입니다.
   따라서 $40\alpha = 40 \times \frac{3}{4} = 30$입니다.
