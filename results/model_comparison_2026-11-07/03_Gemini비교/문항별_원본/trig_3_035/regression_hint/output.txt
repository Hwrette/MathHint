주어진 방정식 $\left| \cos x + \frac{1}{4} \right| = k$가 $0 \le x < 2\pi$ 범위에서 서로 다른 3개의 실근을 갖기 위한 조건을 구합니다.

먼저 $f(x) = \cos x + \frac{1}{4}$라 하면, $0 \le x < 2\pi$에서 $\cos x$의 값은 $-1$에서 $1$까지 변하므로 $f(x)$의 값의 범위는 다음과 같습니다.
$-1 + \frac{1}{4} \le \cos x + \frac{1}{4} \le 1 + \frac{1}{4}$
$-\frac{3}{4} \le f(x) \le \frac{5}{4}$

이제 $y = |f(x)|$의 그래프를 생각합니다. $f(x)$가 $0$이 되는 지점은 $\cos x = -\frac{1}{4}$일 때이며, 이 방정식은 $0 \le x < 2\pi$에서 서로 다른 2개의 실근을 갖습니다.

$y = |f(x)|$의 그래프를 그려보면:
1. $f(x) = 0$인 지점(2곳)에서 $y=0$이 됩니다.
2. $f(x)$의 최솟값은 $-\frac{3}{4}$이므로, $|f(x)|$의 최댓값은 $|-\frac{3}{4}| = \frac{3}{4}$이 됩니다.
3. $f(x)$의 최댓값은 $\frac{5}{4}$이므로, $|f(x)|$의 최댓값은 $\frac{5}{4}$가 됩니다.

방정식 $|f(x)| = k$가 서로 다른 3개의 실근을 가지려면, 그래프의 극댓값이나 경계값에서 교점이 3개가 되어야 합니다.
- $k = \frac{3}{4}$일 때: $f(x) = -\frac{3}{4}$인 지점 1곳과 $f(x) = \frac{3}{4}$인 지점 2곳에서 만나 총 3개의 실근을 갖습니다.
- $k = \frac{5}{4}$일 때: $f(x) = \frac{5}{4}$인 지점 1곳과 $f(x) = -\frac{5}{4}$인 지점(없음)에서 만나 1개의 실근을 갖습니다.

따라서 서로 다른 3개의 실근을 갖게 하는 $k$의 값은 $\alpha = \frac{3}{4}$입니다.

문제에서 요구하는 값은 $40\alpha$이므로,
$40 \times \frac{3}{4} = 30$
