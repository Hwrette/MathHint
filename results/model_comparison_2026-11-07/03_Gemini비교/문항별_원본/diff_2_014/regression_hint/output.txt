함수 $g(x) = (x^2 - 2x)f(x)$를 미분하면 곱의 미분법에 의해 다음과 같습니다.
$g'(x) = (2x - 2)f(x) + (x^2 - 2x)f'(x)$

이제 $g'(0)$과 $g'(2)$를 각각 구합니다.

1) $x = 0$일 때:
$g'(0) = (2(0) - 2)f(0) + (0^2 - 2(0))f'(0)$
$g'(0) = -2f(0)$

2) $x = 2$일 때:
$g'(2) = (2(2) - 2)f(2) + (2^2 - 2(2))f'(2)$
$g'(2) = (4 - 2)f(2) + (4 - 4)f'(2)$
$g'(2) = 2f(2)$

문제에서 $g'(0) + g'(2) = 16$이라고 하였으므로, 위에서 구한 식을 대입하면 다음과 같습니다.
$-2f(0) + 2f(2) = 16$

양변을 2로 나누면:
$f(2) - f(0) = 8$

따라서 구하는 값은 8입니다.

최종정답: ②
