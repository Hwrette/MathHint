함수 $f(x) = x^3 - 3x + 2a$의 극값을 구하기 위해 도함수를 구하면 다음과 같습니다.
$f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x - 1)(x + 1)$

$f'(x) = 0$이 되는 $x$의 값은 $x = -1$ 또는 $x = 1$입니다.
함수 $f(x)$의 증감표를 생각해보면, $x = -1$에서 극대이고 $x = 1$에서 극소임을 알 수 있습니다.

문제에서 극솟값이 $a + 3$이라고 하였으므로, $f(1)$을 구하면 다음과 같습니다.
$f(1) = 1^3 - 3(1) + 2a = 1 - 3 + 2a = 2a - 2$
따라서 $2a - 2 = a + 3$이 성립합니다.
이를 풀면 $a = 5$입니다.

이제 극댓값 $f(-1)$을 구합니다.
$f(-1) = (-1)^3 - 3(-1) + 2a = -1 + 3 + 2a = 2a + 2$
위에서 구한 $a = 5$를 대입하면,
$f(-1) = 2(5) + 2 = 10 + 2 = 12$

따라서 함수 $f(x)$의 극댓값은 12입니다.
