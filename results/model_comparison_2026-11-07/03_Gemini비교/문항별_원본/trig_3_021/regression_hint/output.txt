주어진 두 함수 $y = \sin x$와 $y = \cos \left( x + \frac{\pi}{2} \right) + 1$이 만나는 점의 $x$좌표를 구하기 위해 방정식을 세웁니다.

먼저, 삼각함수의 성질에 의해 $\cos \left( x + \frac{\pi}{2} \right) = -\sin x$임을 이용합니다.
따라서 주어진 방정식은 다음과 같습니다.
$$\sin x = -\sin x + 1$$

이 식을 정리하면:
$$2 \sin x = 1$$
$$\sin x = \frac{1}{2}$$

범위 $0 \le x < 2\pi$에서 $\sin x = \frac{1}{2}$을 만족하는 $x$의 값은 다음과 같습니다.
1) $x = \frac{\pi}{6}$
2) $x = \pi - \frac{\pi}{6} = \frac{5}{6}\pi$

구하는 모든 점의 $x$좌표의 합은:
$$\frac{\pi}{6} + \frac{5}{6}\pi = \frac{6}{6}\pi = \pi$$

따라서 정답은 ②번입니다.

최종정답: ②
