주어진 식 $\sin^4 \theta + \cos^4 \theta = \frac{23}{32}$을 변형하여 $\sin \theta \cos \theta$의 값을 구합니다.

1. **$\sin^4 \theta + \cos^4 \theta$ 식 변형:**
   $\sin^4 \theta + \cos^4 \theta = (\sin^2 \theta + \cos^2 \theta)^2 - 2\sin^2 \theta \cos^2 \theta$
   $= 1 - 2(\sin \theta \cos \theta)^2 = \frac{23}{32}$

2. **$\sin \theta \cos \theta$ 구하기:**
   $2(\sin \theta \cos \theta)^2 = 1 - \frac{23}{32} = \frac{9}{32}$
   $(\sin \theta \cos \theta)^2 = \frac{9}{64}$
   $\sin \theta \cos \theta = \pm \frac{3}{8}$

   문제에서 $\frac{\pi}{2} < \theta < \pi$이므로, $\sin \theta > 0$이고 $\cos \theta < 0$입니다.
   따라서 $\sin \theta \cos \theta = -\frac{3}{8}$입니다.

3. **$(\sin \theta - \cos \theta)^2$ 구하기:**
   $(\sin \theta - \cos \theta)^2 = \sin^2 \theta + \cos^2 \theta - 2\sin \theta \cos \theta$
   $= 1 - 2\left(-\frac{3}{8}\right) = 1 + \frac{3}{4} = \frac{7}{4}$

4. **$\sin \theta - \cos \theta$ 구하기:**
   $\sin \theta - \cos \theta = \pm \sqrt{\frac{7}{4}} = \pm \frac{\sqrt{7}}{2}$
   
   $\frac{\pi}{2} < \theta < \pi$ 범위에서 $\sin \theta > 0$이고 $\cos \theta < 0$이므로,
   $\sin \theta - \cos \theta = \sin \theta + |\cos \theta| > 0$입니다.
   따라서 $\sin \theta - \cos \theta = \frac{\sqrt{7}}{2}$입니다.
