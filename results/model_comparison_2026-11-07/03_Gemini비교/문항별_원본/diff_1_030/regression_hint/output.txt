함수 $f(x) = x^3 + ax + 9$가 $x = -1$에서 극대이므로, 미분계수 $f'(-1) = 0$이어야 합니다.

먼저 $f(x)$를 미분하면 다음과 같습니다.
$f'(x) = 3x^2 + a$

$x = -1$에서 극대이므로 $f'(-1) = 0$을 대입합니다.
$f'(-1) = 3(-1)^2 + a = 0$
$3 + a = 0$
$a = -3$

따라서 함수는 $f(x) = x^3 - 3x + 9$가 됩니다.
극값을 구하기 위해 $f'(x) = 3x^2 - 3 = 0$을 풀면,
$3(x^2 - 1) = 0$
$3(x - 1)(x + 1) = 0$
$x = -1$ 또는 $x = 1$

$x = -1$에서 극대이므로, 극솟값은 $x = 1$에서 가집니다.
$f(1) = 1^3 - 3(1) + 9$
$f(1) = 1 - 3 + 9 = 7$

따라서 함수 $f(x)$의 극솟값은 $7$입니다.
