주어진 부등식 $3x^4 - 4x^3 - 12x^2 + k \geq 0$이 모든 실수 $x$에 대하여 성립하려면, 함수 $f(x) = 3x^4 - 4x^3 - 12x^2$의 최솟값이 $-k$보다 크거나 같아야 합니다. 즉, $k \geq -f(x)$의 최솟값, 다시 말해 $k \geq -(\text{최솟값})$이 되어야 합니다.

먼저 $f(x) = 3x^4 - 4x^3 - 12x^2$의 최솟값을 구하기 위해 미분합니다.
$f'(x) = 12x^3 - 12x^2 - 24x$

$f'(x) = 12x(x^2 - x - 2) = 12x(x - 2)(x + 1) = 0$으로 두면,
임계점은 $x = -1, x = 0, x = 2$입니다.

각 지점에서의 함숫값을 구하면 다음과 같습니다.
1) $f(-1) = 3(-1)^4 - 4(-1)^3 - 12(-1)^2 = 3 + 4 - 12 = -5$
2) $f(0) = 3(0)^4 - 4(0)^3 - 12(0)^2 = 0$
3) $f(2) = 3(2)^4 - 4(2)^3 - 12(2)^2 = 3(16) - 4(8) - 12(4) = 48 - 32 - 48 = -32$

따라서 함수 $f(x)$의 최솟값은 $-32$입니다.

모든 실수 $x$에 대하여 $f(x) + k \geq 0$이 성립하려면, $f(x)$의 최솟값에 $k$를 더한 값이 $0$ 이상이어야 합니다.
$-32 + k \geq 0$
$k \geq 32$

따라서 실수 $k$의 최솟값은 $32$입니다.

최종정답: 32
