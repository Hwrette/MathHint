주어진 방정식 $\cos^{2} x - 1 = 2 \sin x$를 풀어보겠습니다.

1. **삼각함수의 기본 성질 이용:**
   $\cos^{2} x = 1 - \sin^{2} x$이므로, 이를 방정식에 대입합니다.
   $(1 - \sin^{2} x) - 1 = 2 \sin x$
   $-\sin^{2} x = 2 \sin x$

2. **방정식 정리:**
   $\sin^{2} x + 2 \sin x = 0$
   $\sin x (\sin x + 2) = 0$

3. **해 구하기:**
   따라서 $\sin x = 0$ 또는 $\sin x = -2$입니다.
   그런데 모든 실수 $x$에 대하여 $-1 \leq \sin x \leq 1$이므로, $\sin x = -2$를 만족하는 실수는 존재하지 않습니다.
   따라서 $\sin x = 0$을 만족하는 $x$의 값을 구해야 합니다.

4. **범위 내의 해 찾기:**
   $0 < x \leq 2 \pi$ 범위에서 $\sin x = 0$을 만족하는 $x$는 다음과 같습니다.
   $x = \pi, \quad x = 2 \pi$

5. **해의 합 계산:**
   모든 해의 합은 $\pi + 2 \pi = 3 \pi$입니다.

따라서 정답은 ④번입니다.

최종정답: ④
