주어진 부등식 $2x + 1 \leq f(x) \leq (x + 1)^2$의 각 변에 $(x + 5)$를 곱합니다. 이때 $x \rightarrow 0$인 상황을 고려하면 $x$가 0 근처의 양수일 때와 음수일 때를 생각할 수 있으나, 극한의 성질에 의해 부등식의 양변에 극한을 취하면 됩니다.

먼저, 모든 실수 $x$에 대하여 다음이 성립합니다.
$(2x + 1)(x + 5) \leq (x + 5)f(x) \leq (x + 1)^2(x + 5)$

이제 각 변에 $x \rightarrow 0$일 때의 극한을 취합니다.

1. 좌변의 극한:
$\lim_{x \rightarrow 0} (2x + 1)(x + 5) = (2(0) + 1)(0 + 5) = 1 \times 5 = 5$

2. 우변의 극한:
$\lim_{x \rightarrow 0} (x + 1)^2(x + 5) = (0 + 1)^2(0 + 5) = 1^2 \times 5 = 5$

함수의 극한의 대소 관계(샌드위치 정리)에 의하여,
$\lim_{x \rightarrow 0} (x + 5)f(x) = 5$

따라서 구하는 극한값은 5입니다.
