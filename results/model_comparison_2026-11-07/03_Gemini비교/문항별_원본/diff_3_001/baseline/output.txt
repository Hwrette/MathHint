주어진 부등식 $2x + 1 \leq f(x) \leq (x + 1)^2$의 각 변에 $(x + 5)$를 곱합니다.
$x \to 0$일 때 $x+5 > 0$이므로 부등호의 방향은 바뀌지 않습니다.

$(x + 5)(2x + 1) \leq (x + 5)f(x) \leq (x + 5)(x + 1)^2$

이제 각 변의 $x \to 0$일 때의 극한값을 구합니다.

1. 좌변의 극한:
$\lim_{x \to 0} (x + 5)(2x + 1) = (0 + 5)(2 \cdot 0 + 1) = 5 \cdot 1 = 5$

2. 우변의 극한:
$\lim_{x \to 0} (x + 5)(x + 1)^2 = (0 + 5)(0 + 1)^2 = 5 \cdot 1^2 = 5$

함수의 극한의 대소 관계(샌드위치 정리)에 의해,
$\lim_{x \to 0} (x + 5)f(x) = 5$가 성립합니다.

따라서 정답은 ⑤번입니다.

최종정답: ⑤
