함수 $f(x) = x^3 - 6x^2 + ax + b$가 $x=3$에서 극값을 가지므로, 미분계수 $f'(3) = 0$이어야 합니다.

1. **$a$의 값 구하기**
   $f'(x) = 3x^2 - 12x + a$
   $f'(3) = 3(3)^2 - 12(3) + a = 27 - 36 + a = -9 + a$
   $-9 + a = 0$ 이므로 **$a = 9$**입니다.

2. **극값 구하기**
   $f'(x) = 3x^2 - 12x + 9 = 3(x^2 - 4x + 3) = 3(x-1)(x-3)$
   $f'(x) = 0$이 되는 $x$는 $x=1$ 또는 $x=3$입니다.
   따라서 극값은 $f(1)$과 $f(3)$입니다.

   $f(1) = 1^3 - 6(1)^2 + 9(1) + b = 1 - 6 + 9 + b = 4 + b$
   $f(3) = 3^3 - 6(3)^2 + 9(3) + b = 27 - 54 + 27 + b = b$

3. **$b$의 값 구하기**
   극댓값과 극솟값의 합이 8이라고 하였으므로,
   $(4 + b) + b = 8$
   $2b + 4 = 8$
   $2b = 4$
   **$b = 2$**

4. **$a + b$ 계산하기**
   $a + b = 9 + 2 = 11$

최종정답: 11
