함수 $f(x) = x^3 - 6x^2 + ax + b$가 $x=3$에서 극값을 가지므로, 도함수 $f'(x)$는 $x=3$을 근으로 갖습니다.

1. **$a$의 값 구하기**
   $f'(x) = 3x^2 - 12x + a$
   $f'(3) = 3(3)^2 - 12(3) + a = 0$
   $27 - 36 + a = 0$
   $-9 + a = 0 \implies a = 9$

2. **극값 구하기**
   $f'(x) = 3x^2 - 12x + 9 = 3(x^2 - 4x + 3) = 3(x-1)(x-3)$
   따라서 $f(x)$는 $x=1$에서 극대, $x=3$에서 극소를 갖습니다.
   극댓값: $f(1) = 1^3 - 6(1)^2 + 9(1) + b = 1 - 6 + 9 + b = 4 + b$
   극솟값: $f(3) = 3^3 - 6(3)^2 + 9(3) + b = 27 - 54 + 27 + b = b$

3. **$b$의 값 구하기**
   극댓값과 극솟값의 합이 8이므로,
   $(4 + b) + b = 8$
   $4 + 2b = 8$
   $2b = 4 \implies b = 2$

4. **$a + b$의 값 구하기**
   $a = 9, b = 2$이므로
   $a + b = 9 + 2 = 11$

최종정답: 11
