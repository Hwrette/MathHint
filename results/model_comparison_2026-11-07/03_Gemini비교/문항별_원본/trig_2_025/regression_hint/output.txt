주어진 방정식 $\sqrt{2} \cos x - 1 = 0$을 정리하면 다음과 같습니다.

$\sqrt{2} \cos x = 1$
$\cos x = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$

범위 $0 \leq x \leq 3\pi$에서 $\cos x = \frac{\sqrt{2}}{2}$를 만족하는 $x$의 값을 구합니다.

1. $0 \leq x \leq 2\pi$ 구간에서:
   $\cos x = \frac{\sqrt{2}}{2}$를 만족하는 해는 $x = \frac{\pi}{4}$와 $x = 2\pi - \frac{\pi}{4} = \frac{7}{4}\pi$입니다.

2. $2\pi < x \leq 3\pi$ 구간에서:
   $x = 2\pi + \frac{\pi}{4} = \frac{9}{4}\pi$가 해가 됩니다. (단, $2\pi + \frac{7}{4}\pi = \frac{15}{4}\pi$는 $3\pi$를 초과하므로 제외합니다.)

따라서 구하는 모든 해의 합은 다음과 같습니다.
$\frac{\pi}{4} + \frac{7}{4}\pi + \frac{9}{4}\pi = \frac{17}{4}\pi$
