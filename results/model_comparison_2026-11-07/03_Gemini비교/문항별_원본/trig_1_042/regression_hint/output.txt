함수 $y = \tan ax$의 주기는 $\frac{\pi}{a}$입니다.
직선 $y = b$ ($b > 0$)와 만나는 점의 $x$좌표를 $x_n$이라 하면, 탄젠트 함수의 주기성에 의해 $x_n$은 다음과 같이 나타낼 수 있습니다.
$x_n = \frac{1}{a} (\arctan b + (n-1)\pi)$

문제에서 $x_1 = \pi$라고 하였으므로,
$x_1 = \frac{1}{a} \arctan b = \pi$  --- (1)
가 성립합니다.

또한, $x_4 - x_2 = 6\pi$라고 하였습니다.
$x_4 = \frac{1}{a} (\arctan b + 3\pi)$
$x_2 = \frac{1}{a} (\arctan b + \pi)$
이므로,
$x_4 - x_2 = \frac{1}{a} (\arctan b + 3\pi) - \frac{1}{a} (\arctan b + \pi) = \frac{2\pi}{a}$
따라서 $\frac{2\pi}{a} = 6\pi$가 되어, $a = \frac{1}{3}$입니다.

이제 (1)식에 $a = \frac{1}{3}$을 대입하면,
$\frac{1}{1/3} \arctan b = \pi$
$3 \arctan b = \pi$
$\arctan b = \frac{\pi}{3}$
따라서 $b = \tan \frac{\pi}{3} = \sqrt{3}$입니다.

구하고자 하는 값은 $a \times b$이므로,
$a \times b = \frac{1}{3} \times \sqrt{3} = \frac{\sqrt{3}}{3}$입니다.
