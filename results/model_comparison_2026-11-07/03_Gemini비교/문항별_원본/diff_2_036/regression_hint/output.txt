방정식 $x^3 - 3x^2 - 9x + k = 0$의 서로 다른 실근의 개수가 2개가 되려면, 함수 $f(x) = x^3 - 3x^2 - 9x$와 직선 $y = -k$가 접해야 합니다.

먼저 $f(x) = x^3 - 3x^2 - 9x$의 극값을 구하기 위해 미분합니다.
$f'(x) = 3x^2 - 6x - 9 = 3(x^2 - 2x - 3) = 3(x - 3)(x + 1)$

$f'(x) = 0$이 되는 $x$의 값은 $x = -1$ 또는 $x = 3$입니다.
각각의 극값을 구하면 다음과 같습니다.
1) $x = -1$일 때: $f(-1) = (-1)^3 - 3(-1)^2 - 9(-1) = -1 - 3 + 9 = 5$
2) $x = 3$일 때: $f(3) = (3)^3 - 3(3)^2 - 9(3) = 27 - 27 - 27 = -27$

방정식 $f(x) = -k$가 서로 다른 두 실근을 가지려면, $-k$가 극댓값 또는 극솟값과 같아야 합니다.
즉, $-k = 5$ 또는 $-k = -27$이어야 합니다.

따라서 $k = -5$ 또는 $k = 27$입니다.
문제에서 요구하는 모든 실수 $k$의 값의 합은 $(-5) + 27 = 22$입니다.
