주어진 극한식 $\lim_{h \rightarrow 0} \frac{g(1+h)-4}{h} = 9$는 미분계수의 정의에 의해 $g'(1) = 9$임을 의미합니다. 또한, $h \rightarrow 0$일 때 분자가 0으로 수렴해야 하므로 $g(1) - 4 = 0$, 즉 $g(1) = 4$입니다.

1. $g(x) = (x^2 + x)f(x)$이므로, $g(1) = (1^2 + 1)f(1) = 2f(1) = 4$입니다.
   따라서 **$f(1) = 2$**입니다.

2. $g(x)$를 미분하면 곱의 미분법에 의해 다음과 같습니다.
   $g'(x) = (2x + 1)f(x) + (x^2 + x)f'(x)$

3. $g'(1) = 9$를 대입하면:
   $g'(1) = (2(1) + 1)f(1) + (1^2 + 1)f'(1) = 9$
   $3f(1) + 2f'(1) = 9$

4. 위에서 구한 $f(1) = 2$를 대입합니다.
   $3(2) + 2f'(1) = 9$
   $6 + 2f'(1) = 9$
   $2f'(1) = 3$
   **$f'(1) = \frac{3}{2}$**

5. 문제에서 요구하는 $f(1) \times f'(1)$의 값은:
   $f(1) \times f'(1) = 2 \times \frac{3}{2} = 3$
