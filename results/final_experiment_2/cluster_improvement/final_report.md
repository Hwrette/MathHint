# MathHint 전체265 문제 BoW·불용어 전처리 군집화 보고서

## 1. 연구 배경과 목적

원시 BoW에서 자주 등장하는 서식·변수·숫자가 거리 계산을 크게 차지할 수 있다. 사용자가 직접 승인한 문제 불용어를 적용했을 때 실제 교육과정 분류와의 군집 구조 일치도가 어떻게 변하는지 탐색했다. 개선을 미리 가정하지 않고 상승·하락·변화 없음을 함께 기록한다.

## 3. 사용자 불용어 적용과 실험 방법

K0/K1은 동일한 전체 원문과 토큰화에서 출발한다. K1은 사용자가 승인한 문제 목록만 적용하고 해당 차원을 제외한 활성 어휘를 사용한다. 원시 TF는 정수로 유지하며 추가 정규화·새 토큰화·자동 불용어 선정은 하지 않았다. 기존185/80 분할은 문항 출처로 보존했지만 이번 중심은 두 집합을 합친265문항에서 학습했다.

계층 라벨은 curriculum→unit→subunit→type의 경로다. subject의 자료군을 과목으로 사용하지 않았다. 라벨은 k 검증과 사후 평가·대표 라벨 정하기에만 쓰고 K-means 빈도 벡터에 포함하지 않았다. 시드42~46의5회 초기화, 최대100회·기존 수렴 기준을 유지하고 각 방법의 학습 목적함수가 최소인 실행을 선택한다. ARI·NMI나 실제 분류를 보고 시드를 선택하지 않는다. 서로 다른 방법의 목적함수 크기는 직접 비교하지 않는다.

실제분류×군집번호 교차표는 여러 유형의 혼합과 한 유형의 분산을 보여준다. 실제분류×군집대표라벨 혼동행렬은 군집을 실제 라벨로 매핑한 뒤의 일치 문항 수를 보여준다. 서로 다른 군집이 같은 최빈 라벨을 가지면 같은 예측 열에 합쳐진다. 행과 열의 라벨 순서는 같아서 대각선 합/265가 저장된 대표 라벨 일치율과 대응한다. 각 군집의 원문을 읽어 수식·자연어의 공통점과 차이를 확인한다.

## 6. 관찰과 가능한 해석

**확인한 사실:** 선택된 모델에서 K0 대비 상승한 조건 수는 ARI 8/8, AMI 8/8, NMI 8/8다. 하지만 유클리드 단원 ARI 변화는 +0.0108로, 과목 +0.3096와 유형 +0.2527보다 작았다.

유클리드 세부단원의 Macro-F1은 0.314665→0.314530(-0.000135)로 아주 작게 하락했다. 같은 조건의 ARI·Weighted-F1 상승이 모든 실제 분류를 균등하게 더 잘 구별한다는 뜻은 아니다. 이 미세 차이의 통계적 유의성은 검정하지 않았다.

어휘만 복원한 K0는 기존 전체265 결과 대비 ARI가 5조건에서 같고 2조건에서 상승·1조건에서 하락했다. 구면 방식의 유형 ARI는 0.2063→0.1993였다. 표현을 복원하는 것과 군집 일치도가 높아지는 것은 같은 결과가 아니다.

불용어 제거 후 같은 벡터가 된 문항: `diff_1_007`·`diff_1_011`(같은 실제 유형). 숫자·변수 등 제거한 좌표의 차이가 사라진 정보 손실 사례다. 같은 유형 안의 중복 표현이 생겼다는 사실을 유형 오분류가 발생했다는 주장과 구분한다.

**가능한 해석:** 빈도 규모가 큰 좌표를 제거하면 유클리드 공간의 상대 가중치가 달라진다. 이 변화가 어떤 분류에는 도움이 되고 다른 분류의 단서를 잃게 할 수 있다. 하지만 여러 종류의 승인 토큰을 한꺼번에 제거했으므로 개별 토큰의 인과 효과를 분리해 검증한 것은 아니다. 코사인 방식도 같은 좌표 제거 뒤 방향이 바뀌므로 서식 제거 효과가 항상 같은 방향일 필요는 없다.

## 7. 기존 연구와의 차이

이번 비교의 역사적 기준선은 기존 전체265 탐색 실험이다. 기존 학습185·테스트80 평가와 이번 동일265 평가를 같은 의미의 성능으로 비교하지 않는다. 기존 회귀·Gemini 응답과 평가값은 읽기 화면에 남아 있으며 이번 연구의 새 결과로 다시 보고하지 않았다.

## 8. 정보 사용과 데이터 규모의 한계

- 전체265문항으로 어휘와 군집 중심을 만들고 같은265문항을 평가했다. 새로운 문항에 대한 테스트 정확도·일반화 성능이 아니다.
- 군집 대표 라벨도 같은265문항의 최빈 실제 라벨이다. 대표 라벨 일치율과 F1은 동일 자료 내 설명용 분류 지표이며, ARI·AMI·NMI는 군집 구조의 일치도다.
- 사용자가 전체265의 토큰 통계·η²를 보고 불용어를 선택했으므로 완전히 미관측인 독립 검증으로 주장할 수 없다. 새 문항으로 추가 검증해야 한다.
- K1과 기존 결과의 차이에는 어휘 재구성과 불용어 적용이 함께 포함된다. 불용어 적용 효과는 같은 전체 어휘에서 출발한 K0↔K1로 구분한다.
- BoW는 순서·분자/분모·밑/지수·논리 관계를 빈도 합으로 잃는다. 실제 분류와 비슷한 군집이 수학적 이해나 풀이 능력을 증명하지 않는다.
- Spherical 방식은 L2 정규화와 중심 갱신·정규화가 함께 다르다. 이번 결과만으로 차이의 원인을 입력 정규화 하나로 확정하지 않는다.
- 다중 시드는 초기화 변동을 관찰하기 위한 것이며 독립 데이터 반복 검증이나 통계적 유의성 검정이 아니다. 유형70개와 희귀 유형 때문에 높은 NMI만으로 분류 품질을 판단하지 않는다.

## 9. BoW의 표현 한계와 후속 연구

토큰 빈도는 개념·연산·문제 표현의 존재를 간단히 비교할 수 있지만 토큰 순서와 수식 구조를 직접 다루지 못한다. 다층 비선형 모델이나 어텐션 기반 표현을 검토할 수는 있으나 이번 결과가 그 필요성이나 성능 향상을 증명하지 않는다. 층을 늘리는 것만으로 BoW에서 사라진 수식 구조가 복원되지도 않는다. 문맥 기반 표현·디코딩 제약·Lean 같은 출력 검증으로 확장하더라도 새로운 데이터에서의 검증이 필요하며 형식 검증 성공과 고등학교 교육과정 적합성은 구분해야 한다. 이번에는 그러한 구현을 하지 않았다.
