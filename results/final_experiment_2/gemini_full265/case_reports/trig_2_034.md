## 원본 문제와 선택지

$0 \leq x \leq 2 \pi$일 때, 부등식 $3 \sin x - 2 > 0$의 해가 $\alpha < x < \beta$이다. $\cos \left( \alpha + \beta \right)$의 값은?
① $- 1$		② $- \frac{1}{2}$		③ $0$
④ $\frac{1}{2}$		⑤ $1$


## 원본 정답

①

## 원본 해설 전체

[정답] ①

[해설]
$3 \sin x - 2 > 0$에서 $\sin x > \frac{2}{3}$이다.
$0 \leq x < 2 \pi$에서 함수 $y = \sin x$의 그래프와 직선 $y = \frac{2}{3}$는 그림과 같다.

$0 \leq x < 2 \pi$일 때, 부등식 $3 \sin x - 2 > 0$의 해가 $\alpha < x < \beta$이므로 함수 $y = \sin x$의 그래프와 직선 $y = \frac{2}{3}$가 만나는 두 점의 $x$좌표는 각각 $\alpha$, $\beta \left( 0 < \alpha < \beta < \pi \right)$이다.
$\frac{\pi}{2} - \alpha = \beta - \frac{\pi}{2}$이므로 $\alpha + \beta = \pi$이다.
따라서 $\cos \left( \alpha + \beta \right) = \cos {\pi} = - 1$

### 생성 풀이 전체

주어진 부등식 $3 \sin x - 2 > 0$을 정리하면 다음과 같습니다.
$3 \sin x > 2$
$\sin x > \frac{2}{3}$

$0 \leq x \leq 2\pi$ 범위에서 $\sin x = \frac{2}{3}$를 만족하는 두 값을 각각 $x_1, x_2$라고 하면, 사인 함수의 그래프의 대칭성에 의해 두 값의 합은 다음과 같습니다.
$x_1 + x_2 = \pi$

부등식 $\sin x > \frac{2}{3}$의 해는 $\sin x = \frac{2}{3}$인 두 지점 사이의 구간이므로, 해는 $x_1 < x < x_2$가 됩니다.
문제에서 해가 $\alpha < x < \beta$라고 하였으므로, $\alpha = x_1$이고 $\beta = x_2$입니다.
따라서 $\alpha + \beta = \pi$입니다.

우리가 구하고자 하는 값은 $\cos(\alpha + \beta)$이므로,
$\cos(\alpha + \beta) = \cos(\pi)$

$\cos(\pi) = -1$입니다.

최종정답: ①
