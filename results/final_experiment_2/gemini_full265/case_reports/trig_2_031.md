## 원본 문제와 선택지

두 자연수 $a$, $b$에 대하여 함수
$f \left( x \right) = a \sin b x + 8 - a$
가 다음 조건을 만족시킬 때, $a + b$의 값을 구하시오.

(가) 모든 실수 $x$에 대하여 $f (x) \geq 0$이다.
(나) $0 \leq x < 2 \pi$일 때, $x$에 대한 방정식 $f (x) = 0$의 서로 다른 실근의 개수는 $\mathrm{4}$이다.


## 원본 정답

$8$

## 원본 해설 전체

[정답] $8$

[해설]
조건 (가)에서 $f \left( x \right) \ge 0$이고, 조건 (나)에서 방정식 $f \left( x \right) = 0$의 실근이 존재하므로 함수 $f \left( x \right)$의 최솟값은 $0$이다.
수 $f \left( x \right) = a \sin b x + 8 - a$의 최솟값은 $8 - 2 a$이므로
$8 - 2 a = 0$,    $a = 4$
조건 (나)에서 $0 \leq x < 2 \pi$일 때, 방정식 $\sin b x = - 1$의 서로 다른 실근의 개수가 $4$이므로 방정식 $\sin b x = - 1$의 해는
$b x = \frac{3}{2} \pi$, $2 \pi + \frac{3}{2} \pi$, $4 \pi + \frac{3}{2} \pi$, $6 \pi + \frac{3}{2} \pi$
뿐이어야 한다.
$x < 2 \pi$이므로    $6 \pi + \frac{3}{2} \pi < 2 \pi b \leq 8 \pi + \frac{3}{2} \pi$
따라서 $3 + \frac{3}{4} < b \leq 4 + \frac{3}{4}$이고 $b$는 자연수이므로
$b = 4$
$\therefore$ $a + b = 8$

### 생성 풀이 전체

함수 $f(x) = a \sin bx + 8 - a$에 대하여 주어진 조건을 분석합니다.

**1. 조건 (가) 분석**
모든 실수 $x$에 대하여 $f(x) \geq 0$이어야 합니다.
$\sin bx$의 값은 $-1$에서 $1$ 사이의 값을 가지므로, $f(x)$의 최솟값은 $a(-1) + 8 - a = 8 - 2a$입니다.
따라서 $8 - 2a \geq 0$이어야 하므로 $2a \leq 8$, 즉 $a \leq 4$입니다.
$a$는 자연수이므로 $a \in \{1, 2, 3, 4\}$입니다.

**2. 조건 (나) 분석**
$f(x) = 0$은 $a \sin bx = a - 8$이므로, $\sin bx = \frac{a-8}{a} = 1 - \frac{8}{a}$입니다.
$0 \leq x < 2\pi$일 때, $0 \leq bx < 2\pi b$입니다.
$\sin bx = k$ (단, $k = 1 - \frac{8}{a}$)의 실근의 개수가 4개가 되려면, $b$의 값에 따라 결정됩니다.

- $a=1$일 때: $\sin bx = 1 - 8 = -7$ (해 없음)
- $a=2$일 때: $\sin bx = 1 - 4 = -3$ (해 없음)
- $a=3$일 때: $\sin bx = 1 - \frac{8}{3} = -\frac{5}{3}$ (해 없음)
- $a=4$일 때: $\sin bx = 1 - \frac{8}{4} = -1$

$a=4$일 때, 방정식은 $\sin bx = -1$이 됩니다.
$0 \leq bx < 2\pi b$ 범위에서 $\sin bx = -1$인 $bx$의 값은 $\frac{3}{2}\pi, \frac{7}{2}\pi, \frac{11}{2}\pi, \dots$ 입니다.
실근의 개수가 4개가 되려면, $2\pi b$의 범위 안에 $\sin bx = -1$이 되는 지점이 4개 포함되어야 합니다.
즉, $\frac{15}{2}\pi < 2\pi b \leq \frac{19}{2}\pi$를 만족해야 합니다.
$\frac{15}{4} < b \leq \frac{19}{4}$ 이므로 $3.75 < b \leq 4.75$입니다.
$b$는 자연수이므로 $b = 4$입니다.

확인: $b=4$이면 $0 \leq x < 2\pi$에서 $0 \leq 4x < 8\pi$입니다.
$\sin 4x = -1$을 만족하는 $4x$는 $\frac{3}{2}\pi, \frac{7}{2}\pi, \frac{11}{2}\pi, \frac{15}{2}\pi$로 총 4개입니다.

따라서 $a=4, b=4$이므로 $a+b = 8$입니다.

최종정답: 8

### 생성 풀이 전체

함수 $f(x) = a \sin bx + 8 - a$에 대하여 주어진 조건을 분석합니다.

**(가) 모든 실수 $x$에 대하여 $f(x) \geq 0$이다.**
함수 $f(x)$의 최솟값은 $a(-1) + 8 - a = 8 - 2a$입니다.
모든 실수 $x$에 대하여 $f(x) \geq 0$이려면 최솟값이 $0$ 이상이어야 하므로,
$8 - 2a \geq 0 \implies 2a \leq 8 \implies a \leq 4$입니다.
$a$는 자연수이므로 $a \in \{1, 2, 3, 4\}$입니다.

**(나) $0 \leq x < 2\pi$일 때, $f(x) = 0$의 서로 다른 실근의 개수는 4이다.**
$f(x) = 0$에서 $a \sin bx = a - 8$이므로, $\sin bx = \frac{a-8}{a} = 1 - \frac{8}{a}$입니다.
이때, $f(x) \geq 0$ 조건에 의해 $1 - \frac{8}{a} \geq -1$이 성립합니다.

1) $a=4$인 경우: $\sin bx = 1 - \frac{8}{4} = -1$
$\sin bx = -1$이 되는 $x$의 개수가 $0 \leq x < 2\pi$에서 4개가 되려면, $bx$의 범위가 $0 \leq bx < 2b\pi$이므로 $b$가 2여야 합니다.
$b=2$이면 $\sin 2x = -1$에서 $2x = \frac{3}{2}\pi, \frac{7}{2}\pi$가 되어 근은 2개뿐입니다. (조건 불만족)

2) $a < 4$인 경우: $-1 < 1 - \frac{8}{a} < 0$
$\sin bx = k$ (단, $-1 < k < 0$) 형태의 방정식은 $0 \leq bx < 2b\pi$ 범위에서 각 주기마다 2개의 근을 가집니다.
주기가 $b$개 있으므로 총 근의 개수는 $2b$개입니다.
문제에서 근의 개수가 4개라고 하였으므로 $2b = 4 \implies b = 2$입니다.

이제 $a$의 값을 결정합니다. $a$는 자연수이고 $a < 4$이므로 $a \in \{1, 2, 3\}$입니다.
$a=1$일 때 $\sin 2x = -7$ (불가능)
$a=2$일 때 $\sin 2x = -3$ (불가능)
$a=3$일 때 $\sin 2x = 1 - \frac{8}{3} = -\frac{5}{3}$ (불가능)

다시 확인하면, $f(x) = 0$이 되려면 $a \sin bx = a - 8$에서 $\sin bx = \frac{a-8}{a}$입니다.
근이 4개가 되려면 $\sin bx = k$에서 $-1 < k < 0$이어야 하며, $b=2$일 때 $2b=4$가 성립합니다.
$a=4$일 때 $\sin 2x = -1$은 근이 2개이므로, $a$가 4보다 작으면서 근이 4개가 되는 경우는 $a=4$일 때의 경계 조건을 다시 살펴야 합니다.
$a=4$일 때 $f(x) = 4 \sin bx + 4 = 0 \implies \sin bx = -1$.
$0 \leq x < 2\pi$에서 $\sin bx = -1$이 근을 4개 가지려면 $b=2$일 때 $2x = \frac{3}{2}\pi, \frac{7}{2}\pi$로 2개, $b=3$일 때 $3x = \frac{3}{2}\pi, \frac{7}{2}\pi, \frac{11}{2}\pi$로 3개, $b=4$일 때 $4x = \frac{3}{2}\pi, \frac{7}{2}\pi, \frac{11}{2}\pi, \frac{15}{2}\pi$로 4개가 됩니다.
따라서 $a=4, b=4$일 때 조건을 만족합니다.

$a+b = 4+4 = 8$

최종정답: 8
