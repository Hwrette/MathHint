## 원본 문제와 선택지

두 양수 $a$, $b$에 대하여 함수 $f \left( x \right) = a \sin b x + 1$의 주기가 $3 \pi$이고 최댓값과 최솟값의 차가 $6$일 때, $a + b$의 값은?
① $\frac{11}{3}$		② $4$		③ $\frac{13}{3}$
④ $\frac{14}{3}$		⑤ $5$


## 원본 정답

①

## 원본 해설 전체

[정답] ①

[해설]
함수 $f \left( x \right)$의 최댓값과 최솟값이 각각
$a + 1$, $- a + 1$이므로
$\left( a + 1 \right) - \left( - a + 1 \right) = 2 a = 6$에서 $a = 3$
함수 $f \left( x \right)$의 주기가 $\frac{2 \pi}{b}$이므로
$\frac{2 \pi}{b} = 3 \pi$에서 $b = \frac{2}{3}$
따라서 $a + b = \frac{11}{3}$

### 생성 풀이 전체

함수 $f(x) = a \sin bx + 1$ ($a > 0, b > 0$)에 대하여 주어진 조건들을 하나씩 해결해 보겠습니다.

**1. 최댓값과 최솟값의 차 이용**
함수 $f(x) = a \sin bx + 1$에서 $\sin bx$의 값은 $-1$에서 $1$ 사이의 값을 가집니다.
*   최댓값: $a(1) + 1 = a + 1$
*   최솟값: $a(-1) + 1 = -a + 1$
최댓값과 최솟값의 차가 $6$이라고 하였으므로,
$(a + 1) - (-a + 1) = 6$
$a + 1 + a - 1 = 6$
$2a = 6$
따라서 **$a = 3$**입니다.

**2. 주기 이용**
함수 $f(x) = a \sin bx + 1$의 주기는 $\frac{2\pi}{|b|}$입니다.
문제에서 주기가 $3\pi$라고 하였고 $b > 0$이므로,
$\frac{2\pi}{b} = 3\pi$
$3\pi b = 2\pi$
따라서 **$b = \frac{2}{3}$**입니다.

**3. $a + b$의 값 계산**
$a + b = 3 + \frac{2}{3} = \frac{9}{3} + \frac{2}{3} = \frac{11}{3}$

따라서 정답은 ①번입니다.
