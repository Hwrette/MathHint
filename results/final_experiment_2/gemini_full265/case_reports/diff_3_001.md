## 원본 문제와 선택지

함수 $f (x)$가 모든 실수 $x$에 대하여
$2 x + 1 \leq f (x) \leq (x + 1)^{2}$
을 만족시킬 때, $\lim_{x \rightarrow 0} (x + 5) f (x)$의 값은?
① $\mathrm{1}$		② $\mathrm{2}$		③ $\mathrm{3}$
④ $\mathrm{4}$		⑤ $\mathrm{5}$


## 원본 정답

⑤

## 원본 해설 전체

[정답] ⑤

[해설]
$2 x + 1 \leq f (x) \leq (x + 1)^{2}$에서
$\lim_{x \rightarrow 0} (2 x + 1) = \lim_{x \rightarrow 0} (x + 1)^{2} = 1$이므로
함수의 극한의 대소 관계에 의하여 $\lim_{x \rightarrow 0} f (x) = 1$
$\lim_{x \rightarrow 0} (x + 5) f (x) = \lim_{x \rightarrow 0} (x + 5) \times \lim_{x \rightarrow 0} f (x) = 5 \times 1 = 5$

### 생성 풀이 전체

주어진 부등식 $2x + 1 \leq f(x) \leq (x + 1)^2$의 각 변에 $(x + 5)$를 곱합니다.
$x \to 0$일 때 $x+5 > 0$이므로 부등호의 방향은 바뀌지 않습니다.

$(x + 5)(2x + 1) \leq (x + 5)f(x) \leq (x + 5)(x + 1)^2$

이제 각 변의 $x \to 0$일 때의 극한값을 구합니다.

1. 좌변의 극한:
$\lim_{x \to 0} (x + 5)(2x + 1) = (0 + 5)(2 \cdot 0 + 1) = 5 \cdot 1 = 5$

2. 우변의 극한:
$\lim_{x \to 0} (x + 5)(x + 1)^2 = (0 + 5)(0 + 1)^2 = 5 \cdot 1^2 = 5$

함수의 극한의 대소 관계(샌드위치 정리)에 의해,
$\lim_{x \to 0} (x + 5)f(x) = 5$가 성립합니다.

따라서 정답은 ⑤번입니다.

최종정답: ⑤
