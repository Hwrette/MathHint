이때, $\sin^2 x = 1 - \cos^2 x$임을 이용하면,
$f(x) = (1 - \cos^2 x) + \cos x + 1$
$f(x) = -\cos^2 x + \cos x + 2$

이제 $t = \cos x$라고 치환하면, $-1 \le t \le 1$의 범위에서 함수는 다음과 같습니다.

$g(t) = -(t^2 - t) + 2$

범위 $-1 \le t \le 1$ 내에서 $t = \frac{1}{2}$일 때 최댓값 $M = \frac{9}{4}$를 가집니다.
