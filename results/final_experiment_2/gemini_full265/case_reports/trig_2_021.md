① $\frac{\pi}{2}$		② $\frac{3}{4} \pi$		③ $\pi$
④ $\frac{5}{4} \pi$		⑤ $\frac{3}{2} \pi$

[해설]
$2 \sin^{2} x + 3 \sin x - 2 = 0$
$\left( 2 \sin x - 1 \right) \left( \sin x + 2 \right) = 0$
$- 1 \leq \sin x \leq 1$이므로 $\sin x = \frac{1}{2}$

따라서 모든 해의 합은 $\pi$

### 생성 풀이 전체

주어진 방정식 $2 \sin^{2} x + 3 \sin x - 2 = 0$을 $\sin x$에 대한 이차방정식으로 보고 인수분해합니다.

$2 \sin^{2} x + 3 \sin x - 2 = (2 \sin x - 1)(\sin x + 2) = 0$

이 식을 만족하려면 다음 두 경우 중 하나여야 합니다.
1) $2 \sin x - 1 = 0 \implies \sin x = \frac{1}{2}$
2) $\sin x + 2 = 0 \implies \sin x = -2$

그런데 모든 실수 $x$에 대하여 $-1 \leq \sin x \leq 1$이므로, $\sin x = -2$를 만족하는 실수는 존재하지 않습니다.

따라서 $\sin x = \frac{1}{2}$인 경우만 고려하면 됩니다.
$0 \leq x \leq 2\pi$ 범위에서 $\sin x = \frac{1}{2}$을 만족하는 $x$의 값은 다음과 같습니다.
- 제1사분면에서 $x = \frac{\pi}{6}$
- 제2사분면에서 $x = \pi - \frac{\pi}{6} = \frac{5}{6}\pi$

구하는 모든 해의 합은:
$\frac{\pi}{6} + \frac{5}{6}\pi = \frac{6}{6}\pi = \pi$

따라서 정답은 ③번입니다.

최종정답: ③
