## 원본 문제와 선택지

상수 $a$에 대하여 함수 $f \left( x \right) = 3 x^{3} - 9 x^{2} + a$의 극댓값이 $20$일 때, 함수 $f \left( x \right)$의 극솟값을 구하시오.


## 원본 정답

$8$

## 원본 해설 전체

[정답] $8$

[해설]
$f \left( x \right) = 3 x^{3} - 9 x^{2} + a$에서
$f' \left( x \right) = 9 x^{2} - 18 x = 9 x \left( x - 2 \right)$
$f' \left( x \right) = 0$에서    $x = 0$ 또는 $x = 2$
함수 $f (x)$의 증가와 감소를 표로 나타내면 다음과 같다.

$x$	$\cdots$	$0$	$\cdots$	$2$	$\cdots$
$f' (x)$	$+$	$0$	$-$	$0$	$+$
$f (x)$	$\nearrow$	$a$	$\searrow$	$- 12 + a$	$\nearrow$

이때 함수 $f \left( x \right)$는 $x = 0$일 때 극댓값 $20$을 가지므로
$f \left( 0 \right) = a = 20$
따라서 함수 $f \left( x \right)$의 극솟값은
$f \left( 2 \right) = - 12 + a = - 12 + 20 = 8$

### 생성 풀이 전체

함수 $f(x) = 3x^3 - 9x^2 + a$의 극값을 구하기 위해 먼저 도함수를 구합니다.
$f'(x) = 9x^2 - 18x$

극값을 갖는 지점을 찾기 위해 $f'(x) = 0$으로 놓으면,
$9x(x - 2) = 0$
$x = 0$ 또는 $x = 2$

함수 $f(x)$는 삼차항의 계수가 양수이므로 $x=0$에서 극댓값을 갖고, $x=2$에서 극솟값을 갖습니다.

1. **극댓값 구하기:**
$x=0$일 때의 함숫값이 극댓값이므로,
$f(0) = 3(0)^3 - 9(0)^2 + a = a$
문제에서 극댓값이 $20$이라고 하였으므로, $a = 20$입니다.

2. **극솟값 구하기:**
$x=2$일 때의 함숫값이 극솟값이므로,
$f(2) = 3(2)^3 - 9(2)^2 + a$
$f(2) = 3(8) - 9(4) + a$
$f(2) = 24 - 36 + a$
$f(2) = -12 + a$

위에서 구한 $a=20$을 대입하면,
$f(2) = -12 + 20 = 8$

따라서 함수 $f(x)$의 극솟값은 $8$입니다.
