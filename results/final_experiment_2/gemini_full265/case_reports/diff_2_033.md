### 생성 풀이 전체

함수 $f(x) = x^3 - 3x^2 - 9x + k$의 극값을 구하기 위해 도함수를 구하면 다음과 같습니다.
$f'(x) = 3x^2 - 6x - 9$

극값을 갖는 $x$의 값을 찾기 위해 $f'(x) = 0$으로 놓으면,
$3(x^2 - 2x - 3) = 0$
$3(x - 3)(x + 1) = 0$
따라서 $x = -1$ 또는 $x = 3$에서 극값을 갖습니다.

함수 $f(x)$는 삼차항의 계수가 양수이므로 $x = -1$에서 극대이고, $x = 3$에서 극소입니다.

문제에서 극솟값이 $-17$이라고 하였으므로, $f(3) = -17$을 이용하여 상수 $k$의 값을 구합니다.
$f(3) = 3^3 - 3(3^2) - 9(3) + k = -17$
$27 - 27 - 27 + k = -17$
$-27 + k = -17$
$k = 10$

이제 $k = 10$을 대입하여 함수 $f(x) = x^3 - 3x^2 - 9x + 10$의 극댓값을 구합니다. 극댓값은 $x = -1$일 때의 함숫값입니다.
$f(-1) = (-1)^3 - 3(-1)^2 - 9(-1) + 10$
$f(-1) = -1 - 3 + 9 + 10$
$f(-1) = 15$

따라서 함수 $f(x)$의 극댓값은 $15$입니다.
