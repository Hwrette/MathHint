## 원본 문제와 선택지

$\pi < \theta < \frac{3}{2} \pi$인 $\theta$에 대하여 $\tan \left( \pi - \theta \right) = - 2$일 때, $\cos \theta - \sin \theta$의 값은?
① $- \frac{\sqrt{5}}{5}$	② $- \frac{\sqrt{5}}{10}$	③ $0$
④ $\frac{\sqrt{5}}{10}$	⑤ $\frac{\sqrt{5}}{5}$

## 원본 해설 전체

[정답] ⑤

[해설]
$\tan \left( \pi - \theta \right) = - \tan \theta = - 2$에서 $\tan \theta = 2$
$\frac{\sin \theta}{\cos \theta} = 2$에서 $\sin \theta = 2 \cos \theta$
$\sin^{2} \theta + \cos^{2} \theta = 1$에서
$4 \cos^{2} \theta + \cos^{2} \theta = 1$, $\cos^{2} \theta = \frac{1}{5}$
$\pi < \theta < \frac{3}{2} \pi$이므로 $\cos \theta < 0$, $\sin \theta < 0$
$\cos \theta = - \frac{\sqrt{5}}{5}$이므로 $\sin \theta = 2 \cos \theta = - \frac{2 \sqrt{5}}{5}$
따라서 $\cos \theta - \sin \theta = - \frac{\sqrt{5}}{5} - \left( - \frac{2 \sqrt{5}}{5} \right) = \frac{\sqrt{5}}{5}$

### 생성 풀이 전체

주어진 조건과 삼각함수의 성질을 이용하여 문제를 해결합니다.

**1. $\tan(\pi - \theta)$의 값 정리**
삼각함수의 성질에 의해 $\tan(\pi - \theta) = -\tan \theta$입니다.
문제에서 $\tan(\pi - \theta) = -2$라고 하였으므로,
$-\tan \theta = -2$에서 **$\tan \theta = 2$**임을 알 수 있습니다.

**2. $\sin \theta$와 $\cos \theta$의 값 구하기**
$\tan \theta = \frac{\sin \theta}{\cos \theta} = 2$이므로 $\sin \theta = 2\cos \theta$입니다.
또한, $\sin^2 \theta + \cos^2 \theta = 1$에 대입하면:
$(2\cos \theta)^2 + \cos^2 \theta = 1$
$4\cos^2 \theta + \cos^2 \theta = 1$
$5\cos^2 \theta = 1$
$\cos^2 \theta = \frac{1}{5}$

조건에서 $\pi < \theta < \frac{3}{2} \pi$ (제3사분면)이므로, $\sin \theta$와 $\cos \theta$는 모두 음수입니다.
따라서,
$\cos \theta = -\frac{1}{\sqrt{5}} = -\frac{\sqrt{5}}{5}$
$\sin \theta = 2\cos \theta = -\frac{2\sqrt{5}}{5}$

**3. $\cos \theta - \sin \theta$ 계산**
$\cos \theta - \sin \theta = \left( -\frac{\sqrt{5}}{5} \right) - \left( -\frac{2\sqrt{5}}{5} \right)$
$= -\frac{\sqrt{5}}{5} + \frac{2\sqrt{5}}{5}$
$= \frac{\sqrt{5}}{5}$

따라서 정답은 ⑤번입니다.

최종정답: ⑤
