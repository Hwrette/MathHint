## 원본 문제와 선택지

$f \left( x \right) = 2 x^{3} - 3 a x^{2} - 12 a^{2} x$
라 하자. 함수 $f \left( x \right)$의 극댓값이 $\frac{7}{27}$일 때, $f \left( 3 \right)$의 값을 구하시오.

## 원본 해설 전체

[정답] $41$

[해설]
양수 $a$에 대하여 함수 $f \left( x \right)$를
$f \left( x \right) = 2 x^{3} - 3 a x^{2} - 12 a^{2} x$
라 하면
$f' \left( x \right) = 6 x^{2} - 6 a x - 12 a^{2}$
$f' \left( x \right) = 0$에서    $6 \left( x - 2 a \right) \left( x + a \right) = 0$
$x = - a$ 또는 $x = 2 a$
함수 $f \left( x \right)$의 증가와 감소를 표로 나타내면 다음과 같다.

$x$	$\cdots$	$- a$	$\cdots$	$2 a$	$\cdots$
$f' \left( x \right)$	$+$	$0$	$-$	$0$	$+$
$f \left( x \right)$	$\nearrow$	극대	$\searrow$	극소	$\nearrow$

함수 $f \left( x \right)$의 극댓값이 $\frac{7}{27}$이므로
$f \left( - a \right) = - 2 a^{3} - 3 a^{3} + 12 a^{3} = 7 a^{3}$
에서    $7 a^{3} = \frac{7}{27}$    $\therefore$ $a = \frac{1}{3}$
$f \left( x \right) = 2 x^{3} - x^{2} - \frac{4}{3} x$에서
$f \left( 3 \right) = 2 \times 3^{3} - 3^{2} - 4 = 41$

### 생성 풀이 전체

함수 $f(x) = 2x^3 - 3ax^2 - 12a^2x$의 극값을 구하기 위해 도함수를 구하면 다음과 같습니다.
$f'(x) = 6x^2 - 6ax - 12a^2$

극값을 갖는 지점은 $f'(x) = 0$인 곳이므로,
$6(x^2 - ax - 2a^2) = 0$
$6(x - 2a)(x + a) = 0$
따라서 $x = 2a$ 또는 $x = -a$에서 극값을 갖습니다.

함수 $f(x)$의 최고차항의 계수가 양수이므로, $x = -a$에서 극댓값을 갖고 $x = 2a$에서 극솟값을 갖습니다.
문제에서 극댓값이 $\frac{7}{27}$이라고 하였으므로, $f(-a) = \frac{7}{27}$입니다.

$f(-a) = 2(-a)^3 - 3a(-a)^2 - 12a^2(-a)$
$f(-a) = -2a^3 - 3a^3 + 12a^3 = 7a^3$

따라서 $7a^3 = \frac{7}{27}$이 되어, $a^3 = \frac{1}{27}$입니다.
$a$는 양수이므로 $a = \frac{1}{3}$입니다.

이제 $f(x)$를 다시 쓰면,
$f(x) = 2x^3 - 3(\frac{1}{3})x^2 - 12(\frac{1}{3})^2x$
$f(x) = 2x^3 - x^2 - \frac{4}{3}x$

$f(3)$의 값을 구하면,
$f(3) = 2(3)^3 - (3)^2 - \frac{4}{3}(3)$
$f(3) = 2(27) - 9 - 4$
$f(3) = 54 - 13 = 41$

최종정답: 41
