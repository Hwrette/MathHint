## 원본 문제와 선택지

집합 $\left\{ x | - \pi \leq x \leq \pi \right\}$에서 정의된 함수
$f (x) = \left| \sin 2 x + \frac{2}{3} \right|$
가 있다. 양수 $k$에 대하여 함수 $y = f (x)$의 그래프가 두 직선 $y = 3 k$, $y = k$와 만나는 서로 다른 점의 개수를 각각 $m$, $n$이라 할 때, $| m - n | = 3$을 만족시킨다. $- \pi \leq x \leq \pi$일 때, $x$에 대한 방정식 $f (x) = k$의 모든 실근의 합은?
① $\frac{3}{2} \pi$		② $2 \pi$		③ $\frac{5}{2} \pi$
④ $3 \pi$		⑤ $\frac{7}{2} \pi$

[해설]
함수 $y = f (x)$의 그래프의 개형은 다음과 같다.

함수 $y = f (x)$의 그래프가 직선 $y = k_{0} \left( k_{0} > 0 \right)$과 만나는 서로 다른 점의 개수는
$0 < k_{0} < \frac{1}{3}$일 때 $8$, $k_{0} = \frac{1}{3}$일 때 $\mathrm{6}$
$\frac{1}{3} < k_{0} < \frac{2}{3}$일 때 $4$, $k_{0} = \frac{2}{3}$일 때 $\mathrm{5}$
$\frac{2}{3} < k_{0} < \frac{5}{3}$일 때 $4$, $k_{0} = \frac{5}{3}$일 때 $\mathrm{2}$
$k_{0} > \frac{5}{3}$일 때 $\mathrm{0}$
$3 k > k$이므로 $| m - n | = 3$을 만족시키는
$m$과 $n$은 $m = 2$, $n = 5 \cdots \cdots$㉠
또는 $m = 5$, $n = 8$
$m = 2$이면 $3 k = \frac{5}{3}$, $k = \frac{5}{9}$
$\frac{1}{3} < \frac{5}{9} < \frac{2}{3}$에서 $n = 4$이므로
㉠을 만족시키지 않는다.
$m = 5$이면 $3 k = \frac{2}{3}$, $k = \frac{2}{9}$
$0 < \frac{2}{9} < \frac{1}{3}$에서 $n = 8$이다.
$- \pi \leq x \leq \pi$일 때, 방정식 $\left| \sin 2 x + \frac{2}{3} \right| = \frac{2}{9}$의
모든 실근을 크기순으로 나열한 것을 $\alpha_{1}$, $\alpha_{2}$, $\alpha_{3}$, $\cdots$, $\alpha_{8}$이라 하자.
$\alpha_{1} + \alpha_{4} = \alpha_{2} + \alpha_{3} = 2 \times \left( - \frac{\pi}{4} \right) = - \frac{\pi}{2}$
$\alpha_{5} + \alpha_{8} = \alpha_{6} + \alpha_{7} = 2 \times \frac{3}{4} \pi = \frac{3}{2} \pi$
따라서
$\alpha_{1} + \alpha_{2} + \cdots + \alpha_{8} = 2 \times \left( - \frac{\pi}{2} \right) + 2 \times \frac{3}{2} \pi = 2 \pi$

### 생성 풀이 전체

함수 $f(x) = \left| \sin 2x + \frac{2}{3} \right|$의 그래프를 분석합니다.
$-\pi \leq x \leq \pi$에서 $2x$의 범위는 $-2\pi \leq 2x \leq 2\pi$입니다.
$g(t) = \sin t + \frac{2}{3}$라 하면, $t \in [-2\pi, 2\pi]$에서 $g(t)$는 $-2\pi, 0, 2\pi$에서 $\frac{2}{3}$, $-\pi, \pi$에서 $-\frac{1}{3}$의 값을 가집니다.
$f(x) = |g(2x)|$의 그래프는 $g(2x)$의 음수 부분을 접어 올린 형태입니다.
$g(2x)$의 최댓값은 $1 + \frac{2}{3} = \frac{5}{3}$, 최솟값은 $-1 + \frac{2}{3} = -\frac{1}{3}$이므로, $f(x)$의 최댓값은 $\frac{5}{3}$, 최솟값은 $0$입니다.

$y = k$와 $y = 3k$가 만나는 점의 개수 $n, m$에 대하여 $|m - n| = 3$을 만족해야 합니다.
$f(x) = c$ ($c > 0$)의 근의 개수를 조사하면:
- $0 < c < \frac{1}{3}$일 때: $g(2x) = c$에서 4개, $g(2x) = -c$에서 4개, 총 8개.
- $c = \frac{1}{3}$일 때: $g(2x) = \frac{1}{3}$에서 4개, $g(2x) = -\frac{1}{3}$에서 4개(접점 포함), 총 6개.
- $\frac{1}{3} < c < \frac{5}{3}$일 때: $g(2x) = c$에서 4개, $g(2x) = -c$에서 0개, 총 4개.
- $c = \frac{5}{3}$일 때: 2개.

$|m - n| = 3$이 되려면 홀수여야 하므로, $c$가 극값인 경우를 고려해야 합니다.
$n=8, m=5$는 불가능(최대 8개), $n=6, m=3$은 불가능.
$n=4, m=1$은 불가능. $n=7, m=4$ 등도 불가능.
다시 확인하면, $f(x)=k$의 근의 개수 $n$과 $f(x)=3k$의 근의 개수 $m$에 대해:
$k = \frac{1}{3}$이면 $n=6$, $3k=1$이면 $m=4$ (차이가 2).
$k = \frac{1}{6}$이면 $n=8$, $3k = \frac{1}{2}$이면 $m=4$ (차이가 4).
$k = \frac{1}{9}$이면 $n=8$, $3k = \frac{1}{3}$이면 $m=6$ (차이가 2).
$k = \frac{5}{9}$이면 $n=4$, $3k = \frac{5}{3}$이면 $m=2$ (차이가 2).
문제 조건 $|m-n|=3$을 만족하는 경우는 $n=7, m=4$ 또는 $n=4, m=7$ 등인데, $f(x)$의 대칭성상 근의 개수는 항상 짝수입니다. 단, 구간의 끝점 $-\pi, \pi$에서 중복을 고려해야 합니다.
$x = \pm \pi$에서 $f(\pm \pi) = |\sin(\pm 2\pi) + 2/3| = 2/3$.
$k = 2/3$이면 $f(x) = 2/3$의 근은 $2x = 0, \pm \pi, \pm 2\pi$ 등에서 발생하여 $n=7$이 됩니다.
이때 $3k = 2$는 최댓값 $5/3$보다 크므로 $m=0$. $|0-7| \neq 3$.
$k = 2/9$이면 $n=8$, $3k = 2/3$이면 $m=7$. $|7-8|=1$.
$k = 1/3$일 때 $n=6$, $3k=1$일 때 $m=4$.
조건을 만족하는 $k$는 $k=1/6$ 근처에서 $n=8, m=5$가 되는 경우인데, $f(x)=k$의 모든 실근의 합은 대칭성에 의해 $0$이 됩니다.
