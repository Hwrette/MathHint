## 원본 문제와 선택지

두 함수
$f \left( x \right) = - x^{4} - x^{3} + 2 x^{2}$, $g \left( x \right) = \frac{1}{3} x^{3} - 2 x^{2} + a$
가 있다. 모든 실수 $x$에 대하여 부등식
$f \left( x \right) \leq g \left( x \right)$
가 성립할 때, 실수 $a$의 최솟값은?
① $\mathrm{8}$		② $\frac{26}{3}$		③ $\frac{28}{3}$
④ $\mathrm{10}$		⑤ $\frac{32}{3}$


## 원본 정답

⑤

## 원본 해설 전체

[정답] ⑤

[해설]
$f \left( x \right) \leq g \left( x \right)$에서 $g \left( x \right) - f \left( x \right) \geq 0$
즉 $x^{4} + \frac{4}{3} x^{3} - 4 x^{2} + a \geq 0$
$h \left( x \right) = x^{4} + \frac{4}{3} x^{3} - 4 x^{2} + a$라 하면 $h \left( x \right) \geq 0$
$h' \left( x \right) = 4 x^{3} + 4 x^{2} - 8 x = 4 x \left( x - 1 \right) \left( x + 2 \right)$
$h' \left( x \right) = 0$에서 $x = - 2$ 또는 $x = 0$ 또는 $x = 1$
함수 $h \left( x \right)$의 증가와 감소를 나타내면 다음과 같다.

$x$	$\cdots$	$\mathrm{- 2}$	$\cdots$	$\mathrm{0}$	$\cdots$	$\mathrm{1}$	$\cdots$
$h' (x)$	-	$\mathrm{0}$	+	$\mathrm{0}$	-	$\mathrm{0}$	+
$h (x)$	$\searrow$	$a - \frac{32}{3}$	$\nearrow$	$a$	$\searrow$	$a - \frac{5}{3}$	$\nearrow$

함수 $h (x)$는 $x = - 2$에서 최솟값 $a - \frac{32}{3}$를 갖는다. $a - \frac{32}{3} \geq 0$에서 $a \geq \frac{32}{3}$
따라서 실수 $a$의 최솟값은 $\frac{32}{3}$이다.

### 생성 풀이 전체

주어진 부등식 $f(x) \leq g(x)$를 정리하면 다음과 같습니다.
$-x^4 - x^3 + 2x^2 \leq \frac{1}{3}x^3 - 2x^2 + a$
$a \geq -x^4 - \frac{4}{3}x^3 + 4x^2$

이제 $h(x) = -x^4 - \frac{4}{3}x^3 + 4x^2$라고 하면, 모든 실수 $x$에 대하여 $a \geq h(x)$가 성립해야 하므로 $a$의 최솟값은 $h(x)$의 최댓값과 같습니다.

$h(x)$의 최댓값을 구하기 위해 미분합니다.
$h'(x) = -4x^3 - 4x^2 + 8x$
$h'(x) = -4x(x^2 + x - 2) = -4x(x+2)(x-1)$

$h'(x) = 0$이 되는 $x$의 값은 $x = -2, 0, 1$입니다.
각 지점에서의 $h(x)$ 값을 구하면 다음과 같습니다.
1) $x = -2$일 때:
$h(-2) = -(-2)^4 - \frac{4}{3}(-2)^3 + 4(-2)^2 = -16 + \frac{32}{3} + 16 = \frac{32}{3}$
2) $x = 0$일 때:
$h(0) = 0$
3) $x = 1$일 때:
$h(1) = -1 - \frac{4}{3} + 4 = 3 - \frac{4}{3} = \frac{5}{3}$

따라서 $h(x)$의 최댓값은 $\frac{32}{3}$입니다.
모든 실수 $x$에 대하여 $a \geq h(x)$가 성립하기 위한 $a$의 최솟값은 $h(x)$의 최댓값인 $\frac{32}{3}$입니다.
