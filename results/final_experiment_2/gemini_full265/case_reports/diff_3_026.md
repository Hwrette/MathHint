## 원본 문제와 선택지

최고차항의 계수가 $\mathrm{1}$인 삼차함수 $f (x)$가 다음 조건을 만족시킨다.

방정식 $f (x) = 9$는 서로 다른 세 실근을 갖고,
이 세 실근은 크기 순서대로 등비수열을 이룬다.

$f (0) = 1$, $f' (2) = - 2$일 때, $f (3)$의 값은?
① $\mathrm{6}$		② $\mathrm{7}$		③ $\mathrm{8}$
④ $\mathrm{9}$		⑤ $\mathrm{10}$

## 원본 해설 전체

[정답] ②

[해설]
세 실근을 $a$, $a r$, $a r^{2}$이라 하면
$f (x)$$= (x - a) (x - a r) (x - a r^{2}) + 9$
$=$$x^{3} - a (1 + r + r^{2}) x^{2} + a^{2} r (1 + r + r^{2}) x - (a r)^{3} + 9$
$f' (x) =$$3 x^{2} - 2 a (1 + r + r^{2}) x + a^{2} r (1 + r + r^{2})$
$f (0) = - (a r)^{3} + 9 = 1$
$f' (2)$$= 12 - 4 a (1 + r + r^{2}) + a^{2} r (1 + r + r^{2})$
$= - 2$
$a r = 2$, $a (1 + r + r^{2}) = 7$
$\therefore$$f (3) = 27 - 63 + 42 + 1$$= 7$

### 생성 풀이 전체

삼차함수 $f(x)$의 최고차항의 계수가 1이므로, $f(x) - 9 = (x-a)(x-ar)(x-ar^2)$이라 할 수 있습니다. (단, $a$는 첫째항, $r$은 공비, $r>1$ 또는 $0<r<1$인 실수)
$f(x) = (x-a)(x-ar)(x-ar^2) + 9$

$f(0) = 1$이므로,
$f(0) = (-a)(-ar)(-ar^2) + 9 = -a^3 r^3 + 9 = 1$
$a^3 r^3 = 8 \implies ar = 2$
따라서 $a = \frac{2}{r}$이고, 세 근은 $\frac{2}{r}, 2, 2r$입니다.

$f(x) = (x - \frac{2}{r})(x - 2)(x - 2r) + 9$
이를 전개하면,
$f(x) = (x-2)(x^2 - 2(r + \frac{1}{r})x + 4) + 9$
$f'(x) = (x^2 - 2(r + \frac{1}{r})x + 4) + (x-2)(2x - 2(r + \frac{1}{r}))$

$f'(2) = -2$를 대입하면,
$f'(2) = 4 - 4(r + \frac{1}{r}) + 4 + 0 = -2$
$8 - 4(r + \frac{1}{r}) = -2$
$4(r + \frac{1}{r}) = 10 \implies r + \frac{1}{r} = \frac{5}{2}$
$2r^2 - 5r + 2 = 0 \implies (2r-1)(r-2) = 0$
$r=2$ 또는 $r=\frac{1}{2}$입니다. 두 경우 모두 세 근은 $\{1, 2, 4\}$로 동일합니다.

이제 $f(3)$을 구합니다.
$f(x) = (x-1)(x-2)(x-4) + 9$
$f(3) = (3-1)(3-2)(3-4) + 9$
$f(3) = (2)(1)(-1) + 9 = -2 + 9 = 7$

### 생성 풀이 전체

삼차함수 $f(x)$의 최고차항의 계수가 1이므로 $f(x) = x^3 + ax^2 + bx + c$라 할 수 있습니다.
$f(0) = 1$이므로 $c = 1$입니다. 따라서 $f(x) = x^3 + ax^2 + bx + 1$입니다.

방정식 $f(x) = 9$는 $x^3 + ax^2 + bx - 8 = 0$과 같습니다.
이 방정식의 세 실근을 $p/r, p, pr$ ($r > 1$)이라 하면, 근과 계수의 관계에 의해
1) $(p/r) \cdot p \cdot (pr) = p^3 = 8 \implies p = 2$
2) $(p/r)p + p(pr) + (pr)(p/r) = p^2/r + p^2r + p^2 = -b$
   $4/r + 4r + 4 = -b \implies b = -4(r + 1/r + 1)$
3) $(p/r) + p + (pr) = -a$
   $2/r + 2 + 2r = -a \implies a = -2(r + 1/r + 1)$

이제 $f'(x) = 3x^2 + 2ax + b$를 이용합니다.
$f'(2) = 3(2)^2 + 2a(2) + b = 12 + 4a + b = -2$
$4a + b = -14$

위에서 구한 $a, b$를 대입하면:
$4[-2(r + 1/r + 1)] + [-4(r + 1/r + 1)] = -14$
$-8(r + 1/r + 1) - 4(r + 1/r + 1) = -14$
$-12(r + 1/r + 1) = -14$
$r + 1/r + 1 = 14/12 = 7/6$
$r + 1/r = 7/6 - 1 = 1/6$
그런데 $r > 1$이면 $r + 1/r > 2$이어야 하므로, 위 식은 모순이 발생합니다.

다시 확인하면, $f(x) - 9 = (x - p/r)(x - p)(x - pr) = x^3 - (p/r + p + pr)x^2 + (p^2/r + p^2r + p^2)x - p^3 = 0$
$p^3 = 8 \implies p = 2$
$a = -(2/r + 2 + 2r)$, $b = 4/r + 4 + 4r$
$f'(2) = 12 + 4a + b = 12 + 4(-2/r - 2 - 2r) + (4/r + 4 + 4r) = -2$
$12 - 8/r - 8 - 8r + 4/r + 4 + 4r = -2$
$8 - 4/r - 4r = -2 \implies 4(r + 1/r) = 10 \implies r + 1/r = 2.5 = 5/2$
$a = -2(5/2 + 1) = -7$, $b = 4(5/2 + 1) = 14$

따라서 $f(x) = x^3 - 7x^2 + 14x + 1$입니다.
$f(3) = 3^3 - 7(3^2) + 14(3) + 1 = 27 - 63 + 42 + 1 = 7$
