## 원본 문제와 선택지

최고차항의 계수가 $\mathrm{1}$인 삼차함수 $f (x)$가 다음 조건을 만족시킨다.

방정식 $f (x) = 9$는 서로 다른 세 실근을 갖고,
이 세 실근은 크기 순서대로 등비수열을 이룬다.

$f (0) = 1$, $f' (2) = - 2$일 때, $f (3)$의 값은?
① $\mathrm{6}$		② $\mathrm{7}$		③ $\mathrm{8}$
④ $\mathrm{9}$		⑤ $\mathrm{10}$


## 원본 정답

②

## 원본 해설 전체

[정답] ②

[해설]
세 실근을 $a$, $a r$, $a r^{2}$이라 하면
$f (x)$$= (x - a) (x - a r) (x - a r^{2}) + 9$
$=$$x^{3} - a (1 + r + r^{2}) x^{2} + a^{2} r (1 + r + r^{2}) x - (a r)^{3} + 9$
$f' (x) =$$3 x^{2} - 2 a (1 + r + r^{2}) x + a^{2} r (1 + r + r^{2})$
$f (0) = - (a r)^{3} + 9 = 1$
$f' (2)$$= 12 - 4 a (1 + r + r^{2}) + a^{2} r (1 + r + r^{2})$
$= - 2$
$a r = 2$, $a (1 + r + r^{2}) = 7$
$\therefore$$f (3) = 27 - 63 + 42 + 1$$= 7$
