[해설]
함수 $g \left( x \right)$$= \left| \sin 3 x \right|$의 그래프는 다음과 같다.

함수 $g \left( x \right)$의 주기는 $\frac{\pi}{3}$
함수 $f \left( x \right)$의 주기는 $\frac{2 \pi}{\left| a \right|}$
두 함수 $f \left( x \right)$, $g \left( x \right)$의 주기가 서로 같으므로 $\frac{2 \pi}{\left| a \right|}$$= \frac{\pi}{3}$
$a$는 양수이므로 $a = 6$

### 생성 풀이 전체

함수 $f(x) = \cos(ax) + 1$의 주기와 $g(x) = |\sin 3x|$의 주기를 각각 구하여 비교합니다.

1. **함수 $g(x) = |\sin 3x|$의 주기 구하기:**
   함수 $y = \sin(bx)$의 주기는 $\frac{2\pi}{|b|}$입니다.
   함수 $y = \sin(3x)$의 주기는 $\frac{2\pi}{3}$입니다.
   절댓값이 취해진 함수 $y = |\sin(3x)|$는 원래 함수가 $x$축 아래에 있던 부분이 위로 꺾여 올라가므로 주기가 절반으로 줄어듭니다.
   따라서 $g(x)$의 주기는 $\frac{1}{2} \times \frac{2\pi}{3} = \frac{\pi}{3}$입니다.

2. **함수 $f(x) = \cos(ax) + 1$의 주기 구하기:**
   함수 $y = \cos(ax)$의 주기는 $\frac{2\pi}{|a|}$입니다.
   상수항 $+1$은 그래프를 평행이동시킨 것이므로 주기에 영향을 주지 않습니다.
   따라서 $f(x)$의 주기는 $\frac{2\pi}{a}$입니다. (문제에서 $a$는 양수이므로 $|a|=a$)

3. **두 함수의 주기가 같다는 조건 이용하기:**
   두 함수의 주기가 같으므로 다음 식이 성립합니다.
   $$\frac{2\pi}{a} = \frac{\pi}{3}$$
   양변을 $\pi$로 나누면:
   $$\frac{2}{a} = \frac{1}{3}$$
   따라서 $a = 6$입니다.
