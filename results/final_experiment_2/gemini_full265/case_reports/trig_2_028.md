## 원본 문제와 선택지

양수 $a$에 대하여 함수
$f (x) = \left| 4 \sin \left( a x - \frac{\pi}{3} \right) + 2 \right| \left( 0 \leq x < \frac{4 \pi}{a} \right)$
의 그래프가 직선 $y = 2$와 만나는 서로 다른 점의 개수는 $n$이다. 이 $n$개의 점의 $x$좌표의 합이 $\mathrm{39}$일 때, $n \times a$의 값은?
① $\frac{\pi}{2}$		② $\pi$		③ $\frac{3 \pi}{2}$
④ $2 \pi$		⑤ $\frac{5 \pi}{2}$

[해설]
함수 $y = f (x)$의 그래프가 직선 $y = 2$와 만나는 점의 $x$좌표는 $0 \leq x < \frac{4 \pi}{a}$일 때 방정식 $\left| 4 \sin \left( a x - \frac{\pi}{3} \right) + 2 \right| = 2 \quad$	$\cdots \cdots$ ㉠
의 실근과 같다.
$a x - \frac{\pi}{3} = t$라 하면 $- \frac{\pi}{3} \leq t < \frac{11 \pi}{3}$이고
$| 4 \sin t + 2 | = 2 \quad$					$\cdots \cdots$ ㉡
에서 $\sin t = 0$ 또는 $\sin t = - 1$
$- \frac{\pi}{3} \leq t < \frac{11 \pi}{3}$일 때, 방정식 ㉡의 실근은
$0$, $\pi$, $\frac{3 \pi}{2}$, $2 \pi$, $3 \pi$, $\frac{7 \pi}{2}$
의 $\mathrm{6}$개이고 이 $\mathrm{6}$개의 실근의 합은 $11 \pi$이다.
따라서 $n = 6$이고 방정식 ㉠의 $\mathrm{6}$개의 실근의 합이 $\mathrm{39}$이므로
$39 a - \frac{\pi}{3} \times 6 = 11 \pi$, $a = \frac{\pi}{3}$
따라서 $n \times a = 6 \times \frac{\pi}{3} = 2 \pi$

### 생성 풀이 전체

함수 $f(x) = \left| 4 \sin \left( ax - \frac{\pi}{3} \right) + 2 \right|$의 그래프와 직선 $y=2$가 만나는 점은 다음 방정식을 만족합니다.
$$\left| 4 \sin \left( ax - \frac{\pi}{3} \right) + 2 \right| = 2$$
이는 $4 \sin \left( ax - \frac{\pi}{3} \right) + 2 = 2$ 또는 $4 \sin \left( ax - \frac{\pi}{3} \right) + 2 = -2$를 의미합니다.

**1) $4 \sin \left( ax - \frac{\pi}{3} \right) + 2 = 2$인 경우:**
$\sin \left( ax - \frac{\pi}{3} \right) = 0$
$ax - \frac{\pi}{3} = k\pi$ ($k$는 정수)
$ax = k\pi + \frac{\pi}{3} \implies x = \frac{k\pi}{a} + \frac{\pi}{3a}$
범위 $0 \leq x < \frac{4\pi}{a}$에서 $k=0, 1, 2, 3$이 가능합니다.
$x_1 = \frac{\pi}{3a}, x_2 = \frac{4\pi}{3a}, x_3 = \frac{7\pi}{3a}, x_4 = \frac{10\pi}{3a}$ (4개)

**2) $4 \sin \left( ax - \frac{\pi}{3} \right) + 2 = -2$인 경우:**
$\sin \left( ax - \frac{\pi}{3} \right) = -1$
$ax - \frac{\pi}{3} = 2m\pi - \frac{\pi}{2}$ ($m$은 정수)
$ax = 2m\pi - \frac{\pi}{6} \implies x = \frac{2m\pi}{a} - \frac{\pi}{6a}$
범위 $0 \leq x < \frac{4\pi}{a}$에서 $m=1, 2$가 가능합니다.
$x_5 = \frac{11\pi}{6a}, x_6 = \frac{23\pi}{6a}$ (2개)

따라서 $n = 4 + 2 = 6$입니다.
이 6개 점의 $x$좌표의 합은:
$\sum x = \left( \frac{\pi + 4\pi + 7\pi + 10\pi}{3a} \right) + \left( \frac{11\pi + 23\pi}{6a} \right)$
$= \frac{22\pi}{3a} + \frac{34\pi}{6a} = \frac{44\pi + 34\pi}{6a} = \frac{78\pi}{6a} = \frac{13\pi}{a}$

문제에서 합이 $39$라고 하였으므로:
$\frac{13\pi}{a} = 39 \implies a = \frac{13\pi}{39} = \frac{\pi}{3}$

구하고자 하는 값은 $n \times a$이므로:
$n \times a = 6 \times \frac{\pi}{3} = 2\pi$
