## 원본 문제와 선택지

함수
$f \left( x \right) = \left| x^{3} - 3 x^{2} + p \right|$
는 $x = a$와 $x = b$에서 극대이다. $f \left( a \right) = f \left( b \right)$일 때, 실수 $p$의 값은? (단, $a$, $b$는 $a \ne b$인 상수이다.)
① $\frac{3}{2}$		② $2$		③ $\frac{5}{2}$
④ $3$		⑤ $\frac{7}{2}$


## 원본 정답

②

## 원본 해설 전체

[정답] ②

[해설]
$g \left( x \right) = x^{3} - 3 x^{2} + p$라 하면 $f \left( x \right) = \left| g \left( x \right) \right|$
$g' \left( x \right) = 3 x^{2} - 6 x = 3 x \left( x - 2 \right)$
$g' (x) = 0$에서 $x = 0$ 또는 $x = 2$
$g (x)$의 증가와 감소를 표로 나타내면 다음과 같다.

$x$	$\cdots$	$\mathrm{0}$	$\cdots$	$\mathrm{2}$	$\cdots$
$g' (x)$	+	$\mathrm{0}$	-	$\mathrm{0}$	+
$g (x)$	$\nearrow$	극대	$\searrow$	극소	$\nearrow$

따라서 함수 $f \left( x \right) = \left| g \left( x \right) \right|$가 극대가 되는 $x$가
$\mathrm{2}$개가 되려면
$g \left( 0 \right) = p > 0$, $g \left( 2 \right) = p - 4 < 0$ 즉, $0 < p < 4$
$f \left( 0 \right) = \left| p \right| = p$, $f \left( 2 \right) = \left| p - 4 \right| = 4 - p$
$f \left( 0 \right) = f \left( 2 \right)$이므로 $p = 4 - p$ 즉, $p = 2$

### 생성 풀이 전체

함수 $f(x) = |x^3 - 3x^2 + p|$가 $x=a$와 $x=b$에서 극대값을 가지려면, 내부 함수 $g(x) = x^3 - 3x^2 + p$가 $x$축과 서로 다른 세 점에서 만나야 합니다.

먼저 $g(x) = x^3 - 3x^2 + p$의 극값을 구하기 위해 미분하면,
$g'(x) = 3x^2 - 6x = 3x(x-2)$
$g'(x) = 0$에서 $x=0$ 또는 $x=2$입니다.

$x=0$일 때 극댓값은 $g(0) = p$이고,
$x=2$일 때 극솟값은 $g(2) = 8 - 12 + p = p - 4$입니다.

함수 $f(x) = |g(x)|$가 극대값을 갖는 경우는 $g(x)$가 $x$축을 통과하여 부호가 바뀌는 지점(절댓값에 의해 꺾이는 지점)이거나, 원래 $g(x)$의 극대점입니다.
$f(x)$가 $x=a, b$에서 극대값을 갖고 $f(a) = f(b)$가 성립하려면, $g(x)$의 극대점과 극솟값의 절댓값이 같아야 합니다.

즉, $g(0) = |g(2)|$ 또는 $g(0) = -g(2)$가 성립해야 합니다.
1) $g(0) = -g(2)$인 경우:
$p = -(p - 4)$
$p = -p + 4$
$2p = 4$
$p = 2$

이때 $g(x) = x^3 - 3x^2 + 2$가 되며, $g(0)=2, g(2)=-2$입니다.
$f(x) = |x^3 - 3x^2 + 2|$는 $x=0$에서 극대값 $|2|=2$, $x=2$에서 극대값 $|-2|=2$를 가집니다.
또한 $g(x)=0$이 되는 지점(절댓값에 의해 꺾이는 지점)에서도 극대값이 발생할 수 있으나, 문제에서 $a, b$ 두 곳에서만 극대라고 하였으므로 $p=2$일 때의 상황을 확인하면 $g(x) = (x-1)(x^2-2x-2) = 0$이 되어 $x=1, 1\pm\sqrt{3}$에서 꺾이게 됩니다.
문제의 조건 $f(a)=f(b)$를 만족하는 극대점은 $x=0$과 $x=2$일 때 $f(0)=f(2)=2$로 성립합니다.

따라서 실수 $p$의 값은 2입니다.

최종정답: ②

### 풀이 검토 상태

`suspected_error` · 사람 확정: `False`

최종 p=2(②)와 g(0)=2,g(2)=−2에서 절댓값 함수의 두 극댓값이 같다는 계산은 맞다. 그러나 g가 x축을 통과하는 꺾임점에서도 |g|의 극대가 생긴다고 주장하고 후반에도 반복해 철회하지 않았다. p=2일 때 x=1은 g의 단순영점(g′(1)=−3)으로 |g(1)|=0이며 주변에서 양수이므로 엄격한 극소이다. 최종답과 별개로 극대·극소 구분에 구체적인 오류가 있다.
