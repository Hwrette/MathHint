## 원본 문제와 선택지

실수 $k$에 대하여 함수
$f \left( x \right) = 2 \cos^{2} x + 2 \sin x + k$
의 최댓값이 $\frac{15}{2}$일 때, 함수 $f (x)$의 최솟값은?
① $\mathrm{1}$		② $\mathrm{2}$		③ $\mathrm{3}$
④ $\mathrm{4}$		⑤ $\mathrm{5}$


## 원본 정답

## 원본 해설 전체

[정답] ③

[해설]
$\cos^{2} x = 1 - \sin^{2} x$이므로
$f \left( x \right)$$= 2 \cos^{2} x + 2 \sin x + k$
$= 2 \left( 1 - \sin^{2} x \right) + 2 \sin x + k$
$= - 2 \sin^{2} x + 2 \sin x + 2 + k$
$\sin x = t$라 하면 $- 1 \leq t \leq 1$이고
$y$$= - 2 t^{2} + 2 t + 2 + k$
$= - 2 \left( t^{2} - t + \frac{1}{4} \right) + \frac{5}{2} + k$
$= - 2 \left( t - \frac{1}{2} \right)^{2} + \frac{5}{2} + k$
함수 $y = - 2 \left( t - \frac{1}{2} \right)^{2} + \frac{5}{2} + k$는 $t = \frac{1}{2}$에서 최댓값 $\frac{5}{2} + k$를 갖는다.
따라서 $\frac{5}{2} + k = \frac{15}{2}$, 즉 $k = 5$
그러므로 함수 $y = - 2 t^{2} + 2 t + 7$은 $t = - 1$에서 최솟값 $- 2 \times \left( - 1 \right)^{2} + 2 \times \left( - 1 \right) + 7 = 3$을 갖는다.
즉 $f \left( x \right)$의 최솟값은 $\mathrm{3}$이다.

### 생성 풀이 전체

함수 $f(x) = 2 \cos^2 x + 2 \sin x + k$에서 $\cos^2 x = 1 - \sin^2 x$임을 이용하여 식을 정리합니다.

$f(x) = 2(1 - \sin^2 x) + 2 \sin x + k$
$f(x) = -2 \sin^2 x + 2 \sin x + k + 2$

여기서 $t = \sin x$라고 하면, $-1 \le t \le 1$입니다.
함수를 $t$에 대한 이차함수 $g(t)$로 나타내면 다음과 같습니다.
$g(t) = -2t^2 + 2t + k + 2$

이차함수의 꼭짓점의 $t$ 좌표를 구하면:
$t = -\frac{b}{2a} = -\frac{2}{2(-2)} = \frac{1}{2}$
$t = \frac{1}{2}$은 범위 $-1 \le t \le 1$에 포함되므로, $t = \frac{1}{2}$일 때 최댓값을 갖습니다.

최댓값은 $g\left(\frac{1}{2}\right)$입니다.
$g\left(\frac{1}{2}\right) = -2\left(\frac{1}{4}\right) + 2\left(\frac{1}{2}\right) + k + 2 = -\frac{1}{2} + 1 + k + 2 = k + \frac{5}{2}$

문제에서 최댓값이 $\frac{15}{2}$라고 하였으므로,
$k + \frac{5}{2} = \frac{15}{2}$
$k = \frac{10}{2} = 5$

이제 $k=5$를 대입하여 $g(t) = -2t^2 + 2t + 7$의 최솟값을 구합니다.
$t$의 범위가 $-1 \le t \le 1$이므로, 양 끝점에서의 값을 비교합니다.
$g(-1) = -2(-1)^2 + 2(-1) + 7 = -2 - 2 + 7 = 3$
$g(1) = -2(1)^2 + 2(1) + 7 = -2 + 2 + 7 = 7$

따라서 최솟값은 $3$입니다.

### 생성 풀이 전체

함수 $f(x) = 2 \cos^2 x + 2 \sin x + k$에서 $\cos^2 x = 1 - \sin^2 x$를 대입하면,
$f(x) = 2(1 - \sin^2 x) + 2 \sin x + k$
$f(x) = -2 \sin^2 x + 2 \sin x + k + 2$

여기서 $t = \sin x$라고 하면, $-1 \le t \le 1$이므로
$g(t) = -2t^2 + 2t + k + 2$ ($ -1 \le t \le 1$)로 나타낼 수 있습니다.

$g(t)$를 완전제곱식으로 변형하면,
$g(t) = -2(t^2 - t) + k + 2$
$g(t) = -2(t - \frac{1}{2})^2 + \frac{1}{2} + k + 2$
$g(t) = -2(t - \frac{1}{2})^2 + k + \frac{5}{2}$

이차함수 $g(t)$는 $t = \frac{1}{2}$에서 최댓값을 가지며, 범위 $-1 \le t \le 1$ 안에 포함되므로 최댓값은 $k + \frac{5}{2}$입니다.
문제에서 최댓값이 $\frac{15}{2}$라고 하였으므로,
$k + \frac{5}{2} = \frac{15}{2}$
$k = \frac{10}{2} = 5$

이제 최솟값을 구하기 위해 $t$의 범위 양 끝점에서의 값을 비교합니다.
$g(-1) = -2(-1)^2 + 2(-1) + 5 + 2 = -2 - 2 + 7 = 3$
$g(1) = -2(1)^2 + 2(1) + 5 + 2 = -2 + 2 + 7 = 7$

따라서 최솟값은 $3$입니다.
