[해설]
$0 \leq x \leq 2 \pi$일 때, 방정식 $\sin 2 x = \frac{1}{3}$을 만족시키는 해는 두 함수 $y = \sin 2 x$, $y = \frac{1}{3}$의 그래프의 교점의 $x$좌표와 같다.

네 교점의 $x$좌표 $\alpha$, $\beta$, $\gamma$, $\delta$에 대하여
$\frac{\alpha + \beta}{2} = \frac{\pi}{4}$이고 $\frac{\gamma + \delta}{2} = \frac{5}{4} \pi$이므로
방정식의 모든 해의 합은
$\alpha + \beta + \gamma + \delta = 3 \pi$

### 생성 풀이 전체

방정식 $\sin 2x = \frac{1}{3}$을 풀기 위해 $t = 2x$라고 치환합니다.
주어진 범위가 $0 \leq x \leq 2\pi$이므로, $t$의 범위는 $0 \leq t \leq 4\pi$가 됩니다.

이제 방정식 $\sin t = \frac{1}{3}$을 만족하는 $t$의 값을 구합니다.
$0 \leq t \leq 2\pi$ 범위에서 $\sin t = \frac{1}{3}$을 만족하는 두 근을 $\alpha, \beta$라고 하면, 사인 함수의 대칭성에 의해 $\alpha + \beta = \pi$입니다.

$2\pi \leq t \leq 4\pi$ 범위에서는 $t' = t - 2\pi$라고 하면 $\sin(t' + 2\pi) = \sin t' = \frac{1}{3}$이므로, $t'$ 역시 $\alpha, \beta$가 됩니다.
따라서 이 범위에서의 두 근은 $\alpha + 2\pi, \beta + 2\pi$가 됩니다.

방정식의 모든 근 $t$의 합은 다음과 같습니다.
$t_1 + t_2 + t_3 + t_4 = \alpha + \beta + (\alpha + 2\pi) + (\beta + 2\pi)$
$= (\alpha + \beta) + (\alpha + \beta) + 4\pi$
$= \pi + \pi + 4\pi = 6\pi$

우리는 $t = 2x$라고 치환했으므로, $x = \frac{t}{2}$입니다.
따라서 $x$의 모든 근의 합은 $\frac{t_1 + t_2 + t_3 + t_4}{2}$가 됩니다.
$\frac{6\pi}{2} = 3\pi$

함수 $y = \sin t$의 그래프와 직선 $y = \frac{1}{3}$의 교점은 $0 \leq t \leq 2\pi$ 구간에서 2개, $2\pi < t \leq 4\pi$ 구간에서 2개 존재합니다.

1. $0 \leq t \leq 2\pi$ 구간에서의 해를 $t_1, t_2$라 하면, $\sin t$의 대칭성에 의해 $t_1 + t_2 = \pi$입니다.

따라서 $t_3 + t_4 = (t_1 + 2\pi) + (t_2 + 2\pi) = (t_1 + t_2) + 4\pi = \pi + 4\pi = 5\pi$입니다.

모든 $t$의 합은 $t_1 + t_2 + t_3 + t_4 = \pi + 5\pi = 6\pi$입니다.
$t = 2x$이므로 $2x_1 + 2x_2 + 2x_3 + 2x_4 = 6\pi$가 성립합니다.
따라서 모든 해 $x$의 합은 다음과 같습니다.
$x_1 + x_2 + x_3 + x_4 = \frac{6\pi}{2} = 3\pi$
