실수 $k$에 대하여 함수
$f \left( x \right) = \cos^{2} \left( x - \frac{3}{4} \pi \right) - \cos \left( x - \frac{\pi}{4} \right) + k$
의 최댓값은 $3$, 최솟값은 $m$이다. $k + m$의 값은?
① $2$		② $\frac{9}{4}$		③ $\frac{5}{2}$
④ $\frac{11}{4}$		⑤ $3$

## 원본 해설 전체

[정답] ③

[해설]
$x = \theta + \frac{3}{4} \pi$라 하면
$f \left( \theta + \frac{3}{4} \pi \right) = \cos^{2} \theta - \cos \left( \theta + \frac{\pi}{2} \right) + k$
$= \cos^{2} \theta + \sin \theta + k$
$= 1 - \sin^{2} \theta + \sin \theta + k$
$= - \left( \sin \theta - \frac{1}{2} \right)^{2} + k + \frac{5}{4}$
최댓값은 $k + \frac{5}{4} = 3$, $k = \frac{7}{4}$
최솟값은 $\sin \theta = - 1$일 때, $m = \frac{3}{4}$
$k + m = \frac{7}{4} + \frac{3}{4} = \frac{5}{2}$

### 생성 풀이 전체

주어진 함수 $f(x) = \cos^{2} \left( x - \frac{3}{4} \pi \right) - \cos \left( x - \frac{\pi}{4} \right) + k$를 정리해 봅시다.

먼저 삼각함수의 성질을 이용합니다.
$\cos \left( x - \frac{3}{4} \pi \right) = \cos \left( x - \frac{\pi}{4} - \frac{\pi}{2} \right) = \sin \left( x - \frac{\pi}{4} \right)$ 입니다.

이제 $t = \cos \left( x - \frac{\pi}{4} \right)$라고 치환하면, $\sin^2 \left( x - \frac{\pi}{4} \right) = 1 - \cos^2 \left( x - \frac{\pi}{4} \right) = 1 - t^2$이 됩니다.
이때 $x$가 실수 전체의 값을 가질 때 $-1 \le t \le 1$입니다.

함수 $f(x)$를 $t$에 대한 함수 $g(t)$로 나타내면:
$g(t) = (1 - t^2) - t + k = -t^2 - t + 1 + k$
$g(t) = -(t^2 + t) + 1 + k = -(t + \frac{1}{2})^2 + \frac{1}{4} + 1 + k = -(t + \frac{1}{2})^2 + k + \frac{5}{4}$

범위 $-1 \le t \le 1$에서 $g(t)$의 최댓값과 최솟값을 구합니다.
꼭짓점 $t = -\frac{1}{2}$이 범위 안에 포함되므로:
1) 최댓값: $t = -\frac{1}{2}$일 때, $g(-\frac{1}{2}) = k + \frac{5}{4}$
문제에서 최댓값이 $3$이라고 했으므로, $k + \frac{5}{4} = 3 \implies k = 3 - \frac{5}{4} = \frac{7}{4}$

2) 최솟값: $t = 1$일 때 (꼭짓점에서 더 먼 쪽), $g(1) = -(1)^2 - 1 + 1 + k = k - 1$
$k = \frac{7}{4}$을 대입하면, $m = \frac{7}{4} - 1 = \frac{3}{4}$

따라서 $k + m = \frac{7}{4} + \frac{3}{4} = \frac{10}{4} = \frac{5}{2}$입니다.

최종정답: ③

### 생성 풀이 전체

주어진 함수 $f(x) = \cos^2 \left( x - \frac{3}{4}\pi \right) - \cos \left( x - \frac{\pi}{4} \right) + k$를 정리하기 위해 삼각함수의 성질을 이용합니다.

먼저, $\cos \left( x - \frac{3}{4}\pi \right)$를 변형합니다.
$\cos \left( x - \frac{3}{4}\pi \right) = \cos \left( (x - \frac{\pi}{4}) - \frac{\pi}{2} \right) = \sin \left( x - \frac{\pi}{4} \right)$입니다.

따라서 $f(x) = \sin^2 \left( x - \frac{\pi}{4} \right) - \cos \left( x - \frac{\pi}{4} \right) + k$가 됩니다.
여기서 $t = \cos \left( x - \frac{\pi}{4} \right)$로 치환하면, $-1 \le t \le 1$이고, $\sin^2 \left( x - \frac{\pi}{4} \right) = 1 - t^2$이므로,
$g(t) = (1 - t^2) - t + k = -t^2 - t + 1 + k$ ($ -1 \le t \le 1$)로 나타낼 수 있습니다.

이차함수 $g(t) = -(t^2 + t) + 1 + k = -(t + \frac{1}{2})^2 + \frac{1}{4} + 1 + k = -(t + \frac{1}{2})^2 + k + \frac{5}{4}$의 최댓값과 최솟값을 구합니다.
구간 $[-1, 1]$에서 꼭짓점 $t = -\frac{1}{2}$이 포함되므로,
최댓값은 $t = -\frac{1}{2}$일 때 $k + \frac{5}{4}$입니다.
문제에서 최댓값이 $3$이라고 하였으므로, $k + \frac{5}{4} = 3$에서 $k = 3 - \frac{5}{4} = \frac{7}{4}$입니다.

다음으로 최솟값 $m$은 구간의 양 끝점인 $t = -1$ 또는 $t = 1$에서 발생합니다.
$g(-1) = -(-1)^2 - (-1) + 1 + k = -1 + 1 + 1 + k = k + 1 = \frac{7}{4} + 1 = \frac{11}{4}$
$g(1) = -(1)^2 - (1) + 1 + k = -1 - 1 + 1 + k = k - 1 = \frac{7}{4} - 1 = \frac{3}{4}$
따라서 최솟값 $m = \frac{3}{4}$입니다.

구하는 값 $k + m = \frac{7}{4} + \frac{3}{4} = \frac{10}{4} = \frac{5}{2}$입니다.
