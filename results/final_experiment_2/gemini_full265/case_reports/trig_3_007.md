(단, $a$, $b$, $c$는 상수이다.)
① $\mathrm{6}$		② $\mathrm{8}$		③ $\mathrm{10}$
④ $\mathrm{12}$		⑤ $\mathrm{14}$

$\therefore \quad a b c = 6$

### 생성 풀이 전체

함수 $f(x) = a \sin bx + c$ ($a > 0, b > 0$)에 대하여 주어진 조건들을 하나씩 해결해 보겠습니다.

**1. 최댓값과 최솟값 조건 이용**
함수 $f(x) = a \sin bx + c$의 최댓값은 $a + c$이고, 최솟값은 $-a + c$입니다.
문제에서 최댓값이 $4$, 최솟값이 $-2$라고 하였으므로 다음 연립방정식을 얻습니다.
*   $a + c = 4$
*   $-a + c = -2$

두 식을 더하면 $2c = 2$이므로 **$c = 1$**입니다.
이를 첫 번째 식에 대입하면 $a + 1 = 4$이므로 **$a = 3$**입니다.

**2. 주기 조건 이용**
함수 $f(x) = a \sin bx + c$의 주기는 $\frac{2\pi}{b}$입니다.
문제에서 $f(x+p) = f(x)$를 만족시키는 양수 $p$의 최솟값이 $\pi$라는 것은 함수의 주기가 $\pi$라는 뜻입니다.
따라서 $\frac{2\pi}{b} = \pi$가 성립해야 합니다.
양변을 $\pi$로 나누면 $\frac{2}{b} = 1$이 되어 **$b = 2$**입니다.

**3. $abc$의 값 계산**
구한 값들을 곱하면 다음과 같습니다.
$a \times b \times c = 3 \times 2 \times 1 = 6$

따라서 정답은 6입니다.

최종정답: ①
