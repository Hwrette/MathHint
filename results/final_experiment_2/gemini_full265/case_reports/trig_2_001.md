## 원본 문제와 선택지

반지름의 길이가 ${2}$이고 중심각의 크기가 $\theta$인 부채꼴이 있다. $\theta$가 다음 조건을 만족시킬 때, 이 부채꼴의 넓이는?

(가) $0 < \theta < \frac{\pi}{2}$
(나) 각의 크기 $\theta$를 나타내는 동경과 각의 크기 $8 \theta$를 나타내는 동경이 일치한다.

① $\frac{3}{7} \pi$		② $\frac{\pi}{2}$		③ $\frac{4}{7} \pi$
④ $\frac{9}{14} \pi$	⑤ $\frac{5}{7} \pi$


## 원본 정답

③

## 원본 해설 전체

[정답] ③

[해설]
$8 \theta - \theta = 2 n \pi$ ($n$은 정수), $\theta = \frac{2 n}{7} \pi$
$0 < \theta < \frac{\pi}{2}$이므로 $0 < \frac{2 n}{7} \pi < \frac{\pi}{2}$, $0 < n < \frac{7}{4}$
$n$은 정수이므로 $n = 1$, $\theta = \frac{2}{7} \pi$
따라서 부채꼴의 넓이는 $\frac{1}{2} \times 2^{2} \times \frac{2}{7} \pi = \frac{4}{7} \pi$

### 생성 풀이 전체

부채꼴의 반지름의 길이를 $r=2$, 중심각의 크기를 $\theta$라고 할 때, 부채꼴의 넓이 $S$는 다음과 같습니다.
$$S = \frac{1}{2} r^2 \theta = \frac{1}{2} \times 2^2 \times \theta = 2\theta$$

조건 (나)에 의해 각의 크기 $\theta$를 나타내는 동경과 $8\theta$를 나타내는 동경이 일치하므로, 다음 식이 성립합니다.
$$8\theta - \theta = 2n\pi \quad (n은 정수)$$
$$7\theta = 2n\pi$$
$$\theta = \frac{2n\pi}{7}$$

조건 (가)에서 $0 < \theta < \frac{\pi}{2}$이므로,
$$0 < \frac{2n\pi}{7} < \frac{\pi}{2}$$
$$0 < \frac{2n}{7} < \frac{1}{2}$$
$$0 < n < \frac{7}{4} = 1.75$$

따라서 가능한 정수 $n$의 값은 $n=1$입니다.
$n=1$일 때 $\theta = \frac{2\pi}{7}$입니다.

이를 부채꼴의 넓이 공식에 대입하면,
$$S = 2\theta = 2 \times \frac{2\pi}{7} = \frac{4}{7}\pi$$

따라서 부채꼴의 넓이는 $\frac{4}{7}\pi$입니다.
