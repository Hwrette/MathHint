[해설]
$\frac{\sin \theta}{1 - \sin \theta} - \frac{\sin \theta}{1 + \sin \theta} = 4$에서
$\frac{\sin \theta \left( 1 + \sin \theta \right) - \sin \theta \left( 1 - \sin \theta \right)}{\left( 1 - \sin \theta \right) \left( 1 + \sin \theta \right)} = 4$
$\frac{2 \sin^{2} \theta}{1 - \sin^{2} \theta} = 4$, $\frac{2 \left( 1 - \cos^{2} \theta \right)}{\cos^{2} \theta} = 4$
$1 - \cos^{2} \theta = 2 \cos^{2} \theta$
따라서 $\cos^{2} \theta = \frac{1}{3}$이고, $\frac{\pi}{2} < \theta < \pi$이므로
$\cos \theta = - \frac{\sqrt{3}}{3}$

### 생성 풀이 전체

주어진 방정식을 통분하여 정리합니다.

$$\frac{\sin \theta}{1 - \sin \theta} - \frac{\sin \theta}{1 + \sin \theta} = 4$$

좌변을 통분하면 분모는 $(1 - \sin \theta)(1 + \sin \theta) = 1 - \sin^2 \theta = \cos^2 \theta$가 됩니다.

$$\frac{\sin \theta(1 + \sin \theta) - \sin \theta(1 - \sin \theta)}{\cos^2 \theta} = 4$$

분자를 전개하면:
$$\sin \theta + \sin^2 \theta - (\sin \theta - \sin^2 \theta) = 2\sin^2 \theta$$

따라서 식은 다음과 같습니다.
$$\frac{2\sin^2 \theta}{\cos^2 \theta} = 4$$
$$2\tan^2 \theta = 4$$
$$\tan^2 \theta = 2$$

$\tan \theta = \pm \sqrt{2}$인데, 문제에서 $\frac{\pi}{2} < \theta < \pi$ (제2사분면)이므로 $\tan \theta$는 음수입니다.
따라서 $\tan \theta = -\sqrt{2}$입니다.

이제 $\cos \theta$를 구하기 위해 $\tan^2 \theta = \frac{\sin^2 \theta}{\cos^2 \theta} = \frac{1 - \cos^2 \theta}{\cos^2 \theta} = 2$임을 이용합니다.
$$1 - \cos^2 \theta = 2\cos^2 \theta$$
$$3\cos^2 \theta = 1$$
$$\cos^2 \theta = \frac{1}{3}$$

$\frac{\pi}{2} < \theta < \pi$인 제2사분면에서 $\cos \theta$는 음수이므로:
$$\cos \theta = -\sqrt{\frac{1}{3}} = -\frac{1}{\sqrt{3}} = -\frac{\sqrt{3}}{3}$$

따라서 정답은 ①번입니다.

최종정답: ①
