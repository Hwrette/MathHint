## 원본 해설 전체

[정답] ②

[해설]

$\cos \left( \frac{\pi}{2} + x \right) = - \sin x$이므로
$4 \sin^{2} x + 4 \sin x - 3 = 0$
$\sin x = t$라면 $t$의 범위는 $0 \leq x \leq 4 \pi$에 의하여
$- 1 \leq t \leq 1$이다.
$4 t^{2} + 4 t - 3 = 0$ , $(2 t - 1) (2 t + 3) = 0$, $t = \frac{1}{2} , - \frac{3}{2}$
그런데 $t$의 범위를 만족하는 값은 $t = \frac{1}{2}$이다.
따라서 $\sin x = \frac{1}{2}$를 만족하는 $x$의 값을 구하면,
$x = \frac{\pi}{6} , \pi - \frac{\pi}{6} , 2 \pi + \frac{\pi}{6} , 3 \pi - \frac{\pi}{6}$
모든 해의 합은 $6 \pi$

### 생성 풀이 전체

주어진 방정식 $4 \sin^{2} x - 4 \cos \left( \frac{\pi}{2} + x \right) - 3 = 0$을 풀어봅시다.

1. **삼각함수의 변환 공식 적용:**
   $\cos \left( \frac{\pi}{2} + x \right) = -\sin x$이므로, 방정식을 대입하면:
   $4 \sin^{2} x - 4(-\sin x) - 3 = 0$
   $4 \sin^{2} x + 4 \sin x - 3 = 0$

2. **치환을 통한 이차방정식 풀이:**
   $t = \sin x$라 하면 (단, $-1 \leq t \leq 1$),
   $4t^2 + 4t - 3 = 0$
   $(2t - 1)(2t + 3) = 0$
   따라서 $t = \frac{1}{2}$ 또는 $t = -\frac{3}{2}$입니다.
   $-1 \leq \sin x \leq 1$이므로, $\sin x = \frac{1}{2}$만 가능합니다.

3. **범위 $0 \leq x < 4 \pi$에서 해 구하기:**
   $\sin x = \frac{1}{2}$을 만족하는 $x$의 값은 다음과 같습니다.
   - $0 \leq x < 2\pi$ 범위에서: $x = \frac{\pi}{6}, \frac{5\pi}{6}$
   - $2\pi \leq x < 4\pi$ 범위에서: $x = 2\pi + \frac{\pi}{6} = \frac{13\pi}{6}, x = 2\pi + \frac{5\pi}{6} = \frac{17\pi}{6}$

4. **모든 해의 합 구하기:**
   합 $= \frac{\pi}{6} + \frac{5\pi}{6} + \frac{13\pi}{6} + \frac{17\pi}{6}$
   $= \frac{1 + 5 + 13 + 17}{6} \pi$
   $= \frac{36}{6} \pi = 6\pi$

따라서 모든 해의 합은 $6\pi$입니다.

최종정답: ②
