$f \left( g \left( x \right) \right) = g \left( x \right)$

## 원본 해설 전체

[정답] $36$

[해설]
$f \left( g \left( x \right) \right) = g \left( x \right)$에서 $g \left( x \right) = t \quad \left( - 1 \leq t \leq 1 \right)$이라 하면 $f \left( t \right) = t$에서 $2 t^{2} + 2 t - 1 = t$, $\left( 2 t - 1 \right) \left( t + 1 \right) = 0$
$t = \frac{1}{2}$ 또는 $t = - 1$이므로 $g \left( x \right) = \frac{1}{2}$ 또는 $g \left( x \right) = - 1$
함수 $g \left( x \right) = \cos \frac{\pi}{3} x$의 주기는 $\mathrm{6}$이고, $g \left( 1 \right) = g \left( 5 \right) = \frac{1}{2}$, $g \left( 3 \right) = - 1$이다.

그러므로 $0 \leq x < 12$에서 $g \left( 7 \right) = g \left( 11 \right) = \frac{1}{2}$, $g \left( 9 \right) = - 1$이다. 따라서 구하는 모든 실수 $x$의 값의 합은 $1 + 3 + 5 + 7 + 9 + 11 = 36$

### 생성 풀이 전체

주어진 방정식 $f(g(x)) = g(x)$에서 $t = g(x)$라고 하면, 방정식은 $f(t) = t$가 됩니다.
$f(t) = 2t^2 + 2t - 1$이므로,
$2t^2 + 2t - 1 = t$
$2t^2 + t - 1 = 0$
$(2t - 1)(t + 1) = 0$
따라서 $t = \frac{1}{2}$ 또는 $t = -1$입니다.

즉, $g(x) = \cos \frac{\pi}{3} x$에 대하여 다음 두 경우를 고려해야 합니다.

**1) $g(x) = \frac{1}{2}$인 경우**
$\cos \frac{\pi}{3} x = \frac{1}{2}$
$\frac{\pi}{3} x = 2n\pi \pm \frac{\pi}{3}$ ($n$은 정수)
$x = 6n \pm 1$
$0 \leq x < 12$ 범위에서 가능한 $x$의 값은:
$n=0$일 때: $x = 1$
$n=1$일 때: $x = 6-1=5, 6+1=7$
$n=2$일 때: $x = 12-1=11$
따라서 $x = 1, 5, 7, 11$입니다.

**2) $g(x) = -1$인 경우**
$\cos \frac{\pi}{3} x = -1$
$\frac{\pi}{3} x = (2n+1)\pi$
$x = 3(2n+1) = 6n + 3$
$0 \leq x < 12$ 범위에서 가능한 $x$의 값은:
$n=0$일 때: $x = 3$
$n=1$일 때: $x = 9$
따라서 $x = 3, 9$입니다.

구하는 모든 실수 $x$의 값의 합은:
$1 + 5 + 7 + 11 + 3 + 9 = 36$

최종정답: 36
