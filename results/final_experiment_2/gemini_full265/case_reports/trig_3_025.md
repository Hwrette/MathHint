### 생성 풀이 전체

주어진 방정식 $\cos^{2} x = \sin^{2} x - \sin x$를 $x$에 대한 삼각방정식으로 풀기 위해, $\cos^{2} x = 1 - \sin^{2} x$를 대입합니다.

$1 - \sin^{2} x = \sin^{2} x - \sin x$

모든 항을 우변으로 이항하여 정리하면 다음과 같습니다.
$2 \sin^{2} x - \sin x - 1 = 0$

이 식은 $\sin x$에 대한 이차방정식 꼴입니다. 인수분해를 하면:
$(2 \sin x + 1)(\sin x - 1) = 0$

따라서 다음 두 가지 경우를 얻습니다.
1) $\sin x = 1$
2) $\sin x = -\frac{1}{2}$

이제 $0 \le x \le 2 \pi$ 범위에서 각 경우의 해를 구합니다.

1) $\sin x = 1$인 경우:
$x = \frac{\pi}{2}$

2) $\sin x = -\frac{1}{2}$인 경우:
$\sin x$가 음수이므로 제3사분면과 제4사분면의 각입니다.
$x = \pi + \frac{\pi}{6} = \frac{7}{6} \pi$
$x = 2 \pi - \frac{\pi}{6} = \frac{11}{6} \pi$

구한 모든 해의 합을 계산하면:
$\frac{\pi}{2} + \frac{7}{6} \pi + \frac{11}{6} \pi = \frac{3\pi}{6} + \frac{7\pi}{6} + \frac{11\pi}{6} = \frac{21\pi}{6} = \frac{7}{2} \pi$

따라서 모든 해의 합은 $\frac{7}{2} \pi$입니다.

### 생성 풀이 전체

주어진 방정식 $\cos^{2} x = \sin^{2} x - \sin x$를 $0 \le x \le 2 \pi$ 범위에서 풀어보겠습니다.

1. **삼각함수의 성질 이용**:
   $\cos^{2} x = 1 - \sin^{2} x$이므로, 이를 방정식에 대입합니다.
   $1 - \sin^{2} x = \sin^{2} x - \sin x$

2. **방정식 정리**:
   모든 항을 우변으로 이항하여 정리하면 다음과 같습니다.
   $2 \sin^{2} x - \sin x - 1 = 0$

3. **인수분해**:
   $\sin x = t$ ($ -1 \le t \le 1$)로 치환하면,
   $2t^{2} - t - 1 = 0$
   $(2t + 1)(t - 1) = 0$
   따라서 $t = -\frac{1}{2}$ 또는 $t = 1$입니다.

4. **해 구하기**:
   - $\sin x = 1$인 경우:
     $0 \le x \le 2 \pi$ 범위에서 $x = \frac{\pi}{2}$입니다.
   - $\sin x = -\frac{1}{2}$인 경우:
     $x$는 제3사분면 또는 제4사분면의 각이므로,
     $x = \pi + \frac{\pi}{6} = \frac{7}{6} \pi$ 또는 $x = 2 \pi - \frac{\pi}{6} = \frac{11}{6} \pi$입니다.

5. **모든 해의 합**:
   구한 해들을 모두 더하면,
   $\frac{\pi}{2} + \frac{7}{6} \pi + \frac{11}{6} \pi = \frac{3\pi}{6} + \frac{18}{6} \pi = \frac{21}{6} \pi = \frac{7}{2} \pi$

따라서 모든 해의 합은 $\frac{7}{2} \pi$입니다.
