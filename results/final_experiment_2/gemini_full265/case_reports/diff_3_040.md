## 원본 문제와 선택지

함수 $f (x) = x^{4} + a x^{2} + b$는 $x = 1$에서 극소이다.
함수 $f (x)$의 극댓값이 $\mathrm{4}$일 때, $a + b$의 값을 구하시오.
(단, $a$와 $b$는 상수이다.)


## 원본 정답

$2$

## 원본 해설 전체

[정답] $2$

[해설]
$f (x) = x^{4} + a x^{2} + b$에서
$f' (x) = 4 x^{3} + 2 a x$
함수 $f (x)$가 $x = 1$에서 극소이므로 $f' (1) = 4 + 2 a = 0$
에서
$a = - 2$
그러므로
$f' (x) = 4 x^{3} - 4 x = 4 x (x - 1) (x + 1)$
이므로 $f' (x) = 0$에서
$x = - 1$ 또는 $x = 0$ 또는 $x = 1$
함수 $f (x)$는 $x = 0$에서 극댓값 $\mathrm{4}$를 가지므로
$f (0) = b = 4$
따라서 $a + b = (- 2) + 4 = 2$

### 생성 풀이 전체

함수 $f(x) = x^4 + ax^2 + b$가 $x=1$에서 극소이므로, 미분계수 $f'(1) = 0$이어야 합니다.

1. **$f'(x)$ 구하기:**
   $f'(x) = 4x^3 + 2ax$

2. **$f'(1) = 0$ 조건 이용:**
   $f'(1) = 4(1)^3 + 2a(1) = 4 + 2a = 0$
   $2a = -4 \implies a = -2$

3. **함수식 완성 및 극값 확인:**
   $f(x) = x^4 - 2x^2 + b$
   $f'(x) = 4x^3 - 4x = 4x(x^2 - 1) = 4x(x-1)(x+1)$
   $f'(x) = 0$이 되는 $x$의 값은 $x = -1, 0, 1$입니다.
   이계도함수 $f''(x) = 12x^2 - 4$를 이용하면:
   - $f''(1) = 12 - 4 = 8 > 0$ (극소)
   - $f''(-1) = 12 - 4 = 8 > 0$ (극소)
   - $f''(0) = -4 < 0$ (극대)
   따라서 $f(x)$는 $x=0$에서 극댓값을 가집니다.

4. **극댓값 조건 이용:**
   문제에서 극댓값이 4라고 하였으므로, $f(0) = 4$입니다.
   $f(0) = 0^4 - 2(0)^2 + b = 4$
   $b = 4$

5. **$a + b$ 계산:**
   $a = -2, b = 4$이므로
   $a + b = -2 + 4 = 2$

최종정답: 2

### 생성 풀이 전체

함수 $f(x) = x^4 + ax^2 + b$에 대하여 도함수를 구하면 다음과 같습니다.
$f'(x) = 4x^3 + 2ax = 2x(2x^2 + a)$

함수 $f(x)$가 $x=1$에서 극소이므로 $f'(1) = 0$이어야 합니다.
$f'(1) = 2(1)(2(1)^2 + a) = 2(2 + a) = 0$
따라서 $a = -2$입니다.

이제 $a = -2$를 도함수에 대입하면,
$f'(x) = 2x(2x^2 - 2) = 4x(x^2 - 1) = 4x(x - 1)(x + 1)$
$f'(x) = 0$이 되는 $x$의 값은 $x = -1, 0, 1$입니다.

함수 $f(x) = x^4 - 2x^2 + b$의 증감을 살펴보면, $x = -1$과 $x = 1$에서 극소이고, $x = 0$에서 극대입니다.
문제에서 극댓값이 4라고 하였으므로, $f(0) = 4$입니다.
$f(0) = 0^4 - 2(0)^2 + b = b = 4$

따라서 $a = -2, b = 4$이므로,
$a + b = -2 + 4 = 2$
