## 원본 해설 전체

[해설]
$\lim_{x \rightarrow \infty} \frac{f (x)}{x^{2}} = 2$이므로 $f (x)$는 최고차항의 계수가 $\mathrm{2}$인 이차함수이다.
$\lim_{x \rightarrow 1} \frac{f (x)}{x - 1} = 3$에서 $\lim_{x \rightarrow 1} (x - 1) = 0$이므로 $\lim_{x \rightarrow 1} f (x) = 0$, $f (1) = 0$
$f (x) = (x - 1) (2 x + a)$( $a$는 상수 $)$라 하면
$\lim_{x \rightarrow 1} \frac{(x - 1) (2 x + a)}{x - 1} = 2 + a = 3$, $a = 1$
$f (x) = (x - 1) (2 x + 1)$
따라서 $f (3) = 14$

### 생성 풀이 전체

주어진 두 극한 조건을 이용하여 다항함수 $f(x)$를 구합니다.

**1. 첫 번째 조건 분석:**
$\lim_{x \rightarrow \infty} \frac{f(x)}{x^2} = 2$
이 조건으로부터 $f(x)$는 이차항의 계수가 2인 이차함수임을 알 수 있습니다. 따라서 $f(x) = 2x^2 + ax + b$ (단, $a, b$는 상수)라고 둘 수 있습니다.

**2. 두 번째 조건 분석:**
$\lim_{x \rightarrow 1} \frac{f(x)}{x - 1} = 3$
분모가 $x \rightarrow 1$일 때 0으로 가므로, 극한값이 존재하려면 분자도 $x \rightarrow 1$일 때 0이어야 합니다. 즉, $f(1) = 0$입니다.
$f(1) = 2(1)^2 + a(1) + b = 2 + a + b = 0$ 이므로, $b = -a - 2$입니다.

이를 $f(x)$에 대입하면:
$f(x) = 2x^2 + ax - a - 2$
$f(x) = 2(x^2 - 1) + a(x - 1)$
$f(x) = 2(x - 1)(x + 1) + a(x - 1)$
$f(x) = (x - 1)(2x + 2 + a)$

이제 극한식에 대입합니다:
$\lim_{x \rightarrow 1} \frac{(x - 1)(2x + 2 + a)}{x - 1} = \lim_{x \rightarrow 1} (2x + 2 + a) = 2 + 2 + a = 4 + a$
이 값이 3이어야 하므로, $4 + a = 3$에서 $a = -1$입니다.

**3. $f(x)$ 완성 및 $f(3)$ 계산:**
$a = -1$을 $b = -a - 2$에 대입하면 $b = -(-1) - 2 = -1$입니다.
따라서 $f(x) = 2x^2 - x - 1$입니다.

이제 $f(3)$을 구하면:
$f(3) = 2(3)^2 - 3 - 1 = 2(9) - 4 = 18 - 4 = 14$
