## 원본 문제와 선택지

함수 $f (x) = x^{3} - 3 x^{2} + a x + 10$이 $x = 3$에서 극소일 때, 함수 $f (x)$의 극댓값을 구하시오. (단, $a$는 상수이다.)


## 원본 정답

$15$

## 원본 해설 전체

[정답] $15$

[해설]
$f (x) = x^{3} - 3 x^{2} + a x + 10$에서
$f' (x) = 3 x^{2} - 6 x + a$
함수 $f (x)$는 $x = 3$에서 극소이므로
$f' (3) = 27 - 18 + a = 0$, $a = - 9$
$f' (x) = 3 x^{2} - 6 x - 9 = 3 (x - 3) (x + 1)$
$f' (x) = 0$에서 $x = - 1$ 또는 $x = 3$이므로
함수 $f (x)$는 $x = - 1$에서 극대이고 극댓값은
$f (- 1) = - 1 - 3 + 9 + 10 = 15$

### 생성 풀이 전체

함수 $f(x) = x^3 - 3x^2 + ax + 10$이 $x=3$에서 극값을 가지므로, 미분계수 $f'(3) = 0$이어야 합니다.

먼저 $f(x)$를 미분하면 다음과 같습니다.
$f'(x) = 3x^2 - 6x + a$

$x=3$에서 극값을 가지므로 $f'(3) = 0$을 대입합니다.
$f'(3) = 3(3)^2 - 6(3) + a = 0$
$27 - 18 + a = 0$
$9 + a = 0$
$a = -9$

이제 $a = -9$를 $f'(x)$에 대입하여 극값을 갖는 $x$의 위치를 찾습니다.
$f'(x) = 3x^2 - 6x - 9 = 3(x^2 - 2x - 3) = 3(x - 3)(x + 1)$
$f'(x) = 0$이 되는 $x$는 $x = -1$ 또는 $x = 3$입니다.

함수 $f(x)$는 삼차항의 계수가 양수이므로 $x = -1$에서 극대이고, $x = 3$에서 극소입니다.
따라서 극댓값은 $x = -1$일 때의 함숫값 $f(-1)$입니다.

$f(-1) = (-1)^3 - 3(-1)^2 - 9(-1) + 10$
$f(-1) = -1 - 3 + 9 + 10$
$f(-1) = 15$

최종정답: 15
