## 원본 문제와 선택지

(단, $0 \leq x \leq 2 \pi$이고, $p$와 $q$는 서로소인 자연수이다.)

$\frac{2}{\sqrt{3}} \sin \left( x + \frac{\pi}{3} \right) - \frac{7}{8} = 0$에서
$\sin \left( x + \frac{\pi}{3} \right) = \frac{7 \sqrt{3}}{16}$
$t = x + \frac{\pi}{3}$라 하면 $\frac{\pi}{3} \leq t \leq \frac{7}{3} \pi$
$\frac{7 \sqrt{3}}{16} < \frac{\sqrt{3}}{2}$이므로
방정식 $\sin t = \frac{7 \sqrt{3}}{16}$$\left( \frac{\pi}{3} \leq t \leq \frac{7}{3} \pi \right)$는 두 실근
$t_{1}$, $t_{2}$$\left( t_{1} < t_{2} \right)$를 갖는다.
$t_{1} = x_{1} + \frac{\pi}{3}$, $t_{2} = x_{2} + \frac{\pi}{3}$ ($x_{1}$, $x_{2}$는 실수)라
하면
$t_{2} = 2 \pi + \left( \pi - t_{1} \right)$이므로
$t_{1} + t_{2} = \left( x_{1} + \frac{\pi}{3} \right) + \left( x_{2} + \frac{\pi}{3} \right) = 3 \pi$
방정식 $\sin \left( x + \frac{\pi}{3} \right) = \frac{7 \sqrt{3}}{16}$의 모든 실근의 합은
$x_{1} + x_{2} = 3 \pi - \frac{2}{3} \pi = \frac{7}{3} \pi$
따라서 $p + q = 10$

### 생성 풀이 전체

주어진 방정식 $\frac{2}{\sqrt{3}} \sin \left( x + \frac{\pi}{3} \right) - \frac{7}{8} = 0$을 정리하면 다음과 같습니다.

$\frac{2}{\sqrt{3}} \sin \left( x + \frac{\pi}{3} \right) = \frac{7}{8}$
$\sin \left( x + \frac{\pi}{3} \right) = \frac{7}{8} \times \frac{\sqrt{3}}{2} = \frac{7\sqrt{3}}{16}$

여기서 $0 \leq x \leq 2\pi$이므로, $t = x + \frac{\pi}{3}$라 하면 $\frac{\pi}{3} \leq t \leq \frac{7\pi}{3}$입니다.
$\sin t = \frac{7\sqrt{3}}{16}$을 만족하는 $t$의 값을 구합니다. $\frac{7\sqrt{3}}{16} \approx \frac{7 \times 1.732}{16} \approx 0.757$이므로, $0 < \sin t < 1$을 만족합니다.

$\sin t = \alpha$ (단, $\alpha = \frac{7\sqrt{3}}{16}$)라 할 때, $t$의 해를 $t_1, t_2$라 하면, 사인 함수의 대칭성에 의해 $t_1 + t_2 = \pi$ 또는 $t_1 + t_2 = 3\pi$가 됩니다.
범위 $\frac{\pi}{3} \leq t \leq \frac{7\pi}{3}$에서 $\sin t = \alpha$를 만족하는 해는 다음과 같습니다.
1) $t_1 = \arcsin \alpha$ (범위 밖)
2) $t_2 = \pi - \arcsin \alpha$ (범위 내)
3) $t_3 = 2\pi + \arcsin \alpha$ (범위 내)

따라서 $t$의 값은 $t_2 = \pi - \arcsin \alpha$와 $t_3 = 2\pi + \arcsin \alpha$입니다.
$x = t - \frac{\pi}{3}$이므로, 두 실근 $x_1, x_2$는 다음과 같습니다.
$x_1 = (\pi - \arcsin \alpha) - \frac{\pi}{3} = \frac{2\pi}{3} - \arcsin \alpha$
$x_2 = (2\pi + \arcsin \alpha) - \frac{\pi}{3} = \frac{5\pi}{3} + \arcsin \alpha$

두 실근의 합은:
$x_1 + x_2 = \left( \frac{2\pi}{3} - \arcsin \alpha \right) + \left( \frac{5\pi}{3} + \arcsin \alpha \right) = \frac{7\pi}{3}$

문제에서 합이 $\frac{q}{p} \pi$라고 하였으므로, $\frac{q}{p} = \frac{7}{3}$입니다.
$p=3, q=7$은 서로소인 자연수이므로, $p+q = 3+7 = 10$입니다.

최종정답: 10
