## 원본 문제와 선택지

함수 $f (x) = x^{3} + a x^{2} - 9 x + b$는 $x = 1$에서 극소이다. 함수 $f (x)$의 극댓값이 $\mathrm{28}$일 때, $a + b$의 값을 구하시오. (단, $a$와 $b$는 상수이다.)

## 원본 해설 전체

[정답] $4$

[해설]
[정답] $4$
[해설]
함수 $f \left( x \right) = x^{3} + a x^{2} - 9 x + b$에서
$f' \left( x \right) = 3 x^{2} + 2 a x - 9$
함수 $f \left( x \right)$는 $x = 1$에서 극솟값을 가지므로
$f' \left( 1 \right) = 3 + 2 a - 9 = 0$$\therefore \quad$$a = 3$
이때
$f' \left( x \right) = 3 x^{2} + 6 x - 9 = 3 \left( x - 1 \right) \left( x + 3 \right)$
함수 $f \left( x \right)$는 $x = - 3$에서 극댓값을 가지므로
$f \left( - 3 \right) = - 27 + 27 + 27 + b = 27 + b$
$27 + b = 28$에서 $b = 1$
$\therefore \quad$$a + b = 3 + 1 = 4$

### 생성 풀이 전체

함수 $f(x) = x^3 + ax^2 - 9x + b$의 도함수는
$f'(x) = 3x^2 + 2ax - 9$입니다.

문제에서 $f(x)$가 $x=1$에서 극소라고 하였으므로, $f'(1) = 0$이어야 합니다.
$f'(1) = 3(1)^2 + 2a(1) - 9 = 0$
$3 + 2a - 9 = 0$
$2a - 6 = 0$
$2a = 6$ 이므로 **$a = 3$**입니다.

이제 $a=3$을 대입하여 도함수를 구하면
$f'(x) = 3x^2 + 6x - 9 = 3(x^2 + 2x - 3) = 3(x+3)(x-1)$입니다.
$f'(x) = 0$이 되는 $x$의 값은 $x = -3$ 또는 $x = 1$입니다.
$f'(x)$의 부호 변화를 살펴보면 $x = -3$에서 극대, $x = 1$에서 극소를 가짐을 알 수 있습니다.

문제에서 극댓값이 28이라고 하였으므로, $f(-3) = 28$입니다.
$f(x) = x^3 + 3x^2 - 9x + b$에 $x = -3$을 대입하면
$f(-3) = (-3)^3 + 3(-3)^2 - 9(-3) + b = 28$
$-27 + 3(9) + 27 + b = 28$
$-27 + 27 + 27 + b = 28$
$27 + b = 28$ 이므로 **$b = 1$**입니다.

따라서 $a + b = 3 + 1 = 4$입니다.
