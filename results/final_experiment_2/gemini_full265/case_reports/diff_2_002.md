## 원본 문제와 선택지

다항함수 $f \left( x \right)$가
$\lim_{x \rightarrow \infty} \frac{x f \left( x \right) - 2 x^{3} + 1}{x^{2}} = 5$, $f \left( 0 \right) = 1$
을 만족시킬 때, $f \left( 1 \right)$의 값을 구하시오.


## 원본 정답

$8$

## 원본 해설 전체

[정답] $8$

[해설]
$f \left( x \right)$가 다항함수이고
$\lim_{x \rightarrow \infty} \frac{x f \left( x \right) - 2 x^{3} + 1}{x^{2}} = 5$이므로
$x f \left( x \right) = 2 x^{3} + 5 x^{2} + a x \left( a \right.$는 실수$)$
$x \ne 0$일 때
$f \left( x \right) = 2 x^{2} + 5 x + a$이고
함수 $f \left( x \right)$는 $x = 0$에서 연속이므로
$f \left( 0 \right)$$= \lim_{x \rightarrow 0} f \left( x \right)$
$= a$
$= 1$
따라서 $f \left( 1 \right)$$= 2 + 5 + 1$
$= 8$

1. **$f(x)$의 차수와 최고차항 결정:**
   분모가 $x^2$이고 극한값이 5로 수렴하므로, 분자 $x f(x) - 2x^3 + 1$은 $x^2$에 비례하는 다항식이어야 합니다.
   즉, $x f(x) - 2x^3 + 1 = 5x^2 + ax + b$ 꼴이 되어야 하므로,
   $x f(x) = 2x^3 + 5x^2 + ax + (b-1)$입니다.
   따라서 $f(x) = 2x^2 + 5x + a + \frac{b-1}{x}$가 되어야 하는데, $f(x)$가 다항함수이므로 $b-1=0$, 즉 $b=1$이어야 합니다.

2. **상수항 결정:**
   문제에서 $f(0) = 1$이라고 주어졌습니다.
   $f(0) = 2(0)^2 + 5(0) + a = 1$ 이므로, $a = 1$입니다.

3. **함수식 완성:**
   위의 결과들을 종합하면 $f(x) = 2x^2 + 5x + 1$입니다.

4. **$f(1)$의 값 계산:**
   $f(1) = 2(1)^2 + 5(1) + 1 = 2 + 5 + 1 = 8$

   분모가 $x^2$이고 극한값이 5로 수렴하므로, 분자인 $x f(x) - 2x^3 + 1$은 $x^2$에 관한 이차식이어야 합니다. 즉, $x f(x) - 2x^3$의 차수가 2차 이하가 되어야 하므로, $f(x)$는 이차항까지 포함하는 삼차함수여야 합니다.

   $x f(x) = ax^3 + bx^2 + cx + d$
   $x f(x) - 2x^3 = (a-2)x^3 + bx^2 + cx + d$
   이 식이 $x^2$의 차수를 가지려면 $a-2=0$이어야 하므로 $a=2$입니다.

2. **상수항 결정**
   $f(0) = 1$이므로, $f(0) = 2(0)^2 + b(0) + c = 1$에서 $c = 1$입니다.

3. **극한값 계산**
   주어진 식에 대입하면:
   $\lim_{x \rightarrow \infty} \frac{x(2x^2 + bx + 1) - 2x^3 + 1}{x^2} = \lim_{x \rightarrow \infty} \frac{2x^3 + bx^2 + x - 2x^3 + 1}{x^2}$

   문제에서 이 극한값이 5라고 하였으므로 $b = 5$입니다.

4. **$f(1)$ 구하기**
   구해진 $f(x) = 2x^2 + 5x + 1$에 $x=1$을 대입합니다.
   $f(1) = 2(1)^2 + 5(1) + 1 = 2 + 5 + 1 = 8$
