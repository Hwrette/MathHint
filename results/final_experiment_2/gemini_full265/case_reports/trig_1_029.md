## 원본 문제와 선택지

$\sin \left( \frac{\pi}{2} + \theta \right) + \cos \left( \frac{\pi}{2} - \theta \right) = \frac{\sqrt{5}}{5}$일 때, $\sin \theta \cos \theta$의 값은?

④ $\frac{1}{5}$		⑤ $\frac{2}{5}$

## 원본 해설 전체

[정답] ①

[해설]
$\sin \left( \frac{\pi}{2} + \theta \right) = \cos \theta$, $\cos \left( \frac{\pi}{2} - \theta \right) = \sin \theta$이므로
$\cos \theta + \sin \theta = \frac{\sqrt{5}}{5}$
$\left( \cos \theta + \sin \theta \right)^{2}$$= \cos^{2} \theta + 2 \cos \theta \sin \theta + \sin^{2} \theta$
$= 1 + 2 \sin \theta \cos \theta = \frac{1}{5}$
따라서 $\sin \theta \cos \theta = - \frac{2}{5}$

2. **주어진 식에 대입:**
   $\cos \theta + \sin \theta = \frac{\sqrt{5}}{5}$

3. **양변을 제곱하여 $\sin \theta \cos \theta$ 구하기:**
   $(\sin \theta + \cos \theta)^2 = \left( \frac{\sqrt{5}}{5} \right)^2$
   $\sin^2 \theta + 2 \sin \theta \cos \theta + \cos^2 \theta = \frac{5}{25}$

4. **삼각함수의 기본 관계식($\sin^2 \theta + \cos^2 \theta = 1$) 이용:**
   $1 + 2 \sin \theta \cos \theta = \frac{1}{5}$
   $2 \sin \theta \cos \theta = \frac{1}{5} - 1$
   $2 \sin \theta \cos \theta = -\frac{4}{5}$

5. **최종 계산:**
   $\sin \theta \cos \theta = -\frac{4}{5} \div 2 = -\frac{2}{5}$

따라서 구하는 값은 $-\frac{2}{5}$입니다.
