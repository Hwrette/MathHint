## 원본 문제와 선택지

$0 \le x \le \pi$일 때, 방정식
$2 \cos^{2} x + \left( 2 + \sqrt{3} \right) \sin x - \left( 2 + \sqrt{3} \right) = 0$
의 모든 해의 합은?
① $\frac{3}{4} \pi$		② $\pi$		③ $\frac{5}{4} \pi$
④ $\frac{3}{2} \pi$		⑤ $\frac{7}{4} \pi$


## 원본 정답

④

## 원본 해설 전체

[정답] ④

[해설]
$\cos^{2} x = 1 - \sin^{2} x$이므로
$2 (1 - \sin^{2} x) + (2 + \sqrt{3}) \sin x - (2 + \sqrt{3}) = 0$
$2 \sin^{2} x - (2 + \sqrt{3}) \sin x + \sqrt{3} = 0$
$(2 \sin x - \sqrt{3}) (\sin x - 1) = 0$
$\sin x = \frac{\sqrt{3}}{2}$ 또는 $\sin x = 1$이므로 $0 \le x \le \pi$에서
$x = \frac{\pi}{3}$ 또는 $x = \frac{2}{3} \pi$ 또는 $x = \frac{\pi}{2}$
따라서 모든 해의 합은 $\frac{3}{2} \pi$

### 생성 풀이 전체

주어진 방정식 $2 \cos^{2} x + (2 + \sqrt{3}) \sin x - (2 + \sqrt{3}) = 0$을 풀어봅시다.

1. **삼각함수의 성질 이용:**
   $\cos^2 x = 1 - \sin^2 x$이므로, 이를 방정식에 대입합니다.
   $2(1 - \sin^2 x) + (2 + \sqrt{3}) \sin x - (2 + \sqrt{3}) = 0$
   $2 - 2 \sin^2 x + (2 + \sqrt{3}) \sin x - 2 - \sqrt{3} = 0$
   $-2 \sin^2 x + (2 + \sqrt{3}) \sin x - \sqrt{3} = 0$

2. **방정식 정리:**
   양변에 $-1$을 곱하여 정리합니다.
   $2 \sin^2 x - (2 + \sqrt{3}) \sin x + \sqrt{3} = 0$

3. **인수분해:**
   이 식은 $2 \sin x$와 $\sin x$, 그리고 $-\sqrt{3}$과 $-1$의 곱으로 인수분해됩니다.
   $(2 \sin x - \sqrt{3})(\sin x - 1) = 0$

4. **해 구하기:**
   따라서 $\sin x = \frac{\sqrt{3}}{2}$ 또는 $\sin x = 1$입니다.

   - $0 \le x \le \pi$ 범위에서 $\sin x = 1$인 경우:
     $x = \frac{\pi}{2}$
   - $0 \le x \le \pi$ 범위에서 $\sin x = \frac{\sqrt{3}}{2}$인 경우:
     $x = \frac{\pi}{3}$ 또는 $x = \pi - \frac{\pi}{3} = \frac{2}{3}\pi$

5. **모든 해의 합:**
   구한 해는 $\frac{\pi}{2}, \frac{\pi}{3}, \frac{2}{3}\pi$입니다.
   합 = $\frac{\pi}{2} + \frac{\pi}{3} + \frac{2}{3}\pi = \frac{\pi}{2} + \pi = \frac{3}{2}\pi$

따라서 정답은 ④번입니다.

최종정답: ④
