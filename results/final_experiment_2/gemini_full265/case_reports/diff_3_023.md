## 원본 문제와 선택지

다항함수 $f \left( x \right)$에 대하여 함수 $g \left( x \right)$를
$g \left( x \right) = x^{2} f \left( x \right)$
라 하자. $f \left( 2 \right) = 1$, $f' \left( 2 \right) = 3$일 때, $g' \left( 2 \right)$의 값은?
① $\mathrm{12}$		② $\mathrm{14}$		③ $\mathrm{16}$
④ $\mathrm{18}$		⑤ $\mathrm{20}$


## 원본 정답

③

## 원본 해설 전체

[정답] ③

[해설]
$g (x) = x^{2} f (x)$를 $x$에 대하여 미분하면
$g' (x) = 2 x f (x) + x^{2} f' (x)$
이때, $f (2) = 1$, $f' (2) = 3$이므로
$g' (2)$$= 4 f (2) + 4 f' (2)$
$= 4 \times 1 + 4 \times 3$
$= 16$

### 생성 풀이 전체

함수 $g(x) = x^2 f(x)$에 대하여 곱의 미분법을 적용하면 다음과 같습니다.

$g'(x) = (x^2)' f(x) + x^2 f'(x)$
$g'(x) = 2x f(x) + x^2 f'(x)$

이제 $x=2$를 대입하여 $g'(2)$의 값을 구합니다.

$g'(2) = 2(2) f(2) + (2)^2 f'(2)$
$g'(2) = 4 f(2) + 4 f'(2)$

문제에서 주어진 조건 $f(2) = 1$, $f'(2) = 3$을 대입하면,

$g'(2) = 4(1) + 4(3)$
$g'(2) = 4 + 12$
$g'(2) = 16$

따라서 $g'(2)$의 값은 16입니다.

최종정답: ③
