## 원본 문제와 선택지

닫힌구간 $[0 , \pi]$에서 정의된 함수 $f (x) = - \sin 2 x$가 $x = a$에서 최댓값을 갖고 $x = b$에서 최솟값을 갖는다. 곡선 $y = f (x)$ 위의 두 점 $(a , f (a))$, $(b , f (b))$를 지나는 직선의 기울기는?
① $\frac{1}{\pi}$		② $\frac{2}{\pi}$		③ $\frac{3}{\pi}$
④ $\frac{4}{\pi}$		⑤ $\frac{5}{\pi}$


## 원본 정답

④

## 원본 해설 전체

[정답] ④

[해설]
함수 $f \left( x \right) = - \sin 2 x$의 주기는 $\frac{2 \pi}{2} = \pi$이
므로 함수 $y = f \left( x \right)$의 그래프는 다음과 같다.

함수 $f \left( x \right)$는 $x = \frac{\pi}{4}$일 때 최솟값
$f \left( \frac{\pi}{4} \right) = - \sin \frac{\pi}{2} = - 1$
을 갖고, $x = \frac{3}{4} \pi$일 때 최댓값
$f \left( \frac{3}{4} \pi \right) = - \sin \frac{3}{2} \pi = 1$
을 갖는다.
따라서 $a = \frac{3 \pi}{4}$, $b = \frac{\pi}{4}$이므로 두 점
$\left( \frac{3}{4} \pi , 1 \right)$, $\left( \frac{\pi}{4} , - 1 \right)$을 지나는 직선의
기울기는
$\frac{1 - \left( - 1 \right)}{\frac{3}{4} \pi - \frac{\pi}{4}} = \frac{2}{\frac{\pi}{2}} = \frac{4}{\pi}$

### 생성 풀이 전체

함수 $f(x) = -\sin 2x$의 구간 $[0, \pi]$에서의 최댓값과 최솟값을 구하기 위해 $2x = t$라고 하면, $0 \le x \le \pi$에서 $0 \le t \le 2\pi$입니다.
이때 $f(x) = -\sin t$가 됩니다.

1. **최댓값과 최솟값 구하기**
   - $-\sin t$는 $t = \frac{3}{2}\pi$일 때 최댓값 $1$을 갖습니다.
     $2x = \frac{3}{2}\pi \implies x = \frac{3}{4}\pi$
     따라서 $a = \frac{3}{4}\pi$이고, $f(a) = 1$입니다.
   - $-\sin t$는 $t = \frac{1}{2}\pi$일 때 최솟값 $-1$을 갖습니다.
     $2x = \frac{1}{2}\pi \implies x = \frac{1}{4}\pi$
     따라서 $b = \frac{1}{4}\pi$이고, $f(b) = -1$입니다.

2. **두 점 $(a, f(a))$와 $(b, f(b))$를 지나는 직선의 기울기 구하기**
   - 두 점은 $(\frac{3}{4}\pi, 1)$과 $(\frac{1}{4}\pi, -1)$입니다.
   - 기울기 $m = \frac{f(a) - f(b)}{a - b}$를 계산하면:
     $m = \frac{1 - (-1)}{\frac{3}{4}\pi - \frac{1}{4}\pi}$
     $m = \frac{2}{\frac{2}{4}\pi}$
     $m = \frac{2}{\frac{1}{2}\pi}$
     $m = 2 \times \frac{2}{\pi} = \frac{4}{\pi}$

따라서 구하는 직선의 기울기는 $\frac{4}{\pi}$입니다.

### 생성 풀이 전체

함수 $f(x) = -\sin 2x$의 구간 $[0, \pi]$에서의 최댓값과 최솟값을 구합니다.

1. **최댓값과 최솟값 구하기**
   $x$의 범위가 $0 \le x \le \pi$이므로, $2x$의 범위는 $0 \le 2x \le 2\pi$입니다.
   - $\sin 2x$는 $2x = \frac{\pi}{2}$일 때 최댓값 $1$을 갖고, $2x = \frac{3\pi}{2}$일 때 최솟값 $-1$을 갖습니다.
   - 따라서 $f(x) = -\sin 2x$는:
     - $2x = \frac{3\pi}{2} \implies x = \frac{3\pi}{4}$일 때 최댓값 $f\left(\frac{3\pi}{4}\right) = -\sin\left(\frac{3\pi}{2}\right) = -(-1) = 1$을 갖습니다. 즉, $a = \frac{3\pi}{4}, f(a) = 1$입니다.
     - $2x = \frac{\pi}{2} \implies x = \frac{\pi}{4}$일 때 최솟값 $f\left(\frac{\pi}{4}\right) = -\sin\left(\frac{\pi}{2}\right) = -1$을 갖습니다. 즉, $b = \frac{\pi}{4}, f(b) = -1$입니다.

2. **직선의 기울기 구하기**
   두 점 $(a, f(a)) = \left(\frac{3\pi}{4}, 1\right)$과 $(b, f(b)) = \left(\frac{\pi}{4}, -1\right)$을 지나는 직선의 기울기 $m$은 다음과 같습니다.
   $$m = \frac{f(a) - f(b)}{a - b} = \frac{1 - (-1)}{\frac{3\pi}{4} - \frac{\pi}{4}}$$
   $$m = \frac{2}{\frac{2\pi}{4}} = \frac{2}{\frac{\pi}{2}}$$
   $$m = 2 \times \frac{2}{\pi} = \frac{4}{\pi}$$

따라서 구하는 직선의 기울기는 $\frac{4}{\pi}$입니다.
