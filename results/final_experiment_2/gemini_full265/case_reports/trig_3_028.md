$0 \leq x < 2 \pi$일 때, 방정식 $\cos^{2} 3 x - \sin 3 x + 1 = 0$의 모든 실근의 합은?
① $\frac{3}{2} \pi$		② $\frac{7}{4} \pi$		③ $2 \pi$
④ $\frac{9}{4} \pi$		⑤ $\frac{5}{2} \pi$


## 원본 정답

## 원본 해설 전체

[정답] ⑤

[해설]
방정식 $\cos^{2} 3 x - \sin 3 x + 1 = 0$을 풀면
$\left( 1 - \sin^{2} 3 x \right) - \sin 3 x + 1 = 0$
$\sin^{2} 3 x + \sin 3 x - 2 = 0$, $\left( \sin 3 x + 2 \right) \left( \sin 3 x - 1 \right) = 0$
$\sin 3 x = 1$ ($\because$$-1\le\sin 3x\le1)$
$0 \leq x < 2 \pi$에서 $0 \leq 3 x < 6 \pi$이므로 이 범위에서 만족하는 $3 x$의 값은 $3 x = \frac{\pi}{2} , \frac{5}{2} \pi , \frac{9}{2} \pi$
즉, $x = \frac{1}{6} \pi , \frac{5}{6} \pi , \frac{9}{6} \pi$이므로 모든 $x$의 값의 합은 $\frac{5}{2} \pi$

### 생성 풀이 전체

주어진 방정식 $\cos^{2} 3 x - \sin 3 x + 1 = 0$을 풉니다.

1. **삼각함수의 성질 이용:**
   $\cos^{2} 3x = 1 - \sin^{2} 3x$이므로, 이를 방정식에 대입합니다.
   $(1 - \sin^{2} 3x) - \sin 3x + 1 = 0$
   $-\sin^{2} 3x - \sin 3x + 2 = 0$
   $\sin^{2} 3x + \sin 3x - 2 = 0$

2. **인수분해:**
   $(\sin 3x + 2)(\sin 3x - 1) = 0$
   여기서 $-1 \leq \sin 3x \leq 1$이므로, $\sin 3x + 2 = 0$은 해를 갖지 않습니다.
   따라서 $\sin 3x = 1$이어야 합니다.

3. **범위 설정:**
   $0 \leq x < 2\pi$이므로, $0 \leq 3x < 6\pi$입니다.
   $\sin \theta = 1$을 만족하는 $\theta$는 $\theta = \frac{\pi}{2} + 2n\pi$ ($n$은 정수)입니다.
   $0 \leq 3x < 6\pi$ 범위 내에서 가능한 $3x$의 값은 다음과 같습니다.
   $3x = \frac{\pi}{2}, \frac{\pi}{2} + 2\pi, \frac{\pi}{2} + 4\pi$
   $3x = \frac{\pi}{2}, \frac{5\pi}{2}, \frac{9\pi}{2}$

4. **$x$의 값 구하기:**
   $x = \frac{\pi}{6}, \frac{5\pi}{6}, \frac{9\pi}{6} = \frac{3\pi}{2}$

5. **모든 실근의 합:**
   $\frac{\pi}{6} + \frac{5\pi}{6} + \frac{3\pi}{2} = \frac{6\pi}{6} + \frac{3\pi}{2} = \pi + \frac{3\pi}{2} = \frac{5\pi}{2}$

따라서 모든 실근의 합은 $\frac{5\pi}{2}$입니다.
