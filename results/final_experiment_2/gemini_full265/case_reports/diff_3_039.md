## 원본 문제와 선택지

함수 $f (x) = x^{3} - 3 x^{2} + k$의 극댓값이 $\mathrm{9}$일 때, 함수 $f (x)$의 극솟값은? (단, $k$는 상수이다.)

④ $\mathrm{4}$		⑤ $\mathrm{5}$

## 원본 해설 전체

[정답] ⑤

[해설]
함수 $f (x) = x^{3} - 3 x^{2} + k$이므로 $f' (x) = 3 x^{2} - 6 x = 3 x (x - 2)$이다.
$f' (x) = 0$에서 $x = 0$ 또는 $x = 2$이므로 함수 $f (x)$의 증가와
감소를 표로 나타내면 다음과 같다.

$x$	$\cdots$	$\mathrm{0}$	$\cdots$	$\mathrm{2}$	$\cdots$
$f' (x)$	$+$	$\mathrm{0}$	$-$	$\mathrm{0}$	$+$
$f (x)$	$\nearrow$	$k$	$\searrow$	$k - 4$	$\nearrow$

이때 함수 $f (x)$는 $x = 0$에서 극댓값 $f (0) = k$를 가지므로 $k = 9$이다.
따라서 함수 $f (x)$는 $x = 2$에서 극솟값 $f (2) = k - 4 = 5$를 갖는다.

함수 $f(x) = x^3 - 3x^2 + k$의 극값을 구하기 위해 먼저 도함수를 구합니다.
$f'(x) = 3x^2 - 6x = 3x(x - 2)$

$f'(x) = 0$이 되는 $x$의 값은 $x = 0$ 또는 $x = 2$입니다.
함수 $f(x)$의 증감표를 생각해보면, $x=0$에서 극대이고 $x=2$에서 극소임을 알 수 있습니다.

1. **극댓값 구하기:**
   $x=0$일 때 극댓값은 $f(0) = 0^3 - 3(0)^2 + k = k$입니다.
   문제에서 극댓값이 9라고 하였으므로, $k = 9$입니다.

2. **극솟값 구하기:**
   $k=9$를 대입하면 함수는 $f(x) = x^3 - 3x^2 + 9$가 됩니다.
   $x=2$일 때 극솟값은 $f(2)$입니다.
   $f(2) = 2^3 - 3(2)^2 + 9$
   $f(2) = 8 - 3(4) + 9$
   $f(2) = 8 - 12 + 9$
   $f(2) = 5$

따라서 함수 $f(x)$의 극솟값은 5입니다.
