## 원본 문제와 선택지

두 양수 $a$, $b$에 대하여 함수 $f \left( x \right) = a \sin \frac{x}{b} + 2$의 최댓값이 $5$이고 주기가 $8 \pi$일 때, $a + b$의 값은?
① $6$		② $\frac{25}{4}$		③ $\frac{13}{2}$
④ $\frac{27}{4}$		⑤ $7$


## 원본 정답

⑤

## 원본 해설 전체

[정답] ⑤

[해설]
$f \left( x \right) = a \sin \frac{x}{b} + 2$의 최댓값이 $5$이고 $a > 0$이므로
$a + 2 = 5$    $\therefore$ $a = 3$
또 주기가 $8 \pi$이고 $b > 0$이므로
$\frac{2 \pi}{\frac{1}{b}} = 8 \pi$    $\therefore$ $b = 4$
$\therefore$ $a + b = 7$

함수 $f(x) = a \sin \frac{x}{b} + 2$에 대하여 다음 두 가지 조건을 이용합니다.

**1. 최댓값 조건**
함수 $f(x) = a \sin \frac{x}{b} + 2$에서 $\sin \frac{x}{b}$의 최댓값은 $1$입니다.
따라서 $f(x)$의 최댓값은 $a(1) + 2 = a + 2$입니다.
문제에서 최댓값이 $5$라고 하였으므로,
$a + 2 = 5$
$a = 3$

**2. 주기 조건**
함수 $f(x) = a \sin(kx)$의 주기는 $\frac{2\pi}{|k|}$입니다.
이 문제에서 $k = \frac{1}{b}$이므로, 주기는 $\frac{2\pi}{1/b} = 2\pi b$입니다.
문제에서 주기가 $8\pi$라고 하였으므로,
$2\pi b = 8\pi$
$b = 4$

**3. $a + b$의 값 계산**
구하는 값은 $a + b$이므로,
$a + b = 3 + 4 = 7$

따라서 정답은 ⑤번입니다.
