## 원본 문제와 선택지

함수 $f \left( x \right) = a \sin x + 1$의 최댓값을 $M$, 최솟값을 $m$이라 하자. $M - m = 6$일 때, 양수 $a$의 값은?
① $2$		② $\frac{5}{2}$		③ $3$
④ $\frac{7}{2}$		⑤ $4$

## 원본 해설 전체

[정답] ③

[해설]
함수 $f (x) = a \sin x + 1$의 그래프는
함수 $y = a \sin x$의 그래프를 $y$축의 방향으로 $1$만큼 평행이동한 것이다.
조건 $a > 0$에서
$y = a \sin x$가 최대일 때 $f (x)$는 최대이고,
$y = a \sin x$가 최소일 때 $f (x)$는 최소이므로
함수 $f (x)$는 $\sin x = 1$일 때 최댓값 $M = a + 1$,
$\sin x = - 1$일 때 최솟값 $m = - a + 1$을 갖는다.
따라서 $M - m =$$(a + 1) - (- a + 1) =$$2 a$
$2 a = 6$이므로 $a = 3$이다.

### 생성 풀이 전체

함수 $f(x) = a \sin x + 1$에서 $\sin x$의 값의 범위는 $-1 \le \sin x \le 1$입니다.

1. **최댓값 $M$ 구하기:**
   $a > 0$이므로, $\sin x = 1$일 때 최댓값을 갖습니다.
   $M = a(1) + 1 = a + 1$

2. **최솟값 $m$ 구하기:**
   $a > 0$이므로, $\sin x = -1$일 때 최솟값을 갖습니다.
   $m = a(-1) + 1 = -a + 1$

3. **조건 $M - m = 6$ 이용하기:**
   $M - m = (a + 1) - (-a + 1) = 6$
   $a + 1 + a - 1 = 6$
   $2a = 6$
   $a = 3$

따라서 양수 $a$의 값은 3입니다.

최종정답: ③
