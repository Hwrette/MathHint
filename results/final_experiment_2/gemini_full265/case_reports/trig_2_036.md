$0 \le x < 2 \pi$에서 $x$에 대한 부등식
$\left( 2 a + 6 \right) \cos x - a \sin^{2} x + a + 12 < 0$
의 해가 존재하도록 하는 자연수 $a$의 최솟값을 구하시오.


## 원본 정답

## 원본 해설 전체

[정답] $7$

[해설]
$(2 a + 6) \cos x - a \sin^{2} x + a + 12 < 0$
$(2 a + 6) \cos x - a (1 - \cos^{2} x) + a + 12 < 0$
$a \cos^{2} x + (2 a + 6) \cos x + 12 < 0$
$\left( a \cos x + 6 \right) \left( \cos x + 2 \right) < 0$에서
$\cos x + 2 > 0$이므로 $a \cos x + 6 < 0$
$a > 0$이므로 $\cos x < - \frac{6}{a}$
$0 \le x < 2 \pi$에서 부등식 $\cos x < - \frac{6}{a}$의 해가 존재하기 위해서는 $- \frac{6}{a} > - 1$이어야 한다.
따라서 $a > 6$이며 자연수 $a$의 최솟값은 $7$

### 생성 풀이 전체

주어진 부등식 $\left( 2 a + 6 \right) \cos x - a \sin^{2} x + a + 12 < 0$에서 $\sin^2 x = 1 - \cos^2 x$를 대입합니다.

$-a(1 - \cos^2 x) + (2a + 6) \cos x + a + 12 < 0$
$-a + a \cos^2 x + (2a + 6) \cos x + a + 12 < 0$
$a \cos^2 x + (2a + 6) \cos x + 12 < 0$

여기서 $t = \cos x$라 하면, $0 \le x < 2\pi$이므로 $-1 \le t \le 1$입니다.
부등식은 $f(t) = a t^2 + (2a + 6) t + 12 < 0$이 되고, 이 부등식의 해가 존재한다는 것은 구간 $[-1, 1]$에서 $f(t) < 0$을 만족하는 $t$가 적어도 하나 존재한다는 뜻입니다.

$f(t) = a(t^2 + 2t) + 6t + 12 < 0$
$a(t^2 + 2t) < -6t - 12$
$a(t^2 + 2t) < -6(t + 2)$

$t \in [-1, 1]$일 때 $t^2 + 2t = (t+1)^2 - 1$은 $0$보다 크거나 같으므로, $a > 0$인 자연수 조건에서 양변을 $t^2 + 2t$로 나누면:
$a < \frac{-6(t+2)}{t^2 + 2t} = \frac{-6(t+2)}{t(t+2)} = -\frac{6}{t}$

즉, $a < -\frac{6}{t}$를 만족하는 $t \in [-1, 1]$이 존재해야 합니다.
$t$의 범위가 $[-1, 1]$이므로, $-\frac{6}{t}$의 값의 범위를 구하면:
- $t \in (0, 1]$일 때, $-\frac{6}{t} \in (-\infty, -6]$
- $t \in [-1, 0)$일 때, $-\frac{6}{t} \in [6, \infty)$

$a$는 자연수이므로 $a > 0$입니다. 따라서 $a < -\frac{6}{t}$를 만족하려면 $-\frac{6}{t}$가 양수여야 하므로 $t \in [-1, 0)$ 범위에서 해가 존재해야 합니다.
$t \in [-1, 0)$일 때 $-\frac{6}{t}$의 최솟값은 $t \to -1$일 때 $6$입니다.
즉, $a < -\frac{6}{t}$를 만족하는 $t$가 존재하려면 $a$는 $-\frac{6}{t}$의 최솟값인 $6$보다 작아야 합니다.
(구체적으로 $t$가 $-1$에 가까워질수록 $-\frac{6}{t}$는 $6$에 가까워지며 커지므로, $a < 6$이면 부등식을 만족하는 $t$가 존재합니다.)

하지만 문제에서 $a$가 자연수이고, $f(t) = a t^2 + (2a + 6) t + 12 < 0$에서 $t=-1$을 대입하면:
$f(-1) = a - 2a - 6 + 12 = -a + 6$
$f(-1) < 0$이 되려면 $a > 6$이어야 합니다.

다시 확인하면, $f(t) = a t^2 + (2a + 6) t + 12 < 0$에서 $t \in [-1, 1]$일 때 최솟값이 $0$보다 작아야 합니다.
$f(-1) = 6 - a$
$f(1) = a + 2a + 6 + 12 = 3a + 18$
$f(t)$는 아래로 볼록한 이차함수이므로, 구간 내에서 최솟값은 꼭짓점 $t = -\frac{2a+6}{2a} = -1 - \frac{3}{a}$에서 갖거나 양 끝점에서 갖습니다.
꼭짓점 $t = -1 - \frac{3}{a}$는 항상 $-1$보다 작으므로, 구간 $[-1, 1]$에서 $f(t)$는 $t=-1$에서 최솟값을 갖습니다.
따라서 $f(-1) < 0$이어야 하므로 $6 - a < 0$, 즉 $a > 6$입니다.
자연수 $a$의 최솟값은 $7$입니다.

최종정답: 7
