## 원본 문제와 선택지

함수 $f \left( x \right) = x^{3} + a x^{2} + b$는 $x = - 2$에서 극대이다. 함수 $f \left( x \right)$의 극솟값이 $5$일 때, $f \left( 3 \right)$의 값을 구하시오. (단, $a$와 $b$는 상수이다.)


## 원본 정답

$59$

## 원본 해설 전체

[정답] $59$

[해설]
$f \left( x \right) = x^{3} + a x^{2} + b$에서    $f' \left( x \right) = 3 x^{2} + 2 a x$
함수 $f \left( x \right)$가 $x = - 2$에서 극댓값을 가지므로    $f' \left( - 2 \right) = 0$
$f' \left( - 2 \right) = 12 - 4 a$이므로    $a = 3$
$f \left( x \right) = x^{3} + 3 x^{2} + b$, $f' \left( x \right) = 3 x^{2} + 6 x$
$f' \left( x \right) = 0$에서    $x = - 2$ 또는 $x = 0$
함수 $f \left( x \right)$의 증가와 감소를 표로 나타내면 다음과 같다.

$x$	$\cdots$	$- 2$	$\cdots$	$0$	$\cdots$
$f' \left( x \right)$	$+$	$0$	$-$	$0$	$+$
$f \left( x \right)$	$\nearrow$		$\searrow$		$\nearrow$

함수 $f \left( x \right)$가 $x = 0$에서 극솟값을 가지고, 함수 $f \left( x \right)$의 극솟값이 $5$이므로
$f \left( 0 \right) = 5$,    $b = 5$
따라서 $f \left( x \right) = x^{3} + 3 x^{2} + 5$이므로
$f \left( 3 \right) = 27 + 27 + 5 = 59$

### 생성 풀이 전체

함수 $f(x) = x^3 + ax^2 + b$를 미분하면
$f'(x) = 3x^2 + 2ax = x(3x + 2a)$입니다.

문제에서 $f(x)$가 $x = -2$에서 극대라고 하였으므로, $f'(-2) = 0$이어야 합니다.
$f'(-2) = 3(-2)^2 + 2a(-2) = 12 - 4a = 0$
따라서 $4a = 12$에서 $a = 3$입니다.

이제 $f'(x) = 3x^2 + 6x = 3x(x + 2)$가 됩니다.
$f'(x) = 0$이 되는 $x$의 값은 $x = -2$ 또는 $x = 0$입니다.
$f''(x) = 6x + 6$이므로,
$f''(-2) = -12 + 6 = -6 < 0$ (극대)
$f''(0) = 6 > 0$ (극소)
따라서 함수 $f(x)$는 $x = 0$에서 극솟값을 가집니다.

문제에서 극솟값이 $5$라고 하였으므로,
$f(0) = 0^3 + 3(0)^2 + b = 5$
따라서 $b = 5$입니다.

구해진 $a$와 $b$를 대입하면 함수는
$f(x) = x^3 + 3x^2 + 5$가 됩니다.

마지막으로 $f(3)$의 값을 구하면
$f(3) = 3^3 + 3(3^2) + 5$
$f(3) = 27 + 27 + 5 = 59$

최종정답: 59
