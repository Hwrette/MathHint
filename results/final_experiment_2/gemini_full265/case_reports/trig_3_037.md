$0 < x \leq 2 \pi$일 때, 방정식 $\sin^{2} x$$= \cos^{2} x + \cos x$와 부등식 $\sin x > \cos x$를 동시에 만족시키는 모든 $x$의 값의 합은?
① $\frac{4}{3} \pi$		② $\frac{5}{3} \pi$		③ $2 \pi$
④ $\frac{7}{3} \pi$		⑤ $\frac{8}{3} \pi$

## 원본 해설 전체

[정답] ①

[해설]
$\sin^{2} x$$= \cos^{2} x + \cos x$, $1 - \cos^{2} x = \cos^{2} x + \cos x$
$2 \cos^{2} x + \cos x - 1 = 0$
$\left( 2 \cos x - 1 \right) \left( \cos x + 1 \right) = 0$에서
$\cos x = \frac{1}{2}$ 또는 $\cos x = - 1$
$0 < x \leq 2 \pi$이므로
$\cos x = \frac{1}{2}$에서 $x = \frac{\pi}{3}$ 또는 $x = \frac{5}{3} \pi$
$\cos x = - 1$에서 $x = \pi$
$\sin \frac{\pi}{3} > \cos \frac{\pi}{3}$, $\sin \frac{5}{3} \pi < \cos \frac{5}{3} \pi$, $\sin \pi > \cos \pi$이므로 구하는 모든 $x$의 값의 합은 $\frac{\pi}{3} + \pi = \frac{4}{3} \pi$

### 생성 풀이 전체

주어진 방정식 $\sin^2 x = \cos^2 x + \cos x$를 삼각함수의 기본 관계식 $\sin^2 x = 1 - \cos^2 x$를 이용하여 $\cos x$에 대한 방정식으로 바꿉니다.

$1 - \cos^2 x = \cos^2 x + \cos x$
$2\cos^2 x + \cos x - 1 = 0$

이 식은 $\cos x$에 대한 이차방정식으로, 인수분해하면 다음과 같습니다.
$(2\cos x - 1)(\cos x + 1) = 0$

따라서 $\cos x = \frac{1}{2}$ 또는 $\cos x = -1$입니다.

**1) $\cos x = \frac{1}{2}$인 경우 ($0 < x \leq 2\pi$)**
$x = \frac{\pi}{3}$ 또는 $x = \frac{5\pi}{3}$

**2) $\cos x = -1$인 경우 ($0 < x \leq 2\pi$)**
$x = \pi$

이제 부등식 $\sin x > \cos x$를 만족하는지 확인합니다.
- $x = \frac{\pi}{3}$일 때: $\sin \frac{\pi}{3} = \frac{\sqrt{3}}{2} \approx 0.866$, $\cos \frac{\pi}{3} = 0.5$. $\frac{\sqrt{3}}{2} > 0.5$이므로 **성립**.
- $x = \pi$일 때: $\sin \pi = 0$, $\cos \pi = -1$. $0 > -1$이므로 **성립**.
- $x = \frac{5\pi}{3}$일 때: $\sin \frac{5\pi}{3} = -\frac{\sqrt{3}}{2} \approx -0.866$, $\cos \frac{5\pi}{3} = 0.5$. $-0.866 > 0.5$는 **거짓**.

따라서 조건을 만족하는 $x$의 값은 $\frac{\pi}{3}$와 $\pi$입니다.
이들의 합은 $\frac{\pi}{3} + \pi = \frac{4\pi}{3}$입니다.

최종정답: ①
