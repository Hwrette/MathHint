## 원본 문제와 선택지

다항함수 $f \left( x \right)$에 대하여 함수 $g \left( x \right)$를
$g \left( x \right) = 5 x^{2} + x f \left( x \right)$
라 하자. $f \left( 3 \right) = 2$, $f' \left( 3 \right) = 1$일 때, $g' \left( 3 \right)$의 값은?
① $31$		② $32$		③ $33$
④ $34$		⑤ $35$


## 원본 정답

⑤

## 원본 해설 전체

[정답] ⑤

[해설]
$g \left( x \right) = 5 x^{2} + x f \left( x \right)$에서
$g' \left( x \right)$$= 10 x + f \left( x \right) + x f' \left( x \right)$
이므로 양변에 $x = 3$을 대입하면
$g' \left( 3 \right)$$= 30 + f \left( 3 \right) + 3 f' \left( 3 \right)$
$= 30 + 2 + 3$
$= 35$

### 생성 풀이 전체

주어진 함수 $g(x) = 5x^2 + xf(x)$를 $x$에 대하여 미분하면 곱의 미분법에 의해 다음과 같습니다.

$g'(x) = \frac{d}{dx}(5x^2) + \frac{d}{dx}(xf(x))$
$g'(x) = 10x + (1 \cdot f(x) + x \cdot f'(x))$
$g'(x) = 10x + f(x) + xf'(x)$

이제 $x=3$을 대입하여 $g'(3)$의 값을 구합니다. 문제에서 주어진 조건 $f(3) = 2$, $f'(3) = 1$을 대입하면:

$g'(3) = 10(3) + f(3) + 3f'(3)$
$g'(3) = 30 + 2 + 3(1)$
$g'(3) = 30 + 2 + 3$
$g'(3) = 35$

따라서 $g'(3)$의 값은 35입니다.

최종정답: ⑤
