## 원본 문제와 선택지

$0 < x < 2 \pi$일 때, 방정식 $\cos^{2} x - \sin x = 1$의 모든 실근의 합은 $\frac{q}{p} \pi$이다. $p + q$의 값을 구하시오.
(단, $p$, $q$는 서로소인 자연수이다.)


## 원본 정답

$\mathbf{7}$

## 원본 해설 전체

[정답] $\mathbf{7}$

[해설]
$\cos^{2} x - \sin x = 1$
$\left( 1 - \sin^{2} x \right) - \sin x = 1$
$\sin^{2} x + \sin x = 0$
$\sin x \left( \sin x + 1 \right) = 0$
$\sin x = 0$ 또는 $\sin x = - 1$
$x = \pi$ 또는 $x = \frac{3}{2} \pi$
따라서 모든 실근의 합은 $\pi + \frac{3}{2} \pi = \frac{5}{2} \pi$이므로
$p + q = 2 + 5 = 7$

### 생성 풀이 전체

주어진 방정식 $\cos^{2} x - \sin x = 1$을 삼각함수의 기본 성질을 이용하여 $\sin x$에 대한 식으로 변형합니다.

$\cos^{2} x = 1 - \sin^{2} x$이므로, 이를 방정식에 대입하면:
$(1 - \sin^{2} x) - \sin x = 1$

양변에서 1을 빼고 정리하면:
$-\sin^{2} x - \sin x = 0$
$\sin^{2} x + \sin x = 0$

인수분해하면:
$\sin x (\sin x + 1) = 0$

따라서 $\sin x = 0$ 또는 $\sin x = -1$입니다.

범위 $0 < x < 2\pi$에서 각 경우의 해를 구합니다.

1) $\sin x = 0$인 경우:
$x = \pi$ (범위 내의 해)

2) $\sin x = -1$인 경우:
$x = \frac{3}{2}\pi$ (범위 내의 해)

따라서 방정식의 모든 실근의 합은 다음과 같습니다.
$\pi + \frac{3}{2}\pi = \frac{5}{2}\pi$

문제에서 합이 $\frac{q}{p} \pi$라고 하였으므로, $q = 5, p = 2$입니다.
$p$와 $q$는 서로소인 자연수 조건을 만족합니다.

따라서 $p + q = 2 + 5 = 7$입니다.

최종정답: 7
