### 생성 풀이 전체

주어진 방정식 $2x^3 - 3x^2 - 12x + k = 0$이 서로 다른 세 실근을 갖기 위해서는, 함수 $f(x) = 2x^3 - 3x^2 - 12x$에 대하여 $f(x) = -k$가 서로 다른 세 교점을 가져야 합니다.

**1. $f(x)$의 극값 구하기**
$f(x) = 2x^3 - 3x^2 - 12x$를 미분하면,
$f'(x) = 6x^2 - 6x - 12$
$f'(x) = 6(x^2 - x - 2) = 6(x - 2)(x + 1)$

$f'(x) = 0$이 되는 $x$의 값은 $x = -1$ 또는 $x = 2$입니다.

**2. 극댓값과 극솟값 계산**
*   $x = -1$일 때 (극댓값):
    $f(-1) = 2(-1)^3 - 3(-1)^2 - 12(-1) = -2 - 3 + 12 = 7$
*   $x = 2$일 때 (극솟값):
    $f(2) = 2(2)^3 - 3(2)^2 - 12(2) = 16 - 12 - 24 = -20$

**3. 서로 다른 세 실근을 가질 조건**
방정식 $f(x) = -k$가 서로 다른 세 실근을 가지려면, $-k$의 값이 극솟값과 극댓값 사이에 있어야 합니다.
$-20 < -k < 7$

각 변에 $-1$을 곱하면 부등호의 방향이 바뀝니다.
$-7 < k < 20$

**4. 정수 $k$의 개수 구하기**
부등식 $-7 < k < 20$을 만족하는 정수 $k$는 $-6, -5, \dots, 19$입니다.
개수는 $19 - (-6) + 1 = 19 + 6 + 1 = 26$개입니다.

따라서 정수 $k$의 개수는 26개입니다.
