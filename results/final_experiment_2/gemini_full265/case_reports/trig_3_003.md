근과 계수의 관계에 의하여

$1 + 2 \sin \theta \cos \theta = \frac{1}{25}$이므로 $1 + 2 \times \left( - \frac{a}{5} \right) = \frac{1}{25}$
따라서 $a = \frac{12}{5}$

### 생성 풀이 전체

이차방정식 $5x^2 + x - a = 0$의 두 근이 $\sin \theta, \cos \theta$이므로, 이차방정식의 근과 계수의 관계에 의해 다음이 성립합니다.

1) 두 근의 합: $\sin \theta + \cos \theta = -\frac{1}{5}$
2) 두 근의 곱: $\sin \theta \cos \theta = -\frac{a}{5}$

삼각함수의 기본 항등식인 $\sin^2 \theta + \cos^2 \theta = 1$을 이용하기 위해, 두 근의 합의 식을 양변 제곱합니다.

$(\sin \theta + \cos \theta)^2 = \left(-\frac{1}{5}\right)^2$
$\sin^2 \theta + 2\sin \theta \cos \theta + \cos^2 \theta = \frac{1}{25}$

위 식에 $\sin^2 \theta + \cos^2 \theta = 1$과 $\sin \theta \cos \theta = -\frac{a}{5}$를 대입합니다.

$1 + 2\left(-\frac{a}{5}\right) = \frac{1}{25}$
$1 - \frac{2a}{5} = \frac{1}{25}$

이제 $a$에 대해 정리합니다.
$-\frac{2a}{5} = \frac{1}{25} - 1$
$-\frac{2a}{5} = \frac{1 - 25}{25}$
$-\frac{2a}{5} = -\frac{24}{25}$

양변에 $-\frac{5}{2}$를 곱하면,
$a = \left(-\frac{24}{25}\right) \times \left(-\frac{5}{2}\right)$
$a = \frac{24 \times 5}{25 \times 2}$
$a = \frac{12}{5}$

따라서 상수 $a$의 값은 $\frac{12}{5}$입니다.

1) 두 근의 합: $\sin \theta + \cos \theta = -\frac{1}{5}$
2) 두 근의 곱: $\sin \theta \cos \theta = -\frac{a}{5}$

위의 두 근의 합 식의 양변을 제곱하면 다음과 같습니다.
$(\sin \theta + \cos \theta)^2 = \left(-\frac{1}{5}\right)^2$

이제 근과 계수의 관계에서 구한 두 근의 곱 식과 비교하면,
$-\frac{a}{5} = -\frac{12}{25}$
$a = 5 \times \frac{12}{25} = \frac{12}{5}$
