## 원본 해설 전체

[정답] ①

[해설]
$f' \left( x \right)$$= 6 x^{2} - 6$
$= 6 \left( x + 1 \right) \left( x - 1 \right)$
$f' \left( x \right) = 0$에서 $x = - 1$ 또는 $x = 1$
함수 $f \left( x \right)$의 증가와 감소를 표로 나타내면

$x$	$\cdots$	$\mathrm{- 1}$	$\cdots$	$\mathrm{1}$	$\cdots$
$f' \left( x \right)$	+	$\mathrm{0}$	-	$\mathrm{0}$	+
$f \left( x \right)$	$\nearrow$	$a + 4$	$\searrow$	$a - 4$	$\nearrow$

함수 $f \left( x \right)$는 $x = 1$에서 극솟값 $a - 4$를 갖는다.
따라서
$a - 4 = 2$, $a = 6$

### 생성 풀이 전체

함수 $f(x) = 2x^3 - 6x + a$의 극값을 구하기 위해 먼저 도함수를 구합니다.

$f'(x) = 6x^2 - 6$

극값을 갖는 지점을 찾기 위해 $f'(x) = 0$으로 놓으면,
$6(x^2 - 1) = 0$
$6(x - 1)(x + 1) = 0$
따라서 $x = 1$ 또는 $x = -1$에서 극값을 갖습니다.

이계도함수를 구하여 극대와 극소를 판별하면,
$f''(x) = 12x$
$f''(1) = 12 > 0$ 이므로 $x = 1$에서 극솟값을 갖습니다.
$f''(-1) = -12 < 0$ 이므로 $x = -1$에서 극댓값을 갖습니다.

문제에서 극솟값이 2라고 하였으므로, $f(1) = 2$를 만족해야 합니다.
$f(1) = 2(1)^3 - 6(1) + a = 2$
$2 - 6 + a = 2$
$-4 + a = 2$
$a = 6$

따라서 상수 $a$의 값은 6입니다.
