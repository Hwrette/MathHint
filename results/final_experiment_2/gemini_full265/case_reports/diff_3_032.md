[해설]
접점의 $x$좌표를 $t$라 하면 $y' = - 3 x^{2} - 2 x + 1$
$y = (- 3 t^{2} - 2 t + 1) (x - t) - t^{3} - t^{2} + t$
$0 = 3 t^{3} + 2 t^{2} - t - t^{3} - t^{2} + t$
$2 t^{3} + t^{2} = 0$, $t^{2} (2 t + 1) = 0$
$t = 0$, $- \frac{1}{2}$, $y' = 1$, $\frac{5}{4}$, $\therefore$$1 + \frac{5}{4} = \frac{9}{4}$

곡선 $f(x) = -x^3 - x^2 + x$ 위의 점 $(t, f(t))$에서의 접선의 방정식을 구합니다.

1. **접선의 기울기 구하기:**
   $f'(x) = -3x^2 - 2x + 1$이므로, 점 $(t, f(t))$에서의 접선의 기울기는 $f'(t) = -3t^2 - 2t + 1$입니다.

2. **접선의 방정식 세우기:**
   접선의 방정식은 $y - f(t) = f'(t)(x - t)$입니다.
   $y - (-t^3 - t^2 + t) = (-3t^2 - 2t + 1)(x - t)$

3. **원점을 지나는 조건 적용:**
   접선이 원점 $(0, 0)$을 지나므로 $x=0, y=0$을 대입합니다.
   $0 - (-t^3 - t^2 + t) = (-3t^2 - 2t + 1)(0 - t)$
   $t^3 + t^2 - t = -t(-3t^2 - 2t + 1)$
   $t^3 + t^2 - t = 3t^3 + 2t^2 - t$

4. **방정식 풀기:**
   $2t^3 + t^2 = 0$
   $t^2(2t + 1) = 0$
   따라서 $t = 0$ 또는 $t = -\frac{1}{2}$입니다.

5. **기울기 구하기:**
   기울기 $m = f'(t) = -3t^2 - 2t + 1$에 각 $t$값을 대입합니다.
   - $t = 0$일 때: $m_1 = -3(0)^2 - 2(0) + 1 = 1$

6. **기울기의 합:**
   $m_1 + m_2 = 1 + \frac{5}{4} = \frac{9}{4}$
