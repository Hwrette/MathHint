## 원본 해설 전체

[정답] ⑤

[해설]
$\tan 2 x \sin 2 x = \frac{\sin^{2} 2 x}{\cos 2 x} = \frac{1 - \cos^{2} 2 x}{\cos 2 x} = \frac{3}{2}$

$2 \cos^{2} 2 x + 3 \cos 2 x - 2 = 0$, $\left( 2 \cos 2 x - 1 \right) \left( \cos 2 x + 2 \right) = 0$
$\cos 2 x = \frac{1}{2}$
$x = \pi$에 대하여 서로 대칭인 두 쌍의 실근이므로
모든 해의 합은 $4 \pi$이다.

### 생성 풀이 전체

주어진 방정식 $\tan 2x \sin 2x = \frac{3}{2}$을 풀어봅시다.

1. **방정식 변형:**
   $\tan 2x = \frac{\sin 2x}{\cos 2x}$이므로,
   $\frac{\sin 2x}{\cos 2x} \cdot \sin 2x = \frac{3}{2}$
   $\frac{\sin^2 2x}{\cos 2x} = \frac{3}{2}$

2. **삼각함수 항등식 이용:**
   $\sin^2 2x = 1 - \cos^2 2x$이므로,
   $\frac{1 - \cos^2 2x}{\cos 2x} = \frac{3}{2}$
   $2(1 - \cos^2 2x) = 3 \cos 2x$
   $2 - 2 \cos^2 2x = 3 \cos 2x$
   $2 \cos^2 2x + 3 \cos 2x - 2 = 0$

3. **이차방정식 풀이:**
   $(2 \cos 2x - 1)(\cos 2x + 2) = 0$
   $\cos 2x = \frac{1}{2}$ 또는 $\cos 2x = -2$
   $\cos 2x$의 값은 $-1$과 $1$ 사이여야 하므로, $\cos 2x = \frac{1}{2}$만 가능합니다.

4. **범위 확인 및 해 구하기:**
   $0 \leq x \leq 2\pi$이므로 $0 \leq 2x \leq 4\pi$입니다.
   $\cos 2x = \frac{1}{2}$을 만족하는 $2x$의 값은:
   $2x = \frac{\pi}{3}, \frac{5\pi}{3}, \frac{7\pi}{3}, \frac{11\pi}{3}$
   따라서 $x$의 값은:
   $x = \frac{\pi}{6}, \frac{5\pi}{6}, \frac{7\pi}{6}, \frac{11\pi}{6}$

   (참고: $\cos 2x = \frac{1}{2}$일 때 $\cos 2x \neq 0$이므로 $\tan 2x$는 정의됩니다.)

5. **해의 합 구하기:**
   모든 해의 합은 $\frac{\pi}{6} + \frac{5\pi}{6} + \frac{7\pi}{6} + \frac{11\pi}{6} = \frac{24\pi}{6} = 4\pi$입니다.

### 생성 풀이 전체

주어진 방정식 $\tan 2x \sin 2x = \frac{3}{2}$을 풀어보겠습니다.

1. **방정식 변형:**
   $\tan 2x = \frac{\sin 2x}{\cos 2x}$이므로, 주어진 식은 다음과 같습니다.
   $$\frac{\sin 2x}{\cos 2x} \cdot \sin 2x = \frac{3}{2}$$
   $$\frac{\sin^2 2x}{\cos 2x} = \frac{3}{2}$$
   $\sin^2 2x = 1 - \cos^2 2x$를 대입하면,
   $$\frac{1 - \cos^2 2x}{\cos 2x} = \frac{3}{2}$$

2. **이차방정식 풀이:**
   $t = \cos 2x$라 하면 ($|t| \leq 1$),
   $2t^2 + 3t - 2 = 0$
   $(2t - 1)(t + 2) = 0$
   $t = \frac{1}{2}$ 또는 $t = -2$
   $|t| \leq 1$이므로 $\cos 2x = \frac{1}{2}$입니다.

   $0 \leq x \leq 2\pi$이므로 $0 \leq 2x \leq 4\pi$입니다.
   $\cos 2x = \frac{1}{2}$를 만족하는 $2x$의 값은:
   $2x = \frac{\pi}{3}, \frac{5\pi}{3}, \frac{7\pi}{3}, \frac{11\pi}{3}$
   따라서 $x$의 값은:
   $x = \frac{\pi}{6}, \frac{5\pi}{6}, \frac{7\pi}{6}, \frac{11\pi}{6}$

4. **해의 합:**
   모든 해의 합은 $\frac{\pi + 5\pi + 7\pi + 11\pi}{6} = \frac{24\pi}{6} = 4\pi$입니다.
