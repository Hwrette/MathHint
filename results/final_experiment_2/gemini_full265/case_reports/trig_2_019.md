## 원본 문제와 선택지

좌표평면에서 곡선 $y = \sqrt{x} \quad \left( x > 0 \right)$ 위의 점 ${\mathrm{{P}}}$에 대하여 동경 ${\mathrm{{O P}}}$가 나타내는 각의 크기를 $\theta$라 하자. $\cos^{2} \theta - 2 \sin^{2} \theta = - 1$일 때, 선분 $\mathrm{O P}$의 길이는? (단, ${\mathrm{{O}}}$는 원점이고, $x$축의 양의 방향을 시초선으로 한다.)
① $\frac{1}{2}$		② $\frac{\sqrt{2}}{2}$		③ $\frac{\sqrt{3}}{2}$
④ $\mathrm{1}$		⑤ $\frac{\sqrt{5}}{2}$

## 원본 해설 전체

[정답] ③

[해설]
점 $\mathrm{P} \left( t , \sqrt{t} \right) \quad \left( t > 0 \right)$에 대하여 ${\bar{\mathrm{O P}}} = \sqrt{t^{2} + t}$이므로
$\sin \theta = \frac{\sqrt{t}}{\sqrt{t^{2} + t}}$, $\cos \theta = \frac{t}{\sqrt{t^{2} + t}}$이다.
$\cos^{2} \theta - 2 \sin^{2} \theta = \frac{t^{2}}{t^{2} + t} - \frac{2 t}{t^{2} + t} = - 1$에서
$t^{2} - 2 t = - t^{2} - t$, $t \left( 2 t - 1 \right) = 0$
$t > 0$이므로 $t = \frac{1}{2}$이고 점 ${\mathrm{{P}}}$는 $\mathrm{P} \left( \frac{1}{2} , \frac{\sqrt{2}}{2} \right)$이다.
따라서 ${\bar{\mathrm{O P}}} = \sqrt{\left( \frac{1}{2} \right)^{2} + \left( \frac{\sqrt{2}}{2} \right)^{2}} = \frac{\sqrt{3}}{2}$

### 생성 풀이 전체

점 $\mathrm{P}$의 좌표를 $(x, y)$라 하면, 곡선 $y = \sqrt{x}$ 위의 점이므로 $y^2 = x$ ($x > 0$)가 성립합니다.
점 $\mathrm{P}$의 좌표를 $(x, \sqrt{x})$라 하면, 동경 $\mathrm{OP}$가 나타내는 각 $\theta$에 대하여 다음이 성립합니다.
$\cos \theta = \frac{x}{\sqrt{x^2 + (\sqrt{x})^2}} = \frac{x}{\sqrt{x^2 + x}}$, $\sin \theta = \frac{\sqrt{x}}{\sqrt{x^2 + x}}$

주어진 식 $\cos^2 \theta - 2 \sin^2 \theta = -1$에 대입합니다.
$\cos^2 \theta - 2(1 - \cos^2 \theta) = -1$
$3 \cos^2 \theta - 2 = -1$
$3 \cos^2 \theta = 1$
$\cos^2 \theta = \frac{1}{3}$

이제 $\cos^2 \theta = \frac{x^2}{x^2 + x} = \frac{x}{x+1}$이므로,
$\frac{x}{x+1} = \frac{1}{3}$
$3x = x + 1$
$2x = 1 \implies x = \frac{1}{2}$

점 $\mathrm{P}$의 좌표는 $(\frac{1}{2}, \sqrt{\frac{1}{2}})$입니다.
선분 $\mathrm{OP}$의 길이는 원점 $(0, 0)$과 점 $\mathrm{P}$ 사이의 거리이므로,
$\mathrm{OP} = \sqrt{x^2 + y^2} = \sqrt{x^2 + x}$
$x = \frac{1}{2}$을 대입하면,
$\mathrm{OP} = \sqrt{(\frac{1}{2})^2 + \frac{1}{2}} = \sqrt{\frac{1}{4} + \frac{2}{4}} = \sqrt{\frac{3}{4}} = \frac{\sqrt{3}}{2}$

따라서 선분 $\mathrm{OP}$의 길이는 $\frac{\sqrt{3}}{2}$입니다.

$\frac{x}{x^2} = 2$
$\frac{1}{x} = 2$ 이므로 $x = \frac{1}{2}$입니다.
$y^2 = x = \frac{1}{2}$이므로 $y = \sqrt{\frac{1}{2}} = \frac{\sqrt{2}}{2}$입니다. (단, $x>0$이므로 $y>0$)
