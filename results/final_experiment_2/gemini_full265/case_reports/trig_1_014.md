## 원본 문제와 선택지

두 상수 $a \quad \left( a > 0 \right)$, $b$에 대하여 함수 $y = a \sin a x + b$의 주기가 $\pi$이고 최솟값이 $\mathrm{5}$일 때, $a + b$의 값은?
① $\mathrm{5}$		② $\mathrm{6}$		③ $\mathrm{7}$
④ $\mathrm{8}$		⑤ $\mathrm{9}$


## 원본 정답

⑤

## 원본 해설 전체

[정답] ⑤

[해설]
$y = a \sin a x + b$의 주기가 $\pi$이고 $a > 0$이므로
$\frac{2 \pi}{a} = \pi$    $\therefore$ $a = 2$
최솟값이 $5$이므로
$- a + b = 5$    $\therefore$ $b = 7$
$\therefore$ $a + b = 9$

### 생성 풀이 전체

함수 $y = a \sin(ax) + b$ ($a > 0$)에 대하여 다음 두 가지 조건을 이용합니다.

**1. 주기 조건**
함수 $y = a \sin(ax) + b$의 주기는 $\frac{2\pi}{|a|}$입니다.
문제에서 주기가 $\pi$라고 하였으므로,
$$\frac{2\pi}{a} = \pi$$
이를 풀면 $a = 2$가 됩니다. ($a > 0$ 조건 만족)

**2. 최솟값 조건**
함수 $y = a \sin(ax) + b$에서 $\sin(ax)$의 값은 $-1$에서 $1$ 사이의 값을 가집니다.
따라서 이 함수의 최솟값은 $-a + b$입니다.
문제에서 최솟값이 $5$라고 하였으므로,
$$-a + b = 5$$
위에서 구한 $a = 2$를 대입하면,
$$-2 + b = 5$$
$$b = 7$$

**3. 최종 계산**
구하고자 하는 값은 $a + b$이므로,
$$a + b = 2 + 7 = 9$$

따라서 정답은 ⑤번입니다.

최종정답: ⑤
