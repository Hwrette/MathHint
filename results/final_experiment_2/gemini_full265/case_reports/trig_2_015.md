[해설]
함수 $f (x) = a - \sqrt{3} \tan 2 x$의 그래프의 주기는 $\frac{\pi}{2}$이다.
함수 $f (x)$가 닫힌구간 $\left[ - \frac{\pi}{6} , b \right]$에서 최댓값과 최솟값을 가지므로
$- \frac{\pi}{6} < b < \frac{\pi}{4}$
한편, 함수 $y = f (x)$의 그래프는 구간 $\left[ - \frac{\pi}{6} , b \right]$에서 $x$의 값이 증가할 때, $y$의 값은 감소한다.
함수 $f (x)$는 $x = - \frac{\pi}{6}$에서 최댓값 $\mathrm{7}$을 가지므로
$f \left( - \frac{\pi}{6} \right) = a - \sqrt{3} \tan \left( - \frac{\pi}{3} \right) = 7$에서
$a + \sqrt{3} \tan \frac{\pi}{3} = 7$
$a + 3 = 7$,    $a = 4$
함수 $f (x)$는 $x = b$에서 최솟값 $\mathrm{3}$을 가지므로
$f (b) = 4 - \sqrt{3} \tan 2 b = 3$에서
$\tan 2 b = \frac{\sqrt{3}}{3}$
이때, $- \frac{\pi}{3} < 2 b < \frac{\pi}{2}$이므로
$2 b = \frac{\pi}{6}$,    $b = \frac{\pi}{12}$
$\therefore$ $a \times b = 4 \times \frac{\pi}{12} = \frac{\pi}{3}$

### 생성 풀이 전체

함수 $f(x) = a - \sqrt{3} \tan 2x$는 구간 내에서 단조 감소하는 함수입니다. (탄젠트 함수 $\tan 2x$는 증가함수이고, 앞에 $-\sqrt{3}$이 곱해져 있으므로 전체 함수는 감소함수입니다.)

따라서 닫힌구간 $\left[ -\frac{\pi}{6}, b \right]$에서 최댓값은 $x = -\frac{\pi}{6}$일 때 발생하고, 최솟값은 $x = b$일 때 발생합니다.

**1. 최댓값 구하기:**
$x = -\frac{\pi}{6}$일 때 최댓값 7을 가지므로,
$f\left( -\frac{\pi}{6} \right) = a - \sqrt{3} \tan \left( 2 \times \left( -\frac{\pi}{6} \right) \right) = 7$
$a - \sqrt{3} \tan \left( -\frac{\pi}{3} \right) = 7$
$\tan \left( -\frac{\pi}{3} \right) = -\sqrt{3}$ 이므로,
$a - \sqrt{3} \times (-\sqrt{3}) = 7$
$a + 3 = 7$
$a = 4$

**2. 최솟값 구하기:**
$x = b$일 때 최솟값 3을 가지므로,
$f(b) = 4 - \sqrt{3} \tan 2b = 3$
$-\sqrt{3} \tan 2b = -1$
$\tan 2b = \frac{1}{\sqrt{3}}$

$\tan \theta = \frac{1}{\sqrt{3}}$을 만족하는 기본 각도는 $\theta = \frac{\pi}{6}$입니다.
따라서 $2b = \frac{\pi}{6}$ 이므로,
$b = \frac{\pi}{12}$

**3. $a \times b$ 계산:**
$a \times b = 4 \times \frac{\pi}{12} = \frac{\pi}{3}$

따라서 정답은 ③번입니다.

최종정답: ③

### 생성 풀이 전체

함수 $f(x) = a - \sqrt{3} \tan 2x$는 구간 $\left[ -\frac{\pi}{6}, b \right]$에서 정의됩니다.
탄젠트 함수 $\tan 2x$는 $2x$의 범위가 $(-\frac{\pi}{2}, \frac{\pi}{2})$일 때 증가하는 함수입니다. 즉, $x$의 범위가 $(-\frac{\pi}{4}, \frac{\pi}{4})$일 때 증가합니다.

주어진 구간 $\left[ -\frac{\pi}{6}, b \right]$에서 $f(x)$는 감소함수($-\sqrt{3} < 0$이므로)입니다.
따라서 $x$가 최소일 때 최댓값을 갖고, $x$가 최대일 때 최솟값을 갖습니다.

1. **최댓값 구하기**: $x = -\frac{\pi}{6}$일 때 최댓값 7을 가집니다.
$f\left( -\frac{\pi}{6} \right) = a - \sqrt{3} \tan\left( 2 \times -\frac{\pi}{6} \right) = a - \sqrt{3} \tan\left( -\frac{\pi}{3} \right) = 7$
$\tan\left( -\frac{\pi}{3} \right) = -\sqrt{3}$이므로,
$a - \sqrt{3}(-\sqrt{3}) = a + 3 = 7$
따라서 $a = 4$입니다.

2. **최솟값 구하기**: $x = b$일 때 최솟값 3을 가집니다.
$f(b) = 4 - \sqrt{3} \tan 2b = 3$
$-\sqrt{3} \tan 2b = -1$
$\tan 2b = \frac{1}{\sqrt{3}}$
$2b = \frac{\pi}{6}$ (구간 내에서 탄젠트 값이 $\frac{1}{\sqrt{3}}$이 되는 첫 번째 값)
따라서 $b = \frac{\pi}{12}$입니다.

3. **$a \times b$ 계산**:
$a \times b = 4 \times \frac{\pi}{12} = \frac{\pi}{3}$

최종정답: ③
