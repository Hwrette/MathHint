① $\mathrm{0}$		② $\mathrm{3}$		③ $\mathrm{6}$
④ $\mathrm{9}$		⑤ $\mathrm{12}$

## 원본 해설 전체

[정답] ③

[해설]
$f (x) = x^{3} + a x^{2} + b x + 1$에서
$f' (x) = 3 x^{2} + 2 a x + b$
함수 $f (x)$가 $x = - 1$, $x = 3$에서 극값을 가지므로, 이차방정식 $3 x^{2} + 2 a x + b = 0$의 서로 다른 두 실근이 $- 1$, $3$이다. 따라서 이차방정식의 근과 계수의 관계에 의하여
$- 1 + 3 = - 2 \frac{a}{3}$, $- 1 \times 3 = \frac{b}{3}$
$\therefore$ $a = - 3$, $b = - 9$
$f (x) = x^{3} - 3 x^{2} - 9 x + 1$이므로 극댓값은	$x = - 1$일 때, $6$이다.

### 생성 풀이 전체

함수 $f(x) = x^3 + ax^2 + bx + 1$이 $x = -1$에서 극대이고 $x = 3$에서 극소이므로, 도함수 $f'(x)$는 다음과 같습니다.
$f'(x) = 3x^2 + 2ax + b$

$x = -1$과 $x = 3$에서 극값을 가지므로 $f'(-1) = 0$이고 $f'(3) = 0$입니다. 즉, $f'(x)$는 $x = -1$과 $x = 3$을 근으로 가집니다.
$f'(x) = 3(x + 1)(x - 3) = 3(x^2 - 2x - 3) = 3x^2 - 6x - 9$

따라서 $2a = -6$에서 $a = -3$이고, $b = -9$입니다.
함수 $f(x)$는 다음과 같습니다.
$f(x) = x^3 - 3x^2 - 9x + 1$

문제에서 $x = -1$에서 극대라고 하였으므로, 극댓값은 $f(-1)$입니다.
$f(-1) = (-1)^3 - 3(-1)^2 - 9(-1) + 1$
$f(-1) = -1 - 3 + 9 + 1$
$f(-1) = 6$

따라서 함수 $f(x)$의 극댓값은 6입니다.
