## 원본 문제와 선택지

$0 \leq x < 2 \pi$일 때, 방정식 $\sin x = \sqrt{3} \left( 1 + \cos x \right)$의 모든 해의 합은?
① $\frac{\pi}{3}$		② $\frac{2}{3} \pi$		③ $\pi$
④ $\frac{4}{3} \pi$		⑤ $\frac{5}{3} \pi$


## 원본 정답

⑤

## 원본 해설 전체

[정답] ⑤

[해설]
$\sin x = \sqrt{3} \left( 1 + \cos x \right)$, $\sin^{2} x$$= 1 - \cos^{2} x$이므로
$1 - \cos^{2} x$$= 3 \left( 1 + \cos x \right)^{2}$, $2 \left( 1 + \cos x \right) \left( 2 \cos x + 1 \right)$$= 0$
(ⅰ) $\cos x$$= - 1$일 때, $\sin x$$= 0$이고 $x$$= \pi$
(ⅱ) $\cos x$$= - \frac{1}{2}$일 때, $\sin x$$= \frac{\sqrt{3}}{2}$이고 $x$$= \frac{2}{3} \pi$
(ⅰ), (ⅱ)에서 방정식의 모든 해의 합은 $\frac{5}{3} \pi$이다.

### 생성 풀이 전체

주어진 방정식 $\sin x = \sqrt{3}(1 + \cos x)$를 풀어보겠습니다.

**1. 배각 공식 및 반각 공식 활용**
$x = 2 \cdot \frac{x}{2}$라고 하면,
$\sin x = 2 \sin \frac{x}{2} \cos \frac{x}{2}$
$1 + \cos x = 2 \cos^2 \frac{x}{2}$
이므로, 방정식을 대입하면 다음과 같습니다.
$2 \sin \frac{x}{2} \cos \frac{x}{2} = \sqrt{3} \cdot 2 \cos^2 \frac{x}{2}$
$2 \sin \frac{x}{2} \cos \frac{x}{2} - 2\sqrt{3} \cos^2 \frac{x}{2} = 0$
$2 \cos \frac{x}{2} (\sin \frac{x}{2} - \sqrt{3} \cos \frac{x}{2}) = 0$

**2. 각 경우에 대한 해 구하기**
(i) $\cos \frac{x}{2} = 0$인 경우:
$0 \leq x < 2\pi$이므로 $0 \leq \frac{x}{2} < \pi$입니다.
$\cos \frac{x}{2} = 0$을 만족하는 값은 $\frac{x}{2} = \frac{\pi}{2}$이므로, **$x = \pi$**입니다.

(ii) $\sin \frac{x}{2} - \sqrt{3} \cos \frac{x}{2} = 0$인 경우:
$\sin \frac{x}{2} = \sqrt{3} \cos \frac{x}{2}$
$\tan \frac{x}{2} = \sqrt{3}$
$0 \leq \frac{x}{2} < \pi$ 범위에서 $\tan \frac{x}{2} = \sqrt{3}$을 만족하는 값은 $\frac{x}{2} = \frac{\pi}{3}$입니다.
따라서 **$x = \frac{2}{3}\pi$**입니다.

**3. 모든 해의 합**
구한 해는 $x = \pi$와 $x = \frac{2}{3}\pi$입니다.
이들의 합은 $\pi + \frac{2}{3}\pi = \frac{5}{3}\pi$입니다.

따라서 정답은 ⑤번입니다.

최종정답: ⑤
