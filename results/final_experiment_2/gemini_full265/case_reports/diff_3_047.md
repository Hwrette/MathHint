### 생성 풀이 전체

모든 실수 $x$에 대하여 부등식 $x^4 - 4x^3 + 16x + a \geq 0$이 항상 성립하려면, 함수 $f(x) = x^4 - 4x^3 + 16x + a$의 최솟값이 0 이상이어야 합니다.

먼저 $f(x)$의 최솟값을 구하기 위해 도함수 $f'(x)$를 구합니다.
$f'(x) = 4x^3 - 12x^2 + 16$

$f'(x) = 0$이 되는 $x$를 찾기 위해 식을 인수분해합니다.
$4(x^3 - 3x^2 + 4) = 0$
조립제법을 이용하면 $x = -1$을 대입했을 때 $(-1)^3 - 3(-1)^2 + 4 = -1 - 3 + 4 = 0$이 되므로, $(x+1)$을 인수로 가집니다.
$4(x+1)(x^2 - 4x + 4) = 0$
$4(x+1)(x-2)^2 = 0$

따라서 $f'(x) = 0$을 만족하는 $x$는 $x = -1$ 또는 $x = 2$입니다.
$x = 2$에서는 $f'(x)$의 부호가 변하지 않으므로(중근), $f(x)$는 $x = -1$에서 극소이자 유일한 최솟값을 가집니다.

이제 $x = -1$일 때의 함숫값을 구합니다.
$f(-1) = (-1)^4 - 4(-1)^3 + 16(-1) + a$
$f(-1) = 1 - 4(-1) - 16 + a$
$f(-1) = 1 + 4 - 16 + a$
$f(-1) = a - 11$

모든 실수 $x$에 대하여 $f(x) \geq 0$이 성립하려면 최솟값인 $f(-1) \geq 0$이어야 합니다.
$a - 11 \geq 0$
$a \geq 11$

따라서 실수 $a$의 최솟값은 11입니다.

최종정답: 11
