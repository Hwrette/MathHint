## 원본 문제와 선택지

$\cos x \leq \sin \frac{\pi}{7}$
를 만족시키는 모든 $x$의 값의 범위는 $\alpha \leq x \leq \beta$이다. $\beta - \alpha$의 값은?

## 원본 해설 전체

[정답] ③

[해설]
$0 \le x \le 2 \pi$일 때 주어진 부등식 $\cos x \le \sin \frac{\pi}{7}$을 만족시키는 모든 $x$의 값의 범위는 다음 그림에서와 같이 $\alpha \le x \le \beta$이다.

이때 $\sin \frac{\pi}{7} > 0$이고 함수 $y = \cos x$의 그래프는 직선 $x = \pi$에 대하여 대칭이므로
$\frac{\pi}{2} - \alpha = \beta - \frac{3}{2} \pi = t$
로 놓으면
$\sin \frac{\pi}{7} = \cos \alpha = \cos \left( \frac{\pi}{2} - t \right) = \sin t$$\therefore \quad$$t = \frac{\pi}{7}$
$\therefore \quad$$\beta - \alpha = \left( \frac{3}{2} \pi + t \right) - \left( \frac{\pi}{2} - t \right) = \frac{9}{7} \pi$
[다른 풀이]
$\sin \frac{\pi}{7} = \cos \left( \frac{\pi}{2} - \frac{\pi}{7} \right) = \cos \frac{5}{14} \pi$이므로 부등식 $\cos x \le \sin \frac{\pi}{7}$에서
$\cos x \le \cos \frac{5}{14} \pi$
$\therefore \quad$$\frac{5}{14} \pi \le x \le 2 \pi - \frac{5}{14} \pi$
$\alpha = \frac{5}{14} \pi$, $\beta = \frac{23}{14} \pi$이므로
$\beta - \alpha = \frac{9}{7} \pi$

### 생성 풀이 전체

주어진 부등식 $\cos x \leq \sin \frac{\pi}{7}$을 풀기 위해, 먼저 우변을 코사인 함수로 변환합니다.
$\sin \frac{\pi}{7} = \cos\left(\frac{\pi}{2} - \frac{\pi}{7}\right) = \cos\left(\frac{7\pi - 2\pi}{14}\right) = \cos\left(\frac{5}{14}\pi\right)$

따라서 부등식은 $\cos x \leq \cos\left(\frac{5}{14}\pi\right)$가 됩니다.

$0 \leq x \leq 2\pi$ 범위에서 $y = \cos x$의 그래프와 직선 $y = \cos\left(\frac{5}{14}\pi\right)$의 교점을 찾습니다.
$\cos x = \cos\left(\frac{5}{14}\pi\right)$를 만족하는 $x$값은 다음과 같습니다.
1) $x_1 = \frac{5}{14}\pi$
2) $x_2 = 2\pi - \frac{5}{14}\pi = \frac{28\pi - 5\pi}{14} = \frac{23}{14}\pi$

코사인 함수는 $0$에서 $2\pi$ 사이에서 감소하다가 증가하는 형태이므로, $\cos x \leq \cos\left(\frac{5}{14}\pi\right)$를 만족하는 $x$의 범위는 두 교점 사이인
$\frac{5}{14}\pi \leq x \leq \frac{23}{14}\pi$
입니다.

따라서 $\alpha = \frac{5}{14}\pi$, $\beta = \frac{23}{14}\pi$입니다.
문제에서 요구하는 $\beta - \alpha$의 값은 다음과 같습니다.
$\beta - \alpha = \frac{23}{14}\pi - \frac{5}{14}\pi = \frac{18}{14}\pi = \frac{9}{7}\pi$
