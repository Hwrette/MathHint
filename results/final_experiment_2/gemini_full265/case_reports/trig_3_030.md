함수 $y = \sin x$의 그래프는 직선 $x = \frac{\pi}{2}$에 대하여 대칭이므로 함수 $y = \sin x$의 그래프와 직선 $y = k$가 만나는 두 점의 $x$좌표 $\alpha$, $\beta$에 대하여 $\frac{\alpha + \beta}{2} = \frac{\pi}{2}$, 즉 $\alpha + \beta = \pi$이므로 $\beta = \pi - \alpha$이다.
$\frac{\beta - \alpha}{2} = \frac{\left( \pi - \alpha \right) - \alpha}{2} = \frac{\pi}{2} - \alpha$이므로
$\sin \frac{\beta - \alpha}{2} = \sin \left( \frac{\pi}{2} - \alpha \right) = \cos \alpha = \frac{5}{7}$
따라서 $k^{2} = \sin^{2} \alpha = 1 - \cos^{2} \alpha = 1 - \left( \frac{5}{7} \right)^{2} = \frac{24}{49}$이므로
$k = \frac{2 \sqrt{6}}{7}$

### 생성 풀이 전체

방정식 $\sin x = k$ ($0 < k < 1$)의 두 근을 $\alpha, \beta$ ($\alpha < \beta$)라 하면, 사인 함수의 대칭성에 의해 $\beta = \pi - \alpha$가 성립합니다.

따라서 두 근의 차는 다음과 같습니다.
$\beta - \alpha = (\pi - \alpha) - \alpha = \pi - 2\alpha$

문제에서 주어진 조건 $\sin \frac{\beta - \alpha}{2} = \frac{5}{7}$에 대입하면,
$\sin \left( \frac{\pi - 2\alpha}{2} \right) = \sin \left( \frac{\pi}{2} - \alpha \right) = \cos \alpha = \frac{5}{7}$

이제 $\cos \alpha = \frac{5}{7}$임을 이용하여 $\sin \alpha$의 값을 구합니다.
$0 < k < 1$이므로 $\alpha$는 제1사분면의 각입니다.
$\sin^2 \alpha + \cos^2 \alpha = 1$에서
$\sin^2 \alpha = 1 - \left( \frac{5}{7} \right)^2 = 1 - \frac{25}{49} = \frac{24}{49}$
$\sin \alpha = \sqrt{\frac{24}{49}} = \frac{\sqrt{24}}{7} = \frac{2\sqrt{6}}{7}$

방정식 $\sin x = k$의 근이 $\alpha$이므로,
$k = \sin \alpha = \frac{2\sqrt{6}}{7}$

따라서 $k$의 값은 $\frac{2\sqrt{6}}{7}$입니다.
