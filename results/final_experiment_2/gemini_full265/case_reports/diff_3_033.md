## 원본 해설 전체

[정답] ①

[해설]
$y = x^{3} - 4 x + 5$을 미분하면 $y' = 3 x^{2} - 4$이므로 곡선 $y = x^{3} - 4 x + 5$ 위의 점 $(1 , 2)$에서의 접선의 방정식은
$y = - (x - 1) + 2 = - x + 3$
이다. 이 접선이 곡선 $y = x^{4} + 3 x + a$와 $x = t$에서 접한다고 하면
$\begin{array}{rrr}t^{4} + 3 t + a = - t + 3 & {} & \cdots \cdots \text{㉠} \quad \\ 4 t^{3} + 3 = - 1 & {} & \cdots \cdots \text{㉡}\end{array}$
이고, 식 ㉡에서 $t = - 1$이므로 이를 식 ㉠에 대입하면
$\therefore\ a=6$

### 생성 풀이 전체

1. 먼저 곡선 $y = x^3 - 4x + 5$ 위의 점 $(1, 2)$에서의 접선의 방정식을 구합니다.
   $f(x) = x^3 - 4x + 5$라 하면, $f'(x) = 3x^2 - 4$입니다.
   점 $(1, 2)$에서의 접선의 기울기는 $f'(1) = 3(1)^2 - 4 = -1$입니다.
   따라서 접선의 방정식은 $y - 2 = -1(x - 1)$, 즉 $y = -x + 3$입니다.

2. 이 직선 $y = -x + 3$이 곡선 $g(x) = x^4 + 3x + a$에 접한다고 하였으므로, 접점의 좌표를 $(t, g(t))$라 하면 다음 두 조건을 만족해야 합니다.
   (i) $g(t) = -t + 3$
   (ii) $g'(t) = -1$

3. $g'(x) = 4x^3 + 3$이므로, 조건 (ii)에 의해:
   $4t^3 + 3 = -1$
   $4t^3 = -4$
   $t^3 = -1$
   따라서 $t = -1$입니다.

4. 이제 조건 (i)에 $t = -1$을 대입하여 $a$의 값을 구합니다.
   $g(-1) = (-1)^4 + 3(-1) + a = -(-1) + 3$
   $1 - 3 + a = 1 + 3$
   $-2 + a = 4$
   $a = 6$

따라서 상수 $a$의 값은 6입니다.

3. 접점의 좌표는 $(t, g(t)) = (-1, g(-1))$입니다.

   접점 $(-1, a - 2)$는 직선 $y = -x + 3$ 위의 점이므로,
   $a - 2 = -(-1) + 3$
   $a - 2 = 1 + 3$
   $a - 2 = 4$
   $a = 6$

따라서 상수 $a$의 값은 6입니다.
