## 원본 문제와 선택지

두 양수 $a$, $b$에 대하여 닫힌구간 $\left[ 0 , 2 a \right]$에서 정의된 함수
$f \left( x \right) = 3 \sin \frac{\pi x}{a} + b$
의 그래프가 $x$축과 오직 한 점 $\left( 2 , 0 \right)$에서 만날 때, $a + b$의 값은?
① $\frac{25}{6}$		② $\frac{13}{3}$		③ $\frac{9}{2}$
④ $\frac{14}{3}$		⑤ $\frac{29}{6}$


## 원본 정답

②

## 원본 해설 전체

[정답] ②

[해설]
함수 $y = f \left( x \right)$의 그래프는 $y = 3 \sin \frac{\pi x}{a}$의 그래프를 $y$축의 방향으로 $b \left( b > 0 \right)$만큼 평행이동한 것이고 함수 $y = f \left( x \right)$의 그래프가 $x$축과 오직 한 점에서 만나므로 함수 $f \left( x \right)$의 최솟값은 $0$이다. 함수 $f \left( x \right)$는 $x = \frac{3 a}{2}$일 때, 최솟값 $0$을 가지므로 $\frac{3 a}{2} = 2$, $a = \frac{4}{3}$이고 $f \left( \frac{3 a}{2} \right) = - 3 + b = 0$, $b = 3$
따라서 $a + b = \frac{4}{3} + 3 = \frac{13}{3}$

### 생성 풀이 전체

함수 $f(x) = 3 \sin \frac{\pi x}{a} + b$가 $x$축과 오직 한 점 $(2, 0)$에서 만난다는 것은 $f(2) = 0$이고, 구간 $[0, 2a]$에서 $f(x)$의 최솟값 또는 최댓값이 0이 되어야 함을 의미합니다.

1. **$f(2) = 0$ 조건:**
   $f(2) = 3 \sin \frac{2\pi}{a} + b = 0$ 이므로, $b = -3 \sin \frac{2\pi}{a}$ 입니다.
   $b > 0$이므로 $\sin \frac{2\pi}{a} < 0$이어야 합니다.

2. **그래프의 형태와 범위:**
   $f(x) = 3 \sin \frac{\pi x}{a} + b$의 치역은 $[b-3, b+3]$입니다.
   $x$축과 오직 한 점에서 만나려면, 최솟값 $b-3$이 0이 되어야 합니다. (최댓값 $b+3$은 항상 양수이므로)
   따라서 $b - 3 = 0 \implies b = 3$입니다.

3. **$a$의 값 구하기:**
   $b = 3$을 $f(2) = 0$ 식에 대입하면:
   $3 \sin \frac{2\pi}{a} + 3 = 0$
   $\sin \frac{2\pi}{a} = -1$
   $\frac{2\pi}{a} = \frac{3}{2}\pi + 2n\pi$ ($n$은 정수)

   $a > 0$이므로 가장 작은 양수 $a$를 구하면:
   $\frac{2}{a} = \frac{3}{2} \implies 3a = 4 \implies a = \frac{4}{3}$
   이때 구간 $[0, 2a] = [0, 8/3]$에서 $f(x) = 3 \sin \frac{3\pi x}{4} + 3$은 $x=2$에서 최솟값 0을 가지며, $x=0$일 때 $f(0)=3$, $x=8/3$일 때 $f(8/3)=3$이 되어 조건에 부합합니다.

4. **$a+b$ 계산:**
   $a + b = \frac{4}{3} + 3 = \frac{4}{3} + \frac{9}{3} = \frac{13}{3}$

따라서 정답은 ②번입니다.
