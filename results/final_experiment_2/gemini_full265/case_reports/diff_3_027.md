[정답] ④

[해설]
$\lim_{x \rightarrow 3} \frac{f (x) - g (x)}{x - 3} = 1$이고 $\lim_{x \rightarrow 3} (x - 3) = 0$이므로
$\lim_{x \rightarrow 3} \left\{ f (x) - g (x) \right\} = 0$
$f (x)$, $g (x)$가 모두 다항함수이므로 $f (3) = g (3)$이고
$f (3) = 2$이므로 $g (3) = 2$
$\lim_{x \rightarrow 3} \frac{f (x) - g (x)}{x - 3}$$= \lim_{x \rightarrow 3} \frac{\left\{ f (x) - f (3) \right\} - \left\{ g (x) - g (3) \right\}}{x - 3}$
$= f' (3) - g' (3) = 1$
$f' (3) = 1$이므로 $g' (3) = 0$
$g(x)=x^2+ax+b\quad(a,b$는 상수$)$라 하면
$g' (x) = 2 x + a$
$g (3) = 9 + 3 a + b = 2$, $g' (3) = 6 + a = 0$에서
$a = - 6$, $b = 11$
따라서 $g (1) = 1 - 6 + 11 = 6$

### 생성 풀이 전체

주어진 극한식 $\lim_{x \rightarrow 3} \frac{f (x) - g (x)}{x - 3} = 1$에서 분모가 $0$으로 가므로, 극한값이 존재하기 위해서는 분자도 $0$으로 가야 합니다. 즉,
$\lim_{x \rightarrow 3} (f(x) - g(x)) = f(3) - g(3) = 0$
$f(3) = 2$이므로 $g(3) = 2$입니다.

이제 극한식은 미분계수의 정의에 의해 다음과 같이 쓸 수 있습니다.
$\lim_{x \rightarrow 3} \frac{f (x) - g (x)}{x - 3} = f'(3) - g'(3) = 1$
$f'(3) = 1$이므로,
$1 - g'(3) = 1 \implies g'(3) = 0$

최고차항의 계수가 $1$인 이차함수 $g(x)$를 $g(x) = x^2 + ax + b$라고 하면,
$g'(x) = 2x + a$입니다.
$g'(3) = 2(3) + a = 0$에서 $6 + a = 0$이므로 $a = -6$입니다.
따라서 $g(x) = x^2 - 6x + b$입니다.

앞서 구한 $g(3) = 2$를 대입하면,
$g(3) = 3^2 - 6(3) + b = 9 - 18 + b = -9 + b = 2$
$b = 11$
즉, $g(x) = x^2 - 6x + 11$입니다.

마지막으로 $g(1)$의 값을 구하면,
$g(1) = 1^2 - 6(1) + 11 = 1 - 6 + 11 = 6$
