## 원본 문제와 선택지

좌표평면 위의 원점 ${\mathrm{{O}}}$에서 $x$축의 양의 방향으로 시초선을
잡을 때, 원점 ${\mathrm{{O}}}$와 점 ${\mathrm{{P}}} (5 , a)$를 지나는 동경 ${\mathrm{{O P}}}$가 나타내는 각의 크기를 $\theta$, 선분 ${\mathrm{{O P}}}$의 길이를 $r$라 하자.
$\sin \theta + 2 \cos \theta = 1$일 때, $a + r$의 값은? (단, $a$는 상수이다.)
① $\frac{5}{2}$		② $\mathrm{3}$		③ $\frac{7}{2}$
④ $\mathrm{4}$		⑤ $\frac{9}{2}$

## 원본 해설 전체

[정답] ①

[해설]
동경 ${\mathrm{{O P}}}$가 나타내는 각의 크기가 $\theta$이고 $\overline{{\mathrm{{O P}}}} = r$이므로 $\sin \theta = \frac{a}{r}$이고 $\cos \theta = \frac{5}{r}$이다. $\sin \theta + 2 \cos \theta = 1$에서 $\frac{a}{r} + \frac{10}{r} = 1$이므로
$r = a + 10$이다. $\cdots \cdots$㉠
$\sin^{2} \theta + \cos^{2} \theta = 1$에서 $\left( \frac{a}{r} \right)^{2} + \left( \frac{5}{r} \right)^{2} = 1$이므로
$a^{2} + 25 = r^{2}$이다. $\cdots \cdots$㉡
㉠, ㉡에 의하여 $a = - \frac{15}{4}$이고 $r = \frac{25}{4}$이다.
따라서 $a + r = \frac{5}{2}$

### 생성 풀이 전체

점 $\mathrm{P}(5, a)$에 대하여 선분 $\mathrm{OP}$의 길이 $r$은 다음과 같습니다.
$r = \sqrt{5^2 + a^2} = \sqrt{25 + a^2}$

동경 $\mathrm{OP}$가 나타내는 각 $\theta$에 대하여,
$\sin \theta = \frac{a}{r}$, $\cos \theta = \frac{5}{r}$ 입니다.

주어진 식 $\sin \theta + 2 \cos \theta = 1$에 대입하면,
$\frac{a}{r} + 2 \left( \frac{5}{r} \right) = 1$
$\frac{a + 10}{r} = 1$
따라서 $a + 10 = r$ 이라는 식을 얻습니다.

위 식의 양변을 제곱하면,
$(a + 10)^2 = r^2$
$a^2 + 20a + 100 = 25 + a^2$
$20a = 25 - 100$
$20a = -75$
$a = -\frac{75}{20} = -\frac{15}{4}$

이제 $r$의 값을 구하면,
$r = a + 10 = -\frac{15}{4} + 10 = -\frac{15}{4} + \frac{40}{4} = \frac{25}{4}$

문제에서 요구하는 $a + r$의 값은,
$a + r = -\frac{15}{4} + \frac{25}{4} = \frac{10}{4} = \frac{5}{2}$
