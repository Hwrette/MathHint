## 원본 해설 전체

[정답] ①

[해설]
$\frac{3 \pi}{2} < \theta < 2 \pi$이므로 $\cos^{2} \theta = \frac{1}{10}$에서
$\cos \theta = \frac{\sqrt{10}}{10}$
$\sin^{2} \theta = 1 - \cos^{2} \theta = 1 - \frac{1}{10} = \frac{9}{10}$이므로
$\sin \theta = - \frac{3 \sqrt{10}}{10}$ $\left( \because \quad \frac{3 \pi}{2} < \theta < 2 \pi \right)$
$\therefore$ $\tan \theta = \frac{\sin \theta}{\cos \theta} = \frac{- \frac{3 \sqrt{10}}{10}}{\frac{\sqrt{10}}{10}} = - 3$

### 생성 풀이 전체

주어진 조건과 삼각함수의 성질을 이용하여 문제를 해결합니다.

**1. $\cos \theta$의 값 구하기**
$\cos^2 \theta = \frac{1}{10}$이므로, $\cos \theta = \pm \sqrt{\frac{1}{10}} = \pm \frac{1}{\sqrt{10}}$입니다.
문제에서 $\frac{3\pi}{2} < \theta < 2\pi$ (제4사분면)라고 하였으므로, 제4사분면에서 코사인 값은 양수입니다.
따라서 $\cos \theta = \frac{1}{\sqrt{10}}$입니다.

**2. $\sin \theta$의 값 구하기**
$\sin^2 \theta + \cos^2 \theta = 1$이므로,
$\sin^2 \theta = 1 - \cos^2 \theta = 1 - \frac{1}{10} = \frac{9}{10}$입니다.
제4사분면에서 사인 값은 음수이므로,
$\sin \theta = -\sqrt{\frac{9}{10}} = -\frac{3}{\sqrt{10}}$입니다.

**3. $\tan \theta$의 값 구하기**
$\tan \theta = \frac{\sin \theta}{\cos \theta}$이므로,
$\tan \theta = \frac{-\frac{3}{\sqrt{10}}}{\frac{1}{\sqrt{10}}} = -3$입니다.

따라서 정답은 ①번입니다.
