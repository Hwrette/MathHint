## 원본 문제와 선택지

두 함수 $f \left( x \right)$, $g \left( x \right)$가
$\lim_{x \rightarrow \infty} \left\{ 2 f \left( x \right) - 3 g \left( x \right) \right\}$$= 1$, $\lim_{x \rightarrow \infty} g \left( x \right)$$= \infty$
를 만족시킬 때, $\lim_{x \rightarrow \infty} \frac{4 f \left( x \right) + g \left( x \right)}{3 f \left( x \right) - g \left( x \right)}$의 값은?
① $1$		② $2$		③ $3$
④ $4$		⑤ $5$


## 원본 정답

②

## 원본 해설 전체

[정답] ②

[해설]
$h (x) = 2 f (x) - 3 g (x)$라 하면 $f (x) = \frac{3 g (x) + h (x)}{2}$
$\lim_{x \rightarrow \infty} g (x) = \infty , \quad \lim_{x \rightarrow \infty} h (x) = 1$이므로 $\lim_{x \rightarrow \infty} \frac{h (x)}{g (x)} = 0$
$\lim_{x \rightarrow \infty} \frac{4 f (x) + g (x)}{3 f (x) - g (x)}$$= \lim_{x \rightarrow \infty} \frac{4 \left\{ \frac{3 g (x) + h (x)}{2} \right\} + g (x)}{3 \left\{ \frac{3 g (x) + h (x)}{2} \right\} - g (x)}$
$= \lim_{x \rightarrow \infty} \frac{14 g (x) + 4 h (x)}{7 g (x) + 3 h (x)}$
$= \lim_{x \rightarrow \infty} \frac{14 + 4 \times \frac{h (x)}{g (x)}}{7 + 3 \times \frac{h (x)}{g (x)}}$
$= 2$

### 생성 풀이 전체

주어진 극한값들을 이용하여 문제를 해결해 보겠습니다.

1. **주어진 식 정리:**
   $\lim_{x \rightarrow \infty} \{2f(x) - 3g(x)\} = 1$ 이므로, $2f(x) - 3g(x) = h(x)$라고 하면 $\lim_{x \rightarrow \infty} h(x) = 1$입니다.
   따라서 $2f(x) = 3g(x) + h(x)$이고, $f(x) = \frac{3}{2}g(x) + \frac{1}{2}h(x)$가 됩니다.

2. **구하고자 하는 식에 대입:**
   $\lim_{x \rightarrow \infty} \frac{4f(x) + g(x)}{3f(x) - g(x)}$에 $f(x) = \frac{3}{2}g(x) + \frac{1}{2}h(x)$를 대입합니다.

   분자: $4\left(\frac{3}{2}g(x) + \frac{1}{2}h(x)\right) + g(x) = 6g(x) + 2h(x) + g(x) = 7g(x) + 2h(x)$
   분모: $3\left(\frac{3}{2}g(x) + \frac{1}{2}h(x)\right) - g(x) = \frac{9}{2}g(x) + \frac{3}{2}h(x) - g(x) = \frac{7}{2}g(x) + \frac{3}{2}h(x)$

3. **극한 계산:**
   $\lim_{x \rightarrow \infty} \frac{7g(x) + 2h(x)}{\frac{7}{2}g(x) + \frac{3}{2}h(x)}$
   분모와 분자를 $g(x)$로 나눕니다. ($\lim_{x \rightarrow \infty} g(x) = \infty$이고 $\lim_{x \rightarrow \infty} h(x) = 1$이므로 $\lim_{x \rightarrow \infty} \frac{h(x)}{g(x)} = 0$입니다.)

   $= \lim_{x \rightarrow \infty} \frac{7 + 2\frac{h(x)}{g(x)}}{\frac{7}{2} + \frac{3}{2}\frac{h(x)}{g(x)}} = \frac{7 + 0}{\frac{7}{2} + 0} = \frac{7}{\frac{7}{2}} = 2$

따라서 구하는 값은 $2$입니다.
