## 원본 문제와 선택지

좌표평면에서 직선 $y = x + 1$ 위의 $x$좌표가 양수인 점 $\mathrm{P}$에 대하여 동경 $\mathrm{O P}$가 나타내는 각의 크기를 $\theta \quad \left( 0 < \theta < 2 \pi \right)$라 하자. 각의 크기 $\theta$를 나타내는 동경과 각의 크기 $7 \theta$를 나타내는 동경이 일치할 때, 점 $\mathrm{P}$의 $x$좌표는?
(단, $\mathrm{O}$는 원점이고, $x$축의 양의 방향을 시초선으로 한다.)
① $\frac{\sqrt{3} - 1}{2}$	② $\frac{2 \sqrt{3} - 1}{4}$	③ $\frac{\sqrt{3}}{2}$
④ $\frac{2 \sqrt{3} + 1}{4}$	⑤ $\frac{\sqrt{3} + 1}{2}$

따라서 $a = \frac{1}{\sqrt{3} - 1} = \frac{\sqrt{3} + 1}{2}$

### 생성 풀이 전체

점 $\mathrm{P}$의 좌표를 $(x, y)$라 하면, 점 $\mathrm{P}$는 직선 $y = x + 1$ 위의 점이므로 $y = x + 1$입니다. 이때 $x > 0$이므로 점 $\mathrm{P}$는 제1사분면 또는 제2사분면에 위치합니다.

동경 $\mathrm{OP}$가 나타내는 각을 $\theta$라 하면, $\tan \theta = \frac{y}{x} = \frac{x+1}{x} = 1 + \frac{1}{x}$입니다.
문제에서 $7\theta$를 나타내는 동경과 $\theta$를 나타내는 동경이 일치한다고 하였으므로, 다음 관계가 성립합니다.
$7\theta = \theta + 2n\pi$ ($n$은 정수)
$6\theta = 2n\pi \implies \theta = \frac{n\pi}{3}$

$\theta$는 제1사분면 또는 제2사분면의 각이므로, 가능한 $\theta$의 값은 다음과 같습니다.
1) $n=1$일 때, $\theta = \frac{\pi}{3} = 60^\circ$
2) $n=2$일 때, $\theta = \frac{2\pi}{3} = 120^\circ$

각각의 경우에 대해 $\tan \theta$를 구하면 다음과 같습니다.
1) $\theta = \frac{\pi}{3}$일 때, $\tan \frac{\pi}{3} = \sqrt{3}$
   $1 + \frac{1}{x} = \sqrt{3} \implies \frac{1}{x} = \sqrt{3} - 1 \implies x = \frac{1}{\sqrt{3}-1} = \frac{\sqrt{3}+1}{2}$
2) $\theta = \frac{2\pi}{3}$일 때, $\tan \frac{2\pi}{3} = -\sqrt{3}$
   $1 + \frac{1}{x} = -\sqrt{3} \implies \frac{1}{x} = -\sqrt{3} - 1$
   이 경우 $x$가 음수가 되어 문제의 조건($x > 0$)에 위배됩니다.

따라서 $x = \frac{\sqrt{3}+1}{2}$입니다.

### 생성 풀이 전체

점 $\mathrm{P}$의 좌표를 $(x, y)$라 하면, 점 $\mathrm{P}$는 직선 $y = x + 1$ 위의 점이므로 $y = x + 1$입니다. 이때 $x > 0$이므로 점 $\mathrm{P}$의 좌표는 $(x, x+1)$입니다.

동경 $\mathrm{OP}$가 나타내는 각의 크기를 $\theta$라 할 때, 두 동경 $\theta$와 $7\theta$가 일치하므로 다음이 성립합니다.
$7\theta - \theta = 2n\pi$ ($n$은 정수)
$6\theta = 2n\pi \implies \theta = \frac{n\pi}{3}$

점 $\mathrm{P}(x, x+1)$은 제1사분면 또는 제2사분면에 위치할 수 있습니다.
$\tan \theta = \frac{y}{x} = \frac{x+1}{x} = 1 + \frac{1}{x}$ 입니다.
$x > 0$이므로 $\frac{1}{x} > 0$이고, 따라서 $\tan \theta > 1$입니다.

$\theta = \frac{n\pi}{3}$에서 $\tan \theta > 1$을 만족하는 $\theta$의 범위를 찾으면:
- $n=1$일 때, $\theta = \frac{\pi}{3}$, $\tan \frac{\pi}{3} = \sqrt{3} \approx 1.732 > 1$ (가능)
- $n=2$일 때, $\theta = \frac{2\pi}{3}$, $\tan \frac{2\pi}{3} = -\sqrt{3} < 1$ (불가능)
- $n=4$일 때, $\theta = \frac{4\pi}{3}$, $\tan \frac{4\pi}{3} = \sqrt{3} > 1$ (하지만 $x>0$ 조건 확인 필요)

$\theta = \frac{\pi}{3}$일 때, $\tan \theta = \sqrt{3}$이므로
$1 + \frac{1}{x} = \sqrt{3}$
$\frac{1}{x} = \sqrt{3} - 1$
$x = \frac{1}{\sqrt{3} - 1} = \frac{\sqrt{3} + 1}{(\sqrt{3} - 1)(\sqrt{3} + 1)} = \frac{\sqrt{3} + 1}{3 - 1} = \frac{\sqrt{3} + 1}{2}$

따라서 점 $\mathrm{P}$의 $x$좌표는 $\frac{\sqrt{3} + 1}{2}$입니다.
