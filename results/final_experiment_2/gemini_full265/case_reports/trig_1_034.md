## 원본 문제와 선택지

$\sin \left( \pi + \theta \right) = - \frac{1}{3}$일 때, $\frac{\sin \theta}{1 - \cos \theta} + \frac{\sin \theta}{1 + \cos \theta}$의 값은?
① $- 6$		② $- 3$		③ $0$
④ $3$		⑤ $6$


## 원본 정답

⑤

## 원본 해설 전체

[정답] ⑤

[해설]
$\sin \left( \pi + \theta \right) = - \sin \theta = - \frac{1}{3}$이므로 $\sin \theta = \frac{1}{3}$이고,
$1 - \cos^{2} \theta = \sin^{2} \theta$이므로
$\frac{\sin \theta}{1 - \cos \theta} + \frac{\sin \theta}{1 + \cos \theta}$
$= \frac{\sin \theta \left( 1 + \cos \theta \right) + \sin \theta \left( 1 - \cos \theta \right)}{\left( 1 - \cos \theta \right) \left( 1 + \cos \theta \right)}$
$= \frac{2 \sin \theta}{1 - \cos^{2} \theta}$
$= \frac{2}{\sin \theta}$
$= 6$
이다.

### 생성 풀이 전체

주어진 식 $\sin(\pi + \theta) = -\frac{1}{3}$을 먼저 정리합니다.
삼각함수의 성질에 의해 $\sin(\pi + \theta) = -\sin \theta$이므로,
$-\sin \theta = -\frac{1}{3}$에서 **$\sin \theta = \frac{1}{3}$**임을 알 수 있습니다.

이제 구하고자 하는 식을 통분하여 정리합니다.
$$\frac{\sin \theta}{1 - \cos \theta} + \frac{\sin \theta}{1 + \cos \theta} = \frac{\sin \theta(1 + \cos \theta) + \sin \theta(1 - \cos \theta)}{(1 - \cos \theta)(1 + \cos \theta)}$$
분자를 전개하면:
$$\sin \theta + \sin \theta \cos \theta + \sin \theta - \sin \theta \cos \theta = 2\sin \theta$$
분모는 합차 공식에 의해:
$$(1 - \cos \theta)(1 + \cos \theta) = 1 - \cos^2 \theta = \sin^2 \theta$$
따라서 전체 식은 다음과 같습니다.
$$\frac{2\sin \theta}{\sin^2 \theta} = \frac{2}{\sin \theta}$$

위에서 구한 $\sin \theta = \frac{1}{3}$을 대입하면:
$$\frac{2}{1/3} = 2 \times 3 = 6$$

따라서 구하는 값은 6입니다.
