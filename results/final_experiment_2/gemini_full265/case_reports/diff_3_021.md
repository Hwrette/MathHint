## 원본 해설 전체

[정답] $\mathbf{13}$

[해설]
$f' \left( x \right)$$= 3 x^{2} + a$에서 $x$의 값이 $1$에서 $3$까지 변할 때의 함수 $f \left( x \right)$의 평균변화율이 $f' \left( a \right)$의 값과 같으므로
$\frac{f \left( 3 \right) - f \left( 1 \right)}{3 - 1}$$= f' \left( a \right)$
$\frac{3^{3} + 3 a - \left( 1^{3} + a \right)}{2}$$= 3 a^{2} + a$
따라서 $3 a^{2}$$= 13$

### 생성 풀이 전체

함수 $f(x) = x^3 + ax$에 대하여 $x$의 값이 $1$에서 $3$까지 변할 때의 평균변화율은 다음과 같습니다.
$$\frac{f(3) - f(1)}{3 - 1}$$

먼저 $f(3)$과 $f(1)$을 구하면,
$f(3) = 3^3 + a(3) = 27 + 3a$
$f(1) = 1^3 + a(1) = 1 + a$

따라서 평균변화율은
$$\frac{(27 + 3a) - (1 + a)}{3 - 1} = \frac{26 + 2a}{2} = 13 + a$$

다음으로 $f'(x)$를 구하면,
$f'(x) = 3x^2 + a$
이므로 $f'(a)$의 값은
$f'(a) = 3(a)^2 + a = 3a^2 + a$

문제의 조건에 따라 평균변화율과 $f'(a)$가 같아야 하므로,
$13 + a = 3a^2 + a$

양변에서 $a$를 소거하면,
$3a^2 = 13$

문제에서 요구하는 값은 $3a^2$이므로, 구하는 값은 $13$입니다.

최종정답: 13
