## 원본 문제와 선택지

양수 $t$에 대하여 닫힌구간 $\left[ 0 , \frac{2}{t} \right]$에서 정의된 두 함수
$f \left( x \right) = \sqrt{3} \sin \left( t \pi x \right)$, $g \left( x \right) = - 3 \cos \left( t \pi x \right)$
가 있다. $0 < k < \frac{2}{t}$인 상수 $k$에 대하여 $f \left( k \right) = g \left( k \right) = 3 k$일 때, $60 \left( t + k \right)$의 값을 구하시오.


## 원본 정답

## 원본 해설 전체

[정답] $110$

[해설]
$0 < k < \frac{2}{t}$에서 $0 < t k \pi < 2 \pi$
$f \left( k \right) = 3 k$에서 $\sin \left( t k \pi \right) = \sqrt{3} k > 0$이고
$g \left( k \right) = 3 k$에서 $\cos \left( t k \pi \right) = - k < 0$이므로
$\frac{\pi}{2} < t k \pi < \pi$
$f \left( k \right) = g \left( k \right)$에서 $\tan \left( t k \pi \right) = - \sqrt{3}$이므로
$t k \pi = \frac{2}{3} \pi$, $t k = \frac{2}{3}$
$f \left( k \right) = 3 k$에서 $\sqrt{3} \sin \frac{2}{3} \pi = \frac{3}{2} = 3 k$이므로
$k = \frac{1}{2}$, $t = \frac{4}{3}$
따라서 $60 \left( t + k \right) = 60 \left( \frac{4}{3} + \frac{1}{2} \right) = 110$

### 생성 풀이 전체

주어진 두 함수 $f(x) = \sqrt{3} \sin(t\pi x)$와 $g(x) = -3 \cos(t\pi x)$에 대하여 $f(k) = g(k) = 3k$가 성립합니다.

1. **$f(k) = g(k)$ 조건 이용:**
   $\sqrt{3} \sin(t\pi k) = -3 \cos(t\pi k)$
   양변을 $\cos(t\pi k)$로 나누면 (단, $\cos(t\pi k) \neq 0$):
   $\tan(t\pi k) = -\frac{3}{\sqrt{3}} = -\sqrt{3}$
   $0 < k < \frac{2}{t}$이므로 $0 < t\pi k < 2\pi$입니다.
   $\tan \theta = -\sqrt{3}$을 만족하는 범위 내의 값은 $\theta = \frac{2}{3}\pi$ 또는 $\theta = \frac{5}{3}\pi$입니다.

2. **$f(k) = 3k$ 조건 이용:**
   $f(k) = \sqrt{3} \sin(t\pi k) = 3k$
   - 경우 1: $t\pi k = \frac{2}{3}\pi$일 때
     $\sqrt{3} \sin\left(\frac{2}{3}\pi\right) = \sqrt{3} \cdot \frac{\sqrt{3}}{2} = \frac{3}{2}$
     따라서 $3k = \frac{3}{2} \implies k = \frac{1}{2}$
     $t\pi \left(\frac{1}{2}\right) = \frac{2}{3}\pi \implies \frac{t}{2} = \frac{2}{3} \implies t = \frac{4}{3}$
     이때 $k = \frac{1}{2}$이고 $\frac{2}{t} = \frac{2}{4/3} = \frac{6}{4} = 1.5$이므로 $0 < 0.5 < 1.5$를 만족합니다.

   - 경우 2: $t\pi k = \frac{5}{3}\pi$일 때
     $\sqrt{3} \sin\left(\frac{5}{3}\pi\right) = \sqrt{3} \cdot \left(-\frac{\sqrt{3}}{2}\right) = -\frac{3}{2}$
     그런데 $3k = -\frac{3}{2}$이면 $k = -\frac{1}{2}$이 되어 $k>0$ 조건에 모순입니다.

3. **최종 계산:**
   구하는 값은 $60(t + k)$입니다.
   $t = \frac{4}{3}, k = \frac{1}{2}$이므로
   $t + k = \frac{4}{3} + \frac{1}{2} = \frac{8+3}{6} = \frac{11}{6}$
   $60 \left( \frac{11}{6} \right) = 10 \times 11 = 110$
