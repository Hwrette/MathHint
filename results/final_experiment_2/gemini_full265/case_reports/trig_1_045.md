## 원본 문제와 선택지

$0 \le x < 2 \pi$일 때, 부등식 $2 \cos x - \sqrt{2} \le 0$을 만족시키는 모든 $x$의 값의 범위는 $\alpha \le x \le \beta$이다. $\beta - \alpha$의 값은?
① $\pi$		② $\frac{7}{6} \pi$		③ $\frac{4}{3} \pi$
④ $\frac{3}{2} \pi$		⑤ $\frac{5}{3} \pi$


## 원본 정답

④

## 원본 해설 전체

[정답] ④

[해설]

부등식 $2 \cos x - \sqrt{2} \le 0$에서 $\cos x \le \frac{\sqrt{2}}{2}$
이고, $0 \le x < 2 \pi$에서 곡선 $y = \cos x$와 직선 $y = \frac{\sqrt{2}}{2}$가 만나는 두 점의 $x$좌표가 각각 $\frac{\pi}{4}$, $\frac{7}{4} \pi$이므로 부등식 $\cos x \le \frac{\sqrt{2}}{2}$의 해는 $\frac{\pi}{4} \le x \le \frac{7}{4} \pi$이다.
따라서 $\alpha = \frac{\pi}{4}$, $\beta = \frac{7}{4} \pi$이므로
$\beta - \alpha = \frac{7}{4} \pi - \frac{\pi}{4} = \frac{3}{2} \pi$이다.

### 생성 풀이 전체

주어진 부등식 $2 \cos x - \sqrt{2} \le 0$을 정리하면 다음과 같습니다.

$2 \cos x \le \sqrt{2}$
$\cos x \le \frac{\sqrt{2}}{2}$

$0 \le x < 2\pi$ 범위에서 $\cos x = \frac{\sqrt{2}}{2}$를 만족하는 $x$의 값은 다음과 같습니다.
$x = \frac{\pi}{4}$ 또는 $x = 2\pi - \frac{\pi}{4} = \frac{7}{4}\pi$

함수 $y = \cos x$의 그래프를 고려할 때, $\cos x \le \frac{\sqrt{2}}{2}$를 만족하는 $x$의 범위는 다음과 같습니다.
$\frac{\pi}{4} \le x \le \frac{7}{4}\pi$

따라서 문제에서 주어진 $\alpha = \frac{\pi}{4}$, $\beta = \frac{7}{4}\pi$입니다.

이제 $\beta - \alpha$의 값을 구하면 다음과 같습니다.
$\beta - \alpha = \frac{7}{4}\pi - \frac{\pi}{4} = \frac{6}{4}\pi = \frac{3}{2}\pi$

따라서 정답은 ④번입니다.
