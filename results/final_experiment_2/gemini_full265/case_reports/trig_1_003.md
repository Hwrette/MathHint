## 원본 문제와 선택지

좌표평면에서 원 $x^{2} + y^{2} = r^{2} \quad \left( r > 2 \right)$와 직선 $x = - 2$가 만나는 두 점 중 $y$좌표가 양수인 점을 ${\mathrm{{A}}}$, $y$좌표가 음수인 점을 ${\mathrm{{B}}}$라 하고, 두 동경 ${\mathrm{{O A}}}$, ${\mathrm{{O B}}}$가 나타내는 각의 크기를 각각 $\alpha$, $\beta$라 하자. $2 \cos \alpha = 3 \sin \beta$일 때, $r \left( \sin \alpha + \cos \beta \right)$의 값은? (단, $\mathrm{O}$는 원점이고, $x$축의 양의 방향을 시초선으로 한다.)
① $- \frac{8}{3}$	② $- \frac{5}{3}$		③ $- \frac{2}{3}$
④ $\frac{1}{3}$		⑤ $\frac{4}{3}$

## 원본 해설 전체

[정답] ③

[해설]
점 ${\mathrm{{A}}}$의 좌표를 $\left( - 2 , a \right) \quad \left( a > 0 \right)$이라 하면
점 ${\mathrm{{B}}}$의 좌표는 $(- 2 , - a)$이고 $\overline{{\mathrm{{O A}}}} = \overline{{\mathrm{{O B}}}} = r$이므로
$\cos \alpha = - \frac{2}{r}$, $\sin \beta = - \frac{a}{r}$
$2 \cos \alpha = 3 \sin \beta$에서
$2 \times \left( - \frac{2}{r} \right) = 3 \times \left( - \frac{a}{r} \right)$
$a = \frac{4}{3}$
한편 $\sin \alpha = \frac{a}{r}$, $\cos \beta = - \frac{2}{r}$이므로
$r \left( \sin \alpha + \cos \beta \right)$$= r \left\{ \frac{a}{r} + \left( - \frac{2}{r} \right) \right\}$
$= a + \left( - 2 \right) = \frac{4}{3} + \left( - 2 \right)$
$= - \frac{2}{3}$

### 생성 풀이 전체

원 $x^2 + y^2 = r^2$ 위의 점 $\mathrm{A}$와 $\mathrm{B}$는 직선 $x = -2$ 위에 있으므로, 점의 좌표를 각각 $(-2, y_A)$, $(-2, y_B)$라 할 수 있습니다.
$(-2)^2 + y^2 = r^2$에서 $y^2 = r^2 - 4$이므로 $y = \pm \sqrt{r^2 - 4}$입니다.
점 $\mathrm{A}$는 $y$좌표가 양수이므로 $\mathrm{A}(-2, \sqrt{r^2 - 4})$, 점 $\mathrm{B}$는 $y$좌표가 음수이므로 $\mathrm{B}(-2, -\sqrt{r^2 - 4})$입니다.

동경 $\mathrm{OA}$와 $\mathrm{OB}$에 대하여,
$\cos \alpha = \frac{x_A}{r} = \frac{-2}{r}$, $\sin \alpha = \frac{y_A}{r} = \frac{\sqrt{r^2 - 4}}{r}$
$\cos \beta = \frac{x_B}{r} = \frac{-2}{r}$, $\sin \beta = \frac{y_B}{r} = \frac{-\sqrt{r^2 - 4}}{r}$

주어진 조건 $2 \cos \alpha = 3 \sin \beta$에 대입하면:
$2 \left( -\frac{2}{r} \right) = 3 \left( -\frac{\sqrt{r^2 - 4}}{r} \right)$
$-\frac{4}{r} = -\frac{3\sqrt{r^2 - 4}}{r}$
양변에 $-r$을 곱하면 $4 = 3\sqrt{r^2 - 4}$가 됩니다.
양변을 제곱하면 $16 = 9(r^2 - 4)$
$16 = 9r^2 - 36$
$9r^2 = 52 \implies r^2 = \frac{52}{9}$
또한, $3\sqrt{r^2 - 4} = 4$이므로 $\sqrt{r^2 - 4} = \frac{4}{3}$입니다.

이제 구하고자 하는 값 $r(\sin \alpha + \cos \beta)$를 계산합니다.
$r(\sin \alpha + \cos \beta) = r \left( \frac{\sqrt{r^2 - 4}}{r} + \frac{-2}{r} \right)$
$= \sqrt{r^2 - 4} - 2$

위에서 구한 $\sqrt{r^2 - 4} = \frac{4}{3}$를 대입하면:
$= \frac{4}{3} - 2 = \frac{4}{3} - \frac{6}{3} = -\frac{2}{3}$
