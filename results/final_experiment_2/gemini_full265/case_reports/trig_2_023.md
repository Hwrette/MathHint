$3 \sin^{2} \left( \theta + \frac{2}{3} \pi \right)$$= 3 \sin^{2} (\pi + \alpha)$
$= 3 \sin^{2} \alpha = 3 - 3 \cos^{2} \alpha$

### 생성 풀이 전체

주어진 방정식 $3 \sin^{2} \left( \theta + \frac{2}{3} \pi \right) = 8 \sin \left( \theta + \frac{\pi}{6} \right)$을 풀어봅시다.

먼저 각을 정리하기 위해 삼각함수의 덧셈정리를 이용합니다.
$\theta + \frac{2}{3} \pi = (\theta + \frac{\pi}{6}) + \frac{\pi}{2}$라고 하면,
$\sin \left( \theta + \frac{2}{3} \pi \right) = \sin \left( (\theta + \frac{\pi}{6}) + \frac{\pi}{2} \right) = \cos \left( \theta + \frac{\pi}{6} \right)$입니다.

따라서 주어진 방정식은 다음과 같이 바뀝니다.
$3 \cos^{2} \left( \theta + \frac{\pi}{6} \right) = 8 \sin \left( \theta + \frac{\pi}{6} \right)$

$\cos^{2} x = 1 - \sin^{2} x$임을 이용하면, $x = \theta + \frac{\pi}{6}$라 할 때
$3(1 - \sin^{2} x) = 8 \sin x$
$3 - 3 \sin^{2} x = 8 \sin x$
$3 \sin^{2} x + 8 \sin x - 3 = 0$

이차방정식을 인수분해하면:
$(3 \sin x - 1)(\sin x + 3) = 0$
$\sin x$의 값은 $-1$에서 $1$ 사이여야 하므로, $\sin x = \frac{1}{3}$입니다.
즉, $\sin \left( \theta + \frac{\pi}{6} \right) = \frac{1}{3}$입니다.

이제 구하고자 하는 값 $\cos \left( \theta - \frac{\pi}{3} \right)$을 살펴봅시다.
$\theta - \frac{\pi}{3} = (\theta + \frac{\pi}{6}) - \frac{\pi}{2}$이므로,
$\cos \left( \theta - \frac{\pi}{3} \right) = \cos \left( (\theta + \frac{\pi}{6}) - \frac{\pi}{2} \right)$
$= \cos \left( \theta + \frac{\pi}{6} \right) \cos \frac{\pi}{2} + \sin \left( \theta + \frac{\pi}{6} \right) \sin \frac{\pi}{2}$
$= \cos \left( \theta + \frac{\pi}{6} \right) \cdot 0 + \sin \left( \theta + \frac{\pi}{6} \right) \cdot 1$
$= \sin \left( \theta + \frac{\pi}{6} \right)$

위에서 구한 $\sin \left( \theta + \frac{\pi}{6} \right) = \frac{1}{3}$이므로,
$\cos \left( \theta - \frac{\pi}{3} \right) = \frac{1}{3}$입니다.
