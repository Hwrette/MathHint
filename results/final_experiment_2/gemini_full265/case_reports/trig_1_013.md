함수 $f \left( x \right) = a \cos b x$의 주기는 $\frac{2 \pi}{\left| b \right|} = 6 \pi$이므로
$b = \frac{1}{3}$, $f (x) = a \cos \frac{x}{3}$

닫힌구간 $[\pi , 4 \pi]$에서 함수 $f (x)$의 최댓값은
$f (\pi) = a \cos \frac{\pi}{3} = \frac{a}{2} = 1$이므로 $a = 2$
따라서 $a + b = 2 + \frac{1}{3} = \frac{7}{3}$

### 생성 풀이 전체

함수 $f(x) = a \cos bx$ ($a, b > 0$)의 주기가 $6\pi$이므로, 다음 식이 성립합니다.
$$\frac{2\pi}{b} = 6\pi \implies b = \frac{1}{3}$$
따라서 함수는 $f(x) = a \cos \left( \frac{1}{3}x \right)$가 됩니다.

이제 닫힌구간 $[\pi, 4\pi]$에서 $f(x)$의 최댓값을 구합니다.
$x$의 범위가 $\pi \le x \le 4\pi$일 때, $\frac{1}{3}x$의 범위는 다음과 같습니다.
$$\frac{\pi}{3} \le \frac{1}{3}x \le \frac{4\pi}{3}$$

이 범위에서 $\cos \left( \frac{1}{3}x \right)$의 값의 범위를 구하면,
$\cos \left( \frac{\pi}{3} \right) = \frac{1}{2}$이고, $\cos \left( \frac{4\pi}{3} \right) = -\frac{1}{2}$이며, 구간 내에 $\frac{\pi}{2}$가 포함되어 있으므로 $\cos \left( \frac{1}{3}x \right)$의 최댓값은 $\cos \left( \frac{\pi}{3} \right) = \frac{1}{2}$이고 최솟값은 $-1$입니다. (단, $\frac{1}{3}x = \pi$일 때 $\cos \pi = -1$)

함수 $f(x) = a \cos \left( \frac{1}{3}x \right)$에서 $a > 0$이므로, 최댓값은 $x = \pi$일 때 발생합니다.
$$f(\pi) = a \cos \left( \frac{\pi}{3} \right) = a \cdot \frac{1}{2} = 1$$
따라서 $a = 2$입니다.

구하는 값은 $a + b$이므로,
$$a + b = 2 + \frac{1}{3} = \frac{7}{3}$$

최종정답: ⑤
