## 원본 해설 전체

[정답] ①

[해설]
함수 $f (x)$가 $x = 1$에서 극값을 가지므로
$f' (1) = 0$
$f' \left( x \right) = 3 x^{2} + 2 a x - 9$에서
$f' \left( 1 \right) = 3 + 2 a - 9 = 0$이므로 $a = 3$
$f' \left( x \right) = 3 x^{2} + 6 x - 9 = 3 \left( x - 1 \right) \left( x + 3 \right)$
함수 $f \left( x \right)$는 $x = - 3$에서 극댓값을 갖는다.
따라서 $f \left( - 3 \right) = - 27 + 27 + 27 + 4 = 31$

### 생성 풀이 전체

함수 $f(x) = x^3 + ax^2 - 9x + 4$가 $x=1$에서 극값을 가지므로, 미분계수 $f'(1) = 0$이어야 합니다.

먼저 $f(x)$를 미분하면:
$f'(x) = 3x^2 + 2ax - 9$

$f'(1) = 0$을 대입하면:
$3(1)^2 + 2a(1) - 9 = 0$
$3 + 2a - 9 = 0$
$2a - 6 = 0$
$2a = 6$
$a = 3$

따라서 $f(x) = x^3 + 3x^2 - 9x + 4$가 됩니다.
극값을 구하기 위해 $f'(x) = 0$을 다시 계산하면:
$f'(x) = 3x^2 + 6x - 9 = 0$
$3(x^2 + 2x - 3) = 0$
$3(x + 3)(x - 1) = 0$
$x = -3$ 또는 $x = 1$

함수 $f(x)$의 증감표를 생각해보면, $x < -3$에서 $f'(x) > 0$, $-3 < x < 1$에서 $f'(x) < 0$, $x > 1$에서 $f'(x) > 0$이므로, $x = -3$에서 극댓값을 갖고 $x = 1$에서 극솟값을 갖습니다.

극댓값은 $x = -3$일 때의 함숫값입니다.
$f(-3) = (-3)^3 + 3(-3)^2 - 9(-3) + 4$
$f(-3) = -27 + 3(9) + 27 + 4$
$f(-3) = -27 + 27 + 27 + 4$
$f(-3) = 31$

따라서 함수 $f(x)$의 극댓값은 31입니다.

최종정답: ①
