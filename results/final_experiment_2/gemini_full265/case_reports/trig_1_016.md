[해설]
두 양수 $a$, $b$에 대하여 함수 $f \left( x \right) = a \cos b x + 1$의 최댓값이 $8$이므로    $a + 1 = 8$    $\therefore$ $a = 7$
주기가 $\pi$이므로    $\frac{2 \pi}{b} = \pi$    $\therefore$ $b = 2$
$\therefore$ $a + b = 7 + 2 = 9$

### 생성 풀이 전체

함수 $f(x) = a \cos bx + 1$에 대하여 주어진 조건들을 이용해 $a$와 $b$를 구합니다.

1. **최댓값 조건:**
   함수 $f(x) = a \cos bx + 1$에서 $\cos bx$의 최댓값은 $1$입니다.
   따라서 $f(x)$의 최댓값은 $a(1) + 1 = a + 1$입니다.
   문제에서 최댓값이 $8$이라고 하였으므로,
   $a + 1 = 8$
   $a = 7$ (단, $a$는 양수이므로 조건 만족)

2. **주기 조건:**
   함수 $f(x) = a \cos bx + 1$의 주기는 $\frac{2\pi}{|b|}$입니다.
   문제에서 주기가 $\pi$라고 하였고 $b$는 양수이므로,
   $\frac{2\pi}{b} = \pi$
   $b = 2$ (단, $b$는 양수이므로 조건 만족)

3. **$a + b$의 값:**
   $a = 7$, $b = 2$이므로
   $a + b = 7 + 2 = 9$

따라서 정답은 ④번입니다.
