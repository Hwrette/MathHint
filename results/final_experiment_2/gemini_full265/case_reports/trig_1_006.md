## 원본 문제와 선택지

$\frac{3}{2} \pi < \theta < 2 \pi$인 $\theta$에 대하여 $\sin \theta \tan \theta + \cos \theta = 3$일 때, $\sin \theta - \tan \theta$의 값은?

## 원본 해설 전체

[정답] ⑤

[해설]
$\sin \theta \tan \theta + \cos \theta = 3$의 양변에 $\cos \theta$를 곱하면
$\sin^{2} \theta + \cos^{2} \theta = 3 \cos \theta$
$\sin^{2} \theta + \cos^{2} \theta = 1$이므로 $\cos \theta = \frac{1}{3}$
$\frac{3}{2} \pi < \theta < 2 \pi$에서 $\sin \theta < 0$이므로
$\sin \theta = - \sqrt{1 - \left( \frac{1}{3} \right)^{2}} = - \frac{2 \sqrt{2}}{3}$
그러므로 $\tan \theta = - 2 \sqrt{2}$
따라서 $\sin \theta - \tan \theta = - \frac{2 \sqrt{2}}{3} - \left( - 2 \sqrt{2} \right) = \frac{4 \sqrt{2}}{3}$

### 생성 풀이 전체

주어진 식 $\sin \theta \tan \theta + \cos \theta = 3$을 삼각함수의 기본 관계식을 이용하여 정리합니다.
$\tan \theta = \frac{\sin \theta}{\cos \theta}$이므로,
$\sin \theta \cdot \frac{\sin \theta}{\cos \theta} + \cos \theta = 3$
$\frac{\sin^2 \theta}{\cos \theta} + \cos \theta = 3$

분자를 $\sin^2 \theta = 1 - \cos^2 \theta$로 바꾸면,
$\frac{1 - \cos^2 \theta}{\cos \theta} + \cos \theta = 3$
$\frac{1 - \cos^2 \theta + \cos^2 \theta}{\cos \theta} = 3$
$\frac{1}{\cos \theta} = 3 \implies \cos \theta = \frac{1}{3}$

$\frac{3}{2} \pi < \theta < 2 \pi$ (제4사분면)이므로 $\sin \theta$는 음수입니다.
$\sin^2 \theta = 1 - \cos^2 \theta = 1 - \left(\frac{1}{3}\right)^2 = 1 - \frac{1}{9} = \frac{8}{9}$
$\sin \theta = -\sqrt{\frac{8}{9}} = -\frac{2\sqrt{2}}{3}$

또한, $\tan \theta = \frac{\sin \theta}{\cos \theta} = \frac{-\frac{2\sqrt{2}}{3}}{\frac{1}{3}} = -2\sqrt{2}$입니다.

이제 구하고자 하는 값 $\sin \theta - \tan \theta$를 계산합니다.
$\sin \theta - \tan \theta = \left(-\frac{2\sqrt{2}}{3}\right) - (-2\sqrt{2})$
$= -\frac{2\sqrt{2}}{3} + 2\sqrt{2}$
$= -\frac{2\sqrt{2}}{3} + \frac{6\sqrt{2}}{3}$
$= \frac{4\sqrt{2}}{3}$

따라서 정답은 ⑤번입니다.

최종정답: ⑤
