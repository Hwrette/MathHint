## 원본 문제와 선택지

함수
$f \left( x \right) = {\left\{\begin{array}{llll}x^{3} - a x + 2 b &  &  & \left( x < 1 \right) \\ - 3 x + b &  &  & \left( x \geq 1 \right)\end{array}\right.}$
이 실수 전체의 집합에서 미분가능할 때, $a \times b$의 값은?
(단, $a$와 $b$는 상수이다.)
① $3$		② $6$		③ $9$
④ $12$		⑤ $15$

## 원본 해설 전체

[정답] ④

[해설]
함수 $f \left( x \right)$가 실수 전체의 집합에서 미분가능하므로 함수 $f \left( x \right)$는 $x = 1$에서 미분가능하다.
그러므로 함수 $f \left( x \right)$는 $x = 1$에서 연속이다.
$\lim_{x \rightarrow 1 -} f \left( x \right) = \lim_{x \rightarrow 1 +} f \left( x \right) = f \left( 1 \right)$에서
$1 - a + 2 b = - 3 + b$
$b = a - 4$
$\lim_{x \rightarrow 1 -} \frac{f \left( x \right) - f \left( 1 \right)}{x - 1}$$= \lim_{x \rightarrow 1 -} \frac{\left( x^{3} - a x + 2 b \right) - \left( - 3 + b \right)}{x - 1}$
$= \lim_{x \rightarrow 1 -} \frac{x^{3} - a x + a - 1}{x - 1}$
$= \lim_{x \rightarrow 1 -} \left( x^{2} + x + 1 - a \right)$
$= 3 - a$
$\lim_{x \rightarrow 1 +} \frac{f \left( x \right) - f \left( 1 \right)}{x - 1}$$= \lim_{x \rightarrow 1 +} \frac{\left( - 3 x + b \right) - \left( - 3 + b \right)}{x - 1}$
$= \lim_{x \rightarrow 1 +} \frac{- 3 x + 3}{x - 1}$
$= - 3$
함수 $f \left( x \right)$가 $x = 1$에서 미분가능하므로
$3 - a = - 3$에서 $a = 6$이고 $b = 2$
따라서 $a \times b = 12$

### 생성 풀이 전체

함수 $f(x)$가 실수 전체의 집합에서 미분가능하려면, 모든 실수 $x$에서 연속이어야 하고 미분계수가 존재해야 합니다. 특히 경계인 $x=1$에서 연속이고 미분가능해야 합니다.

**1. $x=1$에서 연속 조건:**
$\lim_{x \to 1^-} f(x) = \lim_{x \to 1^+} f(x) = f(1)$ 이어야 합니다.
- $\lim_{x \to 1^-} (x^3 - ax + 2b) = 1 - a + 2b$
- $\lim_{x \to 1^+} (-3x + b) = -3 + b$
따라서, $1 - a + 2b = -3 + b$
$-a + b = -4 \quad \cdots \text{①}$

**2. $x=1$에서 미분가능 조건:**
각 구간의 도함수가 $x=1$에서 같아야 합니다.
- $x < 1$일 때, $f'(x) = 3x^2 - a$
- $x > 1$일 때, $f'(x) = -3$
$x=1$에서 좌미분계수와 우미분계수가 같아야 하므로:
$3(1)^2 - a = -3$
$3 - a = -3$
$a = 6$

**3. $a$와 $b$의 값 구하기:**
구한 $a=6$을 ①식에 대입합니다.
$-6 + b = -4$
$b = 2$

따라서 $a \times b = 6 \times 2 = 12$입니다.
