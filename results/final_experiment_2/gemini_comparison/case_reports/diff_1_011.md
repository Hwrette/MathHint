## 원본 해설 전체

[해설]
함수 $f \left( x \right)$가 모든 실수 $x$에서 연속이려면 $x = 1$에서 연속이어야 하므로
$\lim_{x \rightarrow 1 -} f \left( x \right) = \lim_{x \rightarrow 1 +} f \left( x \right) = f \left( 1 \right)$
이때 $f \left( 1 \right) = - 2 + a$이고,
$\lim_{x \rightarrow 1 -} f \left( x \right) = \lim_{x \rightarrow 1 -} \left( 3 x - 2 \right) = 1$
$\lim_{x \rightarrow 1 -} f \left( x \right) = \lim_{x \rightarrow 1 +} \left( x^{2} - 3 x + a \right) = - 2 + a$
이므로    $- 2 + a = 1$    $\therefore$ $a = 3$

### 생성 풀이 전체

함수 $f(x)$가 실수 전체의 집합에서 연속이려면, 모든 실수 $x$에 대하여 연속이어야 합니다. 주어진 함수에서 $x < 1$일 때는 일차함수이고, $x > 1$일 때는 이차함수이므로 각각의 구간에서는 항상 연속입니다.

따라서 $f(x)$가 실수 전체에서 연속이려면 경계값인 $x = 1$에서 연속이어야 합니다. 즉, 다음 조건을 만족해야 합니다.
$$\lim_{x \to 1^-} f(x) = \lim_{x \to 1^+} f(x) = f(1)$$

1. **좌극한 계산:**
   $x < 1$일 때 $f(x) = 3x - 2$이므로,
   $$\lim_{x \to 1^-} f(x) = \lim_{x \to 1^-} (3x - 2) = 3(1) - 2 = 1$$

2. **우극한 및 함숫값 계산:**
   $x \ge 1$일 때 $f(x) = x^2 - 3x + a$이므로,
   $$\lim_{x \to 1^+} f(x) = f(1) = 1^2 - 3(1) + a = 1 - 3 + a = a - 2$$

3. **연속 조건 적용:**
   좌극한과 우극한이 같아야 하므로,
   $$1 = a - 2$$
   $$a = 3$$

따라서 상수 $a$의 값은 $3$입니다.
