[해설]
함수 $\left( f (x) + a \right)^{2}$이 실수 전체의 집합에서 연속이려면 $x = 0$에서 연속이어야 하므로
$\lim_{x \rightarrow 0 +} \left( f (x) + a \right)^{2} = \lim_{x \rightarrow 0 -} \left( f (x) + a \right)^{2} = \left( f (0) + a \right)^{2}$
이때 $\left( f (0) + a \right)^{2} = \left( 3 + a \right)^{2}$이고
$\lim_{x \rightarrow 0 +} \left( f (x) + a \right)^{2}$$= \lim_{x \rightarrow 0 +} \left( - x^{2} + 3 + a \right)^{2}$
$= \left( 3 + a \right)^{2}$
$\lim_{x \rightarrow 0 -} \left( f (x) + a \right)^{2}$$= \lim_{x \rightarrow 0 -} \left( x - \frac{1}{2} + a \right)^{2}$
$= \left( - \frac{1}{2} + a \right)^{2}$
이므로    $\left( 3 + a \right)^{2} = \left( - \frac{1}{2} + a \right)^{2}$
$9 + 6 a + a^{2} = \frac{1}{4} - a + a^{2}$,    $7 a = \frac{1}{4} - 9$
$\therefore$ $a = - \frac{5}{4}$

### 생성 풀이 전체

함수 $g(x) = (f(x) + a)^2$이 실수 전체의 집합에서 연속이려면, 함수 $f(x)$가 불연속일 가능성이 있는 지점인 $x=0$에서 $g(x)$가 연속이어야 합니다.

먼저 $x=0$에서 $f(x)$의 좌극한과 우극한(함숫값)을 구합니다.
1) 좌극한: $\lim_{x \to 0^-} f(x) = \lim_{x \to 0^-} (x - \frac{1}{2}) = -\frac{1}{2}$
2) 우극한 및 함숫값: $\lim_{x \to 0^+} f(x) = f(0) = -(0)^2 + 3 = 3$

이제 $g(x) = (f(x) + a)^2$이 $x=0$에서 연속이 되기 위한 조건을 구합니다.
$\lim_{x \to 0^-} g(x) = \lim_{x \to 0^+} g(x)$ 이어야 하므로,
$(-\frac{1}{2} + a)^2 = (3 + a)^2$

이 방정식을 풉니다.
$(a - \frac{1}{2})^2 = (a + 3)^2$
$a^2 - a + \frac{1}{4} = a^2 + 6a + 9$

양변에서 $a^2$을 소거하고 정리하면:
$-a + \frac{1}{4} = 6a + 9$
$-7a = 9 - \frac{1}{4}$
$-7a = \frac{36}{4} - \frac{1}{4}$
$-7a = \frac{35}{4}$
$a = -\frac{35}{4} \times \frac{1}{7}$
$a = -\frac{5}{4}$

따라서 상수 $a$의 값은 $-\frac{5}{4}$입니다.
