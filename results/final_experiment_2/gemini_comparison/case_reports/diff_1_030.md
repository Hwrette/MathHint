## 원본 해설 전체

[해설]
$f \left( x \right) = x^{3} + a x + 9$에서
$f' \left( x \right) = 3 x^{2} + a$
$x = - 1$에서 극대이므로
$f' \left( - 1 \right) = 0$,    $3 + a = 0$,    $a = - 3$
이때 $f' \left( x \right) = 3 x^{2} - 3 = 3 \left( x + 1 \right) \left( x - 1 \right)$이므로 $f' \left( x \right) = 0$에서
$x = - 1$ 또는 $x = 1$
함수 $f \left( x \right)$의 증가와 감소를 표로 나타내면 다음과 같다.

$x$	$\cdots$	$- 1$	$\cdots$	$1$	$\cdots$
$f' \left( x \right)$	$+$	$0$	$-$	$0$	$+$
$f \left( x \right)$	$\nearrow$	$11$	$\searrow$	$7$	$\nearrow$

따라서 함수 $f \left( x \right)$는 $x = 1$에서 극솟값 $7$을 갖는다.

### 생성 풀이 전체

함수 $f(x) = x^3 + ax + 9$가 $x = -1$에서 극대이므로, 미분계수 $f'(-1) = 0$이어야 합니다.

먼저 $f(x)$를 미분하면 다음과 같습니다.
$f'(x) = 3x^2 + a$

$x = -1$에서 극값을 가지므로 $f'(-1) = 0$을 대입합니다.
$f'(-1) = 3(-1)^2 + a = 0$
$3 + a = 0$
$a = -3$

따라서 함수는 $f(x) = x^3 - 3x + 9$가 됩니다.
극값을 찾기 위해 $f'(x) = 3x^2 - 3 = 0$을 풀면,
$3(x^2 - 1) = 0$
$3(x - 1)(x + 1) = 0$
$x = 1$ 또는 $x = -1$

$x = -1$에서 극대이므로, $x = 1$에서 극솟값을 가집니다.
극솟값은 $f(1)$을 계산하여 구할 수 있습니다.
$f(1) = (1)^3 - 3(1) + 9$
$f(1) = 1 - 3 + 9$
$f(1) = 7$

따라서 함수 $f(x)$의 극솟값은 7입니다.
