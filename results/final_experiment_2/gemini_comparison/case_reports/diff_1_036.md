[해설]
직선 $y = 5$는 기울기가 $0$이므로 곡선 $y = f \left( x \right)$의 그래프와 직선 $y = 5$가 접하는 점의 $x$좌표는 $f' \left( x \right) = 0$을 만족시킨다.
$f \left( x \right) = x^{3} + 3 a x^{2} - 9 a^{2} x + 4$에서
$f' \left( x \right) = 3 x^{2} + 6 a x - 9 a^{2}$
$f' \left( x \right) = 0$에서
$3 x^{2} + 6 a x - 9 a^{2} = 0$,    $3 \left( x - a \right) \left( x + 3 a \right) = 0$
$\therefore$ $x = a$ 또는 $x = - 3 a$
(ⅰ) $x = a$일 때
$f \left( a \right) = a^{3} + 3 a \times a^{2} - 9 a^{2} \times a + 4 = - 5 a^{3} + 4$
이때 접선의 방정식이 $y = 5$이므로
$- 5 a^{3} + 4 = 5$,    $- 5 a^{3} = 1$,    $a^{3} = - \frac{1}{5}$
$a$는 양수이므로 조건을 만족시키지 않는다.
(ⅱ) $x = - 3 a$일 때
$f \left( - 3 a \right)$$= \left( - 3 a \right)^{3} + 3 a \times \left( - 3 a \right)^{2} - 9 a^{2} \times \left( - 3 a \right) + 4$
$= - 27 a^{3} + 27 a^{3} + 27 a^{3} + 4 = 27 a^{3} + 4$
이때 접선의 방정식이 $y = 5$이므로
$27 a^{3} + 4 = 5$,    $27 a^{3} = 1$,    $a^{3} = \frac{1}{27}$
$a$가 양수이므로    $a = \frac{1}{3}$
(ⅰ), (ⅱ)에 의하여    $a = \frac{1}{3}$
$\therefore$ $f \left( x \right) = x^{3} + x^{2} - x + 4$
$\therefore$ $f \left( 2 \right) = 2^{3} + 2^{2} - 2 + 4 = 14$

### 생성 풀이 전체

함수 $f(x) = x^3 + 3ax^2 - 9a^2x + 4$에 대하여, 직선 $y=5$가 곡선 $y=f(x)$에 접한다는 것은 어떤 $x=k$에서 $f(k)=5$이고 $f'(k)=0$임을 의미합니다.

먼저 $f'(x)$를 구하면,
$f'(x) = 3x^2 + 6ax - 9a^2$
$f'(x) = 3(x^2 + 2ax - 3a^2) = 3(x+3a)(x-a)$

$f'(x)=0$이 되는 $x$의 값은 $x = -3a$ 또는 $x = a$입니다.

**경우 1: $x = a$에서 접하는 경우**
$f(a) = a^3 + 3a(a^2) - 9a^2(a) + 4 = 5$
$a^3 + 3a^3 - 9a^3 + 4 = 5$
$-5a^3 = 1$
$a^3 = -\frac{1}{5}$
$a$는 양수라는 조건에 모순됩니다.

**경우 2: $x = -3a$에서 접하는 경우**
$f(-3a) = (-3a)^3 + 3a(-3a)^2 - 9a^2(-3a) + 4 = 5$
$-27a^3 + 27a^3 + 27a^3 + 4 = 5$
$27a^3 = 1$
$a^3 = \frac{1}{27}$
$a$는 양수이므로 $a = \frac{1}{3}$입니다.

이제 $a = \frac{1}{3}$을 $f(x)$에 대입합니다.
$f(x) = x^3 + 3(\frac{1}{3})x^2 - 9(\frac{1}{3})^2x + 4$
$f(x) = x^3 + x^2 - x + 4$

문제에서 요구하는 $f(2)$의 값은,
$f(2) = 2^3 + 2^2 - 2 + 4$
$f(2) = 8 + 4 - 2 + 4 = 14$

따라서 $f(2) = 14$입니다.
