## 원본 해설 전체

[정답] ③

[해설]
두 곡선 $y = 2 x^{2} - 1$, $y = x^{3} - x^{2} + k$가 만나는 점의 개수가 $2$이므로 방정식 $2 x^{2} - 1 = x^{3} - x^{2} + k$에서
$x^{3} - 3 x^{2} + 1 = - k$
이때 $f \left( x \right) = x^{3} - 3 x^{2} + 1$로 놓으면 $f' \left( x \right) = 3 x^{2} - 6 x$
$f' \left( x \right) = 0$에서 $x = 0$ 또는 $x = 2$
함수 $f \left( x \right)$의 증가와 감소를 표로 나타내면 다음과 같다.

$x$	$\cdots$	$0$	$\cdots$	$2$	$\cdots$
$f' \left( x \right)$	$+$	$0$	$-$	$0$	$+$
$f \left( x \right)$	$\nearrow$	$1$	$\searrow$	$- 3$	$\nearrow$

따라서 함수 $f \left( x \right)$의 그래프는 다음 그림과 같고 양수 $k$에 대하여 직선 $y = - k$와 서로 다른 두 점에서 만나려면
$- k = - 3$$\therefore \quad$$k = 3$

### 생성 풀이 전체

두 곡선 $y = 2x^2 - 1$과 $y = x^3 - x^2 + k$가 만나는 점의 개수가 2개가 되려면, 방정식 $2x^2 - 1 = x^3 - x^2 + k$가 서로 다른 두 실근을 가져야 합니다.

이 식을 정리하면 다음과 같습니다.
$x^3 - 3x^2 + k + 1 = 0$
$k + 1 = -x^3 + 3x^2$

이제 함수 $f(x) = -x^3 + 3x^2$의 그래프를 그려서 $y = k + 1$과의 교점의 개수를 확인합니다.
$f'(x) = -3x^2 + 6x = -3x(x - 2)$
$f'(x) = 0$이 되는 $x$의 값은 $x = 0$ 또는 $x = 2$입니다.

각 극값을 구하면:
- $x = 0$일 때, $f(0) = 0$ (극소값)
- $x = 2$일 때, $f(2) = -8 + 3(4) = 4$ (극대값)

함수 $f(x) = -x^3 + 3x^2$의 그래프는 $x=0$에서 극솟값 0을 갖고, $x=2$에서 극댓값 4를 갖습니다.
직선 $y = k + 1$과 이 그래프가 만나는 점의 개수가 2개가 되려면, 직선이 극댓값이나 극솟값에 접해야 합니다.

1) $k + 1 = 4$인 경우: $k = 3$
2) $k + 1 = 0$인 경우: $k = -1$

문제에서 $k$는 양수라고 하였으므로, $k = 3$이 조건을 만족합니다.
