## 원본 문제와 선택지

다항함수 $f \left( x \right)$에 대하여 함수 $g \left( x \right)$를
$g \left( x \right) = \left( x^{2} + x \right) f \left( x \right)$
라 하자. $\lim_{h \rightarrow 0} \frac{g \left( 1 + h \right) - 4}{h} = 9$일 때, $f \left( 1 \right) \times f' \left( 1 \right)$의 값은?
① $3$		② $\frac{9}{2}$		③ $6$
④ $\frac{15}{2}$		⑤ $9$


## 원본 정답

①

## 원본 해설 전체

[정답] ①

[해설]
$\lim_{h \rightarrow 0} \frac{g \left( 1 + h \right) - 4}{h} = 9$이고 $\lim_{h \rightarrow 0} h = 0$이므로
$\lim_{h \rightarrow 0} \left( g \left( 1 + h \right) - 4 \right) = 0$
함수 $g \left( x \right) = \left( x^{2} + x \right) f \left( x \right)$가 다항함수이므로
$\lim_{h \rightarrow 0} \left( g \left( 1 + h \right) - 4 \right) = g \left( 1 \right) - 4 = 0$에서
$g \left( 1 \right) = 2 f \left( 1 \right) = 4$, $f \left( 1 \right) = 2$
$\lim_{h \rightarrow 0} \frac{g \left( 1 + h \right) - 4}{h} = \lim_{h \rightarrow 0} \frac{g \left( 1 + h \right) - g \left( 1 \right)}{h} = g' \left( 1 \right)$이므로
$g' \left( 1 \right) = 9$
또한 $g' \left( x \right) = \left( 2 x + 1 \right) f \left( x \right) + \left( x^{2} + x \right) f' \left( x \right)$에서
$g' \left( 1 \right) = 3 f \left( 1 \right) + 2 f' \left( 1 \right) = 6 + 2 f' \left( 1 \right)$이므로
$f' \left( 1 \right) = \frac{3}{2}$
따라서 $f \left( 1 \right) \times f' \left( 1 \right) = 2 \times \frac{3}{2} = 3$

### 생성 풀이 전체

주어진 극한식 $\lim_{h \rightarrow 0} \frac{g(1+h)-4}{h} = 9$로부터 다음 두 가지 사실을 알 수 있습니다.

1. 미분계수의 정의에 의해 $g'(1) = 9$입니다.
2. 극한값이 존재하므로 분자의 극한은 0이어야 합니다. 즉, $g(1) - 4 = 0$에서 $g(1) = 4$입니다.

함수 $g(x) = (x^2 + x)f(x)$에 대하여 $x=1$을 대입하면,
$g(1) = (1^2 + 1)f(1) = 2f(1) = 4$
따라서 **$f(1) = 2$**입니다.

다음으로 $g(x)$를 미분하면 곱의 미분법에 의해
$g'(x) = (2x + 1)f(x) + (x^2 + x)f'(x)$
여기에 $x=1$을 대입하면,
$g'(1) = (2(1) + 1)f(1) + (1^2 + 1)f'(1) = 3f(1) + 2f'(1) = 9$

위에서 구한 $f(1) = 2$를 대입하면,
$3(2) + 2f'(1) = 9$
$6 + 2f'(1) = 9$
$2f'(1) = 3$
따라서 **$f'(1) = \frac{3}{2}$**입니다.

구하고자 하는 값은 $f(1) \times f'(1)$이므로,
$f(1) \times f'(1) = 2 \times \frac{3}{2} = 3$
