[해설]
최고차항의 계수가 $1$이고 $f \left( 0 \right) = 0$인 삼차함수 $f \left( x \right)$를
$f \left( x \right) = x^{3} + p x^{2} + q x$ ($p$, $q$는 상수)
라 하면    $f' \left( x \right) = 3 x^{2} + 2 p x + q$
$\lim_{x \rightarrow a} \frac{f \left( x \right) - 1}{x} - a = 3$에서 $x \rightarrow a$일 때 (분모)$\rightarrow 0$이고 극한값이 존재하므로 (분자)$\rightarrow 0$이다.
즉 $\lim_{x \rightarrow a} {\left\{ f \left( x \right) - 1 \right\}} = 0$에서    $f \left( a \right) = 1$
$\lim_{x \rightarrow a} \frac{f \left( x \right) - f \left( a \right)}{x} - a = 3$에서    $f' \left( a \right) = 3$
즉 곡선 $y = f \left( x \right)$ 위의 점 $\left( a , f \left( a \right) \right)$에서의 접선의 방정식은
$y - f \left( a \right) = f' \left( a \right) \left( x - a \right)$에서    $y = 3 \left( x - a \right) + 1$
이 직선의 $y$절편이 $4$이므로
$- 3 a + 1 = 4$,    $a = - 1$
즉 $f \left( - 1 \right) = 1$에서    $- 1 + p - q = 1$,    $p - q = 2$
$f' \left( - 1 \right) = 3$에서    $3 - 2 p + q = 3$,    $- 2 p + q = 0$
두 식을 연립하여 풀면    $p = - 2$, $q = - 4$
따라서 $f \left( x \right) = x^{3} - 2 x^{2} - 4 x$이므로
$f \left( 1 \right)$$= 1^{3} - 2 \times 1^{2} - 4 \times 1$
$= - 5$

### 생성 풀이 전체

삼차함수 $f(x)$의 최고차항의 계수가 1이고 $f(0)=0$이므로, $f(x) = x^3 + px^2 + qx$라고 할 수 있습니다.

1. **미분계수의 정의 이용:**
   $\lim_{x \rightarrow a} \frac{f(x) - 1}{x - a} = 3$이라는 식에서, 분모가 0으로 가므로 분자도 0으로 가야 합니다. 즉, $f(a) - 1 = 0$이므로 $f(a) = 1$입니다.
   따라서 주어진 식은 미분계수의 정의에 의해 $f'(a) = 3$이 됩니다.

2. **접선의 방정식 이용:**
   곡선 $y=f(x)$ 위의 점 $(a, f(a))$에서의 접선의 방정식은 다음과 같습니다.
   $y - f(a) = f'(a)(x - a)$
   $f(a)=1, f'(a)=3$을 대입하면,
   $y - 1 = 3(x - a) \implies y = 3x - 3a + 1$
   이 접선의 $y$절편이 4라고 하였으므로, $x=0$일 때 $y=4$입니다.
   $-3a + 1 = 4 \implies -3a = 3 \implies a = -1$

3. **$f(x)$ 구하기:**
   $a = -1$이므로 $f(-1) = 1$이고 $f'(-1) = 3$입니다.
   $f(x) = x^3 + px^2 + qx$에서
   $f(-1) = -1 + p - q = 1 \implies p - q = 2$  --- (1)
   $f'(x) = 3x^2 + 2px + q$
   $f'(-1) = 3 - 2p + q = 3 \implies -2p + q = 0 \implies q = 2p$ --- (2)

   (2)를 (1)에 대입하면:
   $p - 2p = 2 \implies -p = 2 \implies p = -2$
   $q = 2(-2) = -4$
   따라서 $f(x) = x^3 - 2x^2 - 4x$입니다.

4. **$f(1)$ 계산:**
   $f(1) = 1^3 - 2(1)^2 - 4(1) = 1 - 2 - 4 = -5$
