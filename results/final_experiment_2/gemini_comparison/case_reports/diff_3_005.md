## 원본 문제와 선택지

다항함수 ${f (x)}$가
$\lim_{x \rightarrow \infty} {\frac{f (x)}{2 x^{2}}} = 1$, $\lim_{x \rightarrow 1} {\frac{f (x) - 3}{\left( x - 1 \right) \left( x - 2 \right)} = 4}$
를 만족시킬 때, $f (4)$의 값을 구하시오.

## 원본 해설 전체

[정답] $\mathbf{9}$

[해설]
$f \left( x \right)$가 다항함수이고 $\lim_{x \rightarrow \infty} {\frac{f \left( x \right)}{2 x^{2}} = 1}$이므로
$f \left( x \right) = 2 x^{2} + a x + b$ ($a , b$는 실수)
$\lim_{x \rightarrow 1} {\frac{f \left( x \right) - 3}{\left( x - 1 \right) \left( x - 2 \right)} = 4}$이고 $\lim_{x \rightarrow 1} {\left( x - 1 \right) \left( x - 2 \right) = 0}$이므로
$\lim_{x \rightarrow 1} {\left\{ f \left( x \right) - 3 \right\}} = 0$
$\lim_{x \rightarrow 1} {f \left( x \right)}$$= \lim_{x \rightarrow 1} {\left[ \left\{ f \left( x \right) - 3 \right\} + 3 \right]}$
$= \lim_{x \rightarrow 1} {\left\{ f \left( x \right) - 3 \right\}} + \lim_{x \rightarrow 1} {3}$
$= 0 + 3 = 3$
$\lim_{x \rightarrow 1} {f \left( x \right)} = 2 + a + b = 3$
즉, $b = - a + 1$
$f \left( x \right) - 3$$= 2 x^{2} + a x - a - 2$
$= \left( x - 1 \right) \left( 2 x + a + 2 \right)$
$\lim_{x\to1}\frac{f(x)-3}{(x-1)(x-2)}$$=\lim_{x\to1}\frac{(x-1)(2x+a+2)}{(x-1)(x-2)}$
$= \frac{2 + a + 2}{- 1} = 4$
따라서 $a = - 8$, $b = 9$이므로 $f \left( x \right) = 2 x^{2} - 8 x + 9$
$\therefore$$f \left( 4 \right) = 9$

### 생성 풀이 전체

주어진 두 극한 조건을 이용하여 다항함수 $f(x)$를 구합니다.

**1. 첫 번째 조건 분석:**
$\lim_{x \rightarrow \infty} \frac{f(x)}{2x^2} = 1$
이 식에서 $x \rightarrow \infty$일 때 $f(x)$는 $2x^2$과 차수가 같고 최고차항의 계수가 2임을 알 수 있습니다. 따라서 $f(x)$는 이차함수이며, 다음과 같이 설정할 수 있습니다.
$f(x) = 2x^2 + ax + b$

**2. 두 번째 조건 분석:**
$\lim_{x \rightarrow 1} \frac{f(x) - 3}{(x - 1)(x - 2)} = 4$
분모가 $x \rightarrow 1$일 때 0으로 가므로, 극한값이 존재하려면 분자도 0이어야 합니다.
$f(1) - 3 = 0 \implies f(1) = 3$
$f(1) = 2(1)^2 + a(1) + b = 3 \implies a + b = 1$  --- (식 1)

이제 로피탈의 정리를 사용하거나 식을 대입하여 극한값을 계산합니다.
$\lim_{x \rightarrow 1} \frac{f'(x)}{(x-2) + (x-1)} = \lim_{x \rightarrow 1} \frac{4x + a}{2x - 3} = 4$
$x = 1$을 대입하면:
$\frac{4(1) + a}{2(1) - 3} = 4$
$\frac{4 + a}{-1} = 4$
$4 + a = -4 \implies a = -8$

**3. 상수 $b$ 구하기:**
(식 1)에 $a = -8$을 대입하면:
$-8 + b = 1 \implies b = 9$

따라서 $f(x) = 2x^2 - 8x + 9$입니다.

**4. $f(4)$ 구하기:**
$f(4) = 2(4)^2 - 8(4) + 9$
$f(4) = 2(16) - 32 + 9$
$f(4) = 32 - 32 + 9 = 9$
