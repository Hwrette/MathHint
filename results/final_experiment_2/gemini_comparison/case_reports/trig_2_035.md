## 원본 문제와 선택지

함수 $f (x) = \sin \frac{\pi}{4} x$라 할 때, $0 < x < 16$에서 부등식
$f \left( 2 + x \right) f \left( 2 - x \right) < \frac{1}{4}$
을 만족시키는 모든 자연수 $x$의 값의 합을 구하시오.

[정답] $32$

[해설]
$f \left( x \right) = \sin \frac{\pi}{4} x$이므로
$f \left( 2 + x \right) = \sin \frac{\pi}{4} \left( 2 + x \right) = \cos \frac{\pi}{4} x$,
$f \left( 2 - x \right) = \sin \frac{\pi}{4} \left( 2 - x \right) = \cos \frac{\pi}{4} x$
부등식 $f \left( 2 + x \right) f \left( 2 - x \right) < \frac{1}{4}$에서
$\cos^{2} \frac{\pi}{4} x < \frac{1}{4}$				$\cdots \cdots$ ㉠
$\frac{\pi}{4} x = \theta$라 하면 $0 < x < 16$에서 $0 < \theta < 4 \pi$이고, ㉠에서
$\cos^{2} \theta - \frac{1}{4} < 0$,    $\left( \cos \theta + \frac{1}{2} \right) \left( \cos \theta - \frac{1}{2} \right) < 0$
$- \frac{1}{2} < \cos \theta < \frac{1}{2}$
$\therefore$ $\frac{\pi}{3} < \theta < \frac{2}{3} \pi$ 또는 $\frac{4}{3} \pi < \theta < \frac{5}{3} \pi$
또는 $\frac{7}{3} \pi < \theta < \frac{8}{3} \pi$ 또는 $\frac{10}{3} \pi < \theta < \frac{11}{3} \pi$
$\frac{\pi}{4} x = \theta$이므로 $x$의 값의 범위는
$\frac{4}{3} < x < \frac{8}{3}$ 또는 $\frac{16}{3} < x < \frac{20}{3}$
또는 $\frac{28}{3} < x < \frac{32}{3}$ 또는 $\frac{40}{3} < x < \frac{44}{3}$
따라서 자연수 $x$는 $2$, $6$, $10$, $14$이므로 모든 자연수 $x$의 값의 합은
$2 + 6 + 10 + 14 = 32$

$g (x) = f \left( 2 + x \right) f \left( 2 - x \right)$라 하면 함수 $f$의 주기가 $8$이므로 함수 $g$의 주기도 $8$이다.
$g (1) = f \left( 3 \right) f \left( 1 \right) = \frac{1}{2}$
$g (2) = f \left( 4 \right) f \left( 0 \right) = 0$

이므로 $x = 1$, $2$, $\cdots$, $15$인 자연수 $x$에 대하여
$g (x) = f \left( 2 + x \right) f \left( 2 - x \right) < \frac{1}{4}$

### 생성 풀이 전체

주어진 함수 $f(x) = \sin \frac{\pi}{4} x$에 대하여 부등식 $f(2+x)f(2-x) < \frac{1}{4}$을 풀어보겠습니다.

먼저 $f(2+x)$와 $f(2-x)$를 계산합니다.
$f(2+x) = \sin \frac{\pi}{4}(2+x) = \sin \left( \frac{\pi}{2} + \frac{\pi}{4}x \right) = \cos \frac{\pi}{4}x$
$f(2-x) = \sin \frac{\pi}{4}(2-x) = \sin \left( \frac{\pi}{2} - \frac{\pi}{4}x \right) = \cos \frac{\pi}{4}x$

따라서 주어진 부등식은 다음과 같습니다.
$\cos \frac{\pi}{4}x \cdot \cos \frac{\pi}{4}x < \frac{1}{4}$
$\cos^2 \frac{\pi}{4}x < \frac{1}{4}$

이 부등식은 $-\frac{1}{2} < \cos \frac{\pi}{4}x < \frac{1}{2}$와 같습니다.
$0 < x < 16$의 범위에서 $\theta = \frac{\pi}{4}x$라 하면 $0 < \theta < 4\pi$입니다.
$\cos \theta$의 값이 $-\frac{1}{2}$과 $\frac{1}{2}$ 사이에 있는 구간을 찾으면:
$\frac{\pi}{3} < \theta < \frac{2\pi}{3}$ 또는 $\frac{4\pi}{3} < \theta < \frac{5\pi}{3}$ 또는 $\frac{7\pi}{3} < \theta < \frac{8\pi}{3}$ 또는 $\frac{10\pi}{3} < \theta < \frac{11\pi}{3}$

각 구간에 $\theta = \frac{\pi}{4}x$를 대입하여 $x$의 범위를 구합니다.
1) $\frac{\pi}{3} < \frac{\pi}{4}x < \frac{2\pi}{3} \implies \frac{4}{3} < x < \frac{8}{3} \approx 1.33 < x < 2.66$
   이 범위의 자연수 $x = 2$
2) $\frac{4\pi}{3} < \frac{\pi}{4}x < \frac{5\pi}{3} \implies \frac{16}{3} < x < \frac{20}{3} \approx 5.33 < x < 6.66$
   이 범위의 자연수 $x = 6$
3) $\frac{7\pi}{3} < \frac{\pi}{4}x < \frac{8\pi}{3} \implies \frac{28}{3} < x < \frac{32}{3} \approx 9.33 < x < 10.66$
   이 범위의 자연수 $x = 10$
4) $\frac{10\pi}{3} < \frac{\pi}{4}x < \frac{11\pi}{3} \implies \frac{40}{3} < x < \frac{44}{3} \approx 13.33 < x < 14.66$
   이 범위의 자연수 $x = 14$

구하는 자연수 $x$는 $2, 6, 10, 14$이며, 이들의 합은 $2 + 6 + 10 + 14 = 32$입니다.
