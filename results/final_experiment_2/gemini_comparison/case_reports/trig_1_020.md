## 원본 문제와 선택지

양수 $a$에 대하여 $\frac{\pi}{3} \le x \le \frac{4}{3} \pi$에서 정의된 함수
$f \left( x \right) = 2 a \cos x + a$
의 최댓값과 최솟값의 곱이 $- 8$일 때, $a$의 값을 구하시오.


## 원본 정답

$2$

## 원본 해설 전체

[정답] $2$

[해설]
$f \left( \frac{\pi}{3} \right) = 2 a \times \frac{1}{2} + a = 2 a$
$f \left( \pi \right) = 2 a \times \left( - 1 \right) + a = - a$
$f \left( \frac{4}{3} \pi \right) = 2 a \times \left( - \frac{1}{2} \right) + a = 0$
함수 $y = f \left( x \right)$의 그래프의 개형은 다음과 같다.

함수 $f \left( x \right)$의 최댓값은 $2 a$, 최솟값은 $- a$
최댓값과 최솟값의 곱은
$2 a \times \left( - a \right) = - 2 a^{2} = - 8$, $a^{2} = 4$
따라서 $a > 0$이므로 $a = 2$

### 생성 풀이 전체

주어진 함수 $f(x) = 2a \cos x + a$에서 $a > 0$이므로, $f(x)$의 최댓값과 최솟값은 $\cos x$의 범위에 의해 결정됩니다.

주어진 범위 $\frac{\pi}{3} \le x \le \frac{4}{3} \pi$에서 $\cos x$의 값의 범위를 구하면 다음과 같습니다.
- $x = \frac{\pi}{3}$일 때, $\cos \frac{\pi}{3} = \frac{1}{2}$
- $x = \pi$일 때, $\cos \pi = -1$
- $x = \frac{4}{3} \pi$일 때, $\cos \frac{4}{3} \pi = -\frac{1}{2}$

따라서 이 범위에서 $\cos x$의 최솟값은 $-1$이고, 최댓값은 $\frac{1}{2}$입니다. 즉, $-1 \le \cos x \le \frac{1}{2}$입니다.

이제 $f(x) = 2a \cos x + a$의 최댓값과 최솟값을 구합니다. $a > 0$이므로:
- 최댓값 $M = f(\frac{\pi}{3}) = 2a(\frac{1}{2}) + a = a + a = 2a$
- 최솟값 $m = f(\pi) = 2a(-1) + a = -2a + a = -a$

문제에서 최댓값과 최솟값의 곱이 $-8$이라고 하였으므로:
$M \times m = (2a) \times (-a) = -8$
$-2a^2 = -8$
$a^2 = 4$

$a$는 양수이므로 $a = 2$입니다.

최종정답: 2
