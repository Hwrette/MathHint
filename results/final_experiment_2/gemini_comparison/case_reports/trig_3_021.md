### 생성 풀이 전체

주어진 두 함수 $y = \sin x$와 $y = \cos \left( x + \frac{\pi}{2} \right) + 1$이 만나는 점의 $x$좌표를 구하기 위해 방정식을 세웁니다.

1. **함수 정리:**
   삼각함수의 성질에 의해 $\cos \left( x + \frac{\pi}{2} \right) = -\sin x$입니다.
   따라서 두 함수의 교점의 $x$좌표는 다음 방정식을 만족합니다.
   $$\sin x = -\sin x + 1$$

2. **방정식 풀이:**
   $$2 \sin x = 1$$
   $$\sin x = \frac{1}{2}$$

3. **범위 내의 해 구하기:**
   $0 \le x < 2\pi$ 범위에서 $\sin x = \frac{1}{2}$을 만족하는 $x$값은 다음과 같습니다.
   - 제1사분면: $x = \frac{\pi}{6}$
   - 제2사분면: $x = \pi - \frac{\pi}{6} = \frac{5}{6}\pi$

4. **$x$좌표의 합:**
   구하는 모든 $x$좌표의 합은
   $$\frac{\pi}{6} + \frac{5}{6}\pi = \frac{6}{6}\pi = \pi$$

따라서 두 그래프가 만나는 모든 점의 $x$좌표의 합은 $\pi$입니다.
