함수 $f (x)$가 실수 전체의 집합에서 연속이므로
$x = 3$에서도 연속이다.
즉, $\lim_{x \rightarrow 3 -} {f (x)}$$= \lim_{x \rightarrow 3 +} {f (x)}$$= f (3)$
$\lim_{x \rightarrow 3 -} {\frac{x^{2} + a x + b}{x - 3}}$의 값이 존재하고, $x \rightarrow 3 -$일 때
(분모)$\rightarrow 0$이므로 (분자)$\rightarrow 0$이다.
즉, $\lim_{x \rightarrow 3 -} {(x^{2} + a x + b)}$$= 0$이므로
$9 + 3 a + b$$= 0$, $b$$= - 3 a - 9$
$\lim_{x \rightarrow 3 -} {\frac{x^{2} + a x - 3 a - 9}{x - 3}}$$= \lim_{x \rightarrow 3 -} {\frac{(x - 3) (x + 3 + a)}{x - 3}}$
$= \lim_{x \rightarrow 3 -} {(x + 3 + a)}$
$= 6 + a$
한편, $\lim_{x \rightarrow 3 +} {f (x)}$$= f (3)$$= 7$
그러므로 $6 + a$$= 7$
따라서 $a$$= 1$, $b$$= - 12$이므로 $a - b$$= 13$

### 생성 풀이 전체

함수 $f(x)$가 실수 전체의 집합에서 연속이려면, 모든 점에서 연속이어야 합니다. 특히 $x=3$에서 연속이어야 하므로 다음 조건이 성립해야 합니다.

$$\lim_{x \to 3^-} f(x) = \lim_{x \to 3^+} f(x) = f(3)$$

**1. 우극한과 함숫값 구하기:**
$x \geq 3$일 때 $f(x) = \frac{2x+1}{x-2}$이므로,
$$\lim_{x \to 3^+} f(x) = f(3) = \frac{2(3)+1}{3-2} = \frac{7}{1} = 7$$

**2. 좌극한 구하기:**
$x < 3$일 때 $f(x) = \frac{x^2+ax+b}{x-3}$입니다. 극한값이 존재하여 7이 되어야 하므로, 분자인 $x^2+ax+b$가 $x=3$에서 0이 되어야 합니다.
$$3^2 + 3a + b = 0 \implies 9 + 3a + b = 0 \implies b = -3a - 9$$

이제 극한식을 다시 쓰면:
$$\lim_{x \to 3^-} \frac{x^2+ax+(-3a-9)}{x-3} = 7$$
분자를 인수분해하면 $x^2-9 + a(x-3) = (x-3)(x+3) + a(x-3) = (x-3)(x+3+a)$이므로,
$$\lim_{x \to 3^-} \frac{(x-3)(x+3+a)}{x-3} = \lim_{x \to 3^-} (x+3+a) = 3+3+a = 6+a$$

**3. $a, b$ 구하기:**
연속 조건에 의해 $6+a = 7$이므로,
$$a = 1$$
이를 $b = -3a - 9$에 대입하면,
$$b = -3(1) - 9 = -12$$

**4. $a-b$ 계산:**
$$a - b = 1 - (-12) = 1 + 12 = 13$$

따라서 정답은 ⑤번입니다.
