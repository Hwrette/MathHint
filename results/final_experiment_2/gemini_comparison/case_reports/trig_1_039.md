## 원본 문제와 선택지

$0 < x \leq 2 \pi$일 때, 방정식
$\cos^{2} x - 1 = 2 \sin x$
의 모든 해의 합은?
① $\frac{3}{2} \pi$		② $2 \pi$		③ $\frac{5}{2} \pi$
④ $3 \pi$		⑤ $\frac{7}{2} \pi$


## 원본 정답

④

## 원본 해설 전체

[정답] ④

[해설]
$\sin^{2} x + \cos^{2} x = 1$이므로
$\cos^{2} x - 1 = 2 \sin x$에서
$\left( 1 - \sin^{2} x \right) - 1 = 2 \sin x$
$\sin^{2} x + 2 \sin x = 0$, $\sin x \left( \sin x + 2 \right) = 0$
$- 1 \leq \sin x \leq 1$이므로 $\sin x = 0$
$0 < x \leq 2 \pi$에서 $x = \pi$ 또는 $x = 2 \pi$
따라서 모든 해의 합은 $3 \pi$

### 생성 풀이 전체

주어진 방정식 $\cos^{2} x - 1 = 2 \sin x$를 풀어보겠습니다.

1. **삼각함수의 기본 성질 이용:**
   $\sin^2 x + \cos^2 x = 1$이므로, $\cos^2 x - 1 = -\sin^2 x$입니다.
   이를 방정식에 대입하면:
   $-\sin^2 x = 2 \sin x$

2. **방정식 정리:**
   $\sin^2 x + 2 \sin x = 0$
   $\sin x (\sin x + 2) = 0$

3. **해 구하기:**
   따라서 $\sin x = 0$ 또는 $\sin x = -2$입니다.
   그런데 모든 실수 $x$에 대하여 $-1 \leq \sin x \leq 1$이므로, $\sin x = -2$를 만족하는 실수는 존재하지 않습니다.
   그러므로 $\sin x = 0$을 만족하는 $x$의 값을 구해야 합니다.

4. **범위 내의 해 찾기:**
   주어진 범위 $0 < x \leq 2\pi$에서 $\sin x = 0$을 만족하는 $x$는:
   $x = \pi, \quad x = 2\pi$

5. **해의 합:**
   모든 해의 합은 $\pi + 2\pi = 3\pi$입니다.

따라서 정답은 ④번입니다.

최종정답: ④
