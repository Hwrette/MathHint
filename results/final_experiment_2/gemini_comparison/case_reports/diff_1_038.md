$f \left( x \right) = x^{3} - 6 x^{2} + a x + b$
라 하자. 함수 $f \left( x \right)$는 $x = 3$에서 극값을 갖고, 함수 $f \left( x \right)$의 극댓값과 극솟값의 합이 $8$이다. $a + b$의 값을 구하시오.

[해설]
$f' \left( x \right) = 3 x^{2} - 12 x + a$
$f' \left( 3 \right) = 27 - 36 + a = 0$이므로 $a = 9$
$f' \left( x \right) = 3 x^{2} - 12 x + 9 = 3 \left( x - 1 \right) \left( x - 3 \right)$
$f' \left( x \right) = 0$에서 $x = 1$ 또는 $x = 3$
함수 $f \left( x \right)$의 증가와 감소를 표로 나타내면

$x$	$\cdots$	$1$	$\cdots$	$3$	$\cdots$
$f' \left( x \right)$	$+$	$0$	$-$	$0$	$+$
$f \left( x \right)$	$\nearrow$	극대	$\searrow$	극소	$\nearrow$

함수 $f \left( x \right)$의 극댓값은 $f \left( 1 \right) = 4 + b$이고,
함수 $f \left( x \right)$의 극솟값은 $f \left( 3 \right) = b$이므로
$4 + 2 b = 8$, $b = 2$
따라서 $a + b = 11$

1. **$a$의 값 구하기**
   $f'(x) = 3x^2 - 12x + a$
   $f'(3) = 3(3)^2 - 12(3) + a = 27 - 36 + a = -9 + a$
   $-9 + a = 0$ 이므로 **$a = 9$**입니다.

2. **극값 구하기**
   $f'(x) = 3x^2 - 12x + 9 = 3(x^2 - 4x + 3) = 3(x-1)(x-3)$

   따라서 극값은 $f(1)$과 $f(3)$입니다.

   $f(1) = 1^3 - 6(1)^2 + 9(1) + b = 1 - 6 + 9 + b = 4 + b$
   $f(3) = 3^3 - 6(3)^2 + 9(3) + b = 27 - 54 + 27 + b = b$

3. **$b$의 값 구하기**
   극댓값과 극솟값의 합이 8이라고 하였으므로,
   $(4 + b) + b = 8$
   $2b + 4 = 8$
   $2b = 4$
   **$b = 2$**

4. **$a + b$ 계산하기**
   $a + b = 9 + 2 = 11$
