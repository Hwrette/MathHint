### 생성 풀이 전체

함수 $f(x)$에서 $x$의 값이 $1$에서 $t$까지 변할 때의 평균변화율은 다음과 같이 정의됩니다.
$$\frac{f(t) - f(1)}{t - 1} = \sqrt{t^2 + 8}$$

이 식의 양변에 $t - 1$을 곱하면 다음과 같습니다.
$$f(t) - f(1) = (t - 1)\sqrt{t^2 + 8}$$
$$f(t) = (t - 1)\sqrt{t^2 + 8} + f(1)$$

함수 $f(x)$의 $x=1$에서의 순간변화율(미분계수) $f'(1)$은 도함수의 정의에 의해 다음과 같습니다.
$$f'(1) = \lim_{t \to 1} \frac{f(t) - f(1)}{t - 1}$$

문제에서 주어진 평균변화율의 식을 위 극한식에 대입하면 다음과 같습니다.
$$f'(1) = \lim_{t \to 1} \sqrt{t^2 + 8}$$

이제 $t$에 $1$을 대입하여 극한값을 구합니다.
$$f'(1) = \sqrt{1^2 + 8} = \sqrt{1 + 8} = \sqrt{9} = 3$$

따라서 함수 $f(x)$의 $x=1$에서의 순간변화율은 $3$입니다.
