는 $x = 1$에서 극소이다. 함수 $f (x)$의 극솟값이 $\mathrm{- 2}$일 때, 함수 $f (x)$의 극댓값을 구하시오.

## 원본 해설 전체

[해설]
함수 $f \left( x \right) = a x^{3} + b x + a$가 $x = 1$에서 극솟값 $- 2$를 가지므로
$f \left( 1 \right) = - 2$, $f' \left( 1 \right) = 0$
$f \left( 1 \right) = a + b + a = 2 a + b = - 2$		$\cdots \cdots$ ㉠
$f' \left( x \right) = 3 a x^{2} + b$에서    $f' \left( 1 \right) = 3 a + b = 0$		$\cdots \cdots$ ㉡
㉠과 ㉡을 연립하면    $a = 2$, $b = - 6$
$\therefore$ $f \left( x \right) = 2 x^{3} - 6 x + 2$, $f' \left( x \right) = 6 x^{2} - 6$
$f' \left( x \right) = 6 x^{2} - 6 = 0$에서    $x = - 1$ 또는 $x = 1$
함수 $f \left( x \right)$는 $x = - 1$에서 극댓값을 가지므로
$f \left( - 1 \right) = - 2 + 6 + 2 = 6$

### 생성 풀이 전체

삼차함수 $f(x) = ax^3 + bx + a$가 $x=1$에서 극소이므로, 미분계수 $f'(1) = 0$이어야 합니다.

1. **도함수 구하기:**
   $f'(x) = 3ax^2 + b$

2. **$f'(1) = 0$ 조건 이용:**
   $f'(1) = 3a(1)^2 + b = 3a + b = 0$
   따라서 $b = -3a$입니다.

3. **$f(x)$ 식에 대입:**
   $f(x) = ax^3 - 3ax + a$
   $f'(x) = 3ax^2 - 3a = 3a(x^2 - 1) = 3a(x-1)(x+1)$
   $f'(x) = 0$이 되는 $x$는 $x=1$ 또는 $x=-1$입니다.

4. **극솟값 조건 이용:**
   $x=1$에서 극솟값이 $-2$이므로, $f(1) = -2$입니다.
   $f(1) = a(1)^3 - 3a(1) + a = a - 3a + a = -a$
   $-a = -2$ 이므로 $a = 2$입니다.
   $a=2$이면 $b = -3(2) = -6$입니다.

5. **극댓값 구하기:**
   $f(x) = 2x^3 - 6x + 2$
   극댓값은 $x=-1$에서 발생합니다.
   $f(-1) = 2(-1)^3 - 6(-1) + 2$
   $f(-1) = -2 + 6 + 2 = 6$

따라서 함수 $f(x)$의 극댓값은 6입니다.
