$f (x) = 2 x^{3} - 6 x^{2} + k$라 하면 방정식의 실근은 함수 $y = f (x)$의 그래프와 $x$축이 만나는 점의 $x$좌표이다.
$f' (x)$$= 6 x^{2} - 12 x$$= 6 x (x - 2)$
이므로 $f' (x) = 0$에서
$x = 0$ 또는 $x = 2$
함수 $f (x)$의 증가와 감소를 표로 나타내면 다음과 같다.

$x$	$\cdots$	$\mathrm{0}$	$\cdots$	$\mathrm{2}$	$\cdots$
$f' (x)$	$+$	$\mathrm{0}$	$-$	$\mathrm{0}$	$+$
$f (x)$	$\nearrow$	$k$	$\searrow$	$k - 8$	$\nearrow$

이때, 방정식 $f \left( x \right) = 0$이 $\mathrm{2}$개의 서로 다른 양의 실근을 갖기 위해서는 그림과 같이 함수 $f (x)$의 극댓값은 양수이어야 하고 함수 $f (x)$의 극솟값은 음수이어야 한다.

따라서 $k > 0$이고 $k - 8 < 0$이므로
$0 < k < 8$
따라서 정수 $k$는 $1$, $2$, $3$, $4$, $5$, $6$, $7$의 $\mathrm{7}$개다.

### 생성 풀이 전체

방정식 $2x^3 - 6x^2 + k = 0$을 변형하면 다음과 같습니다.
$2x^3 - 6x^2 = -k$

함수 $f(x) = 2x^3 - 6x^2$이라 하고, 이 함수의 그래프를 그려서 $y = -k$와의 교점을 분석합니다.
$f'(x) = 6x^2 - 12x = 6x(x - 2)$
$f'(x) = 0$이 되는 $x$의 값은 $x = 0$ 또는 $x = 2$입니다.

각 점에서의 함숫값을 구하면:
- $f(0) = 2(0)^3 - 6(0)^2 = 0$
- $f(2) = 2(8) - 6(4) = 16 - 24 = -8$

함수 $f(x)$의 개형을 살펴보면:
- $x < 0$일 때 $f(x) < 0$
- $x = 0$일 때 극댓값 $0$
- $0 < x < 2$일 때 $f(x)$는 감소
- $x = 2$일 때 극솟값 $-8$
- $x > 2$일 때 $f(x)$는 증가하며 $x \to \infty$일 때 $f(x) \to \infty$

방정식 $f(x) = -k$가 서로 다른 양의 실근을 2개 가지려면, $x > 0$인 범위에서 그래프와 직선 $y = -k$가 두 점에서 만나야 합니다.
1. $x=0$일 때 $f(0)=0$이므로, $x>0$인 범위에서 교점이 생기려면 $-k$의 값은 극솟값보다 커야 합니다.
2. $-8 < -k < 0$인 경우:
   - $x=2$일 때 $f(2)=-8$이므로, $-k = -8$이면 $x=2$에서 중근을 갖고 $x=0$보다 작은 곳에서 다른 근을 가지므로 양의 실근은 1개입니다.

   - 따라서 $-8 < -k < 0$이면 $x>0$인 범위에서 서로 다른 두 양의 실근을 갖습니다.
   - 부등식을 풀면 $0 < k < 8$입니다.
