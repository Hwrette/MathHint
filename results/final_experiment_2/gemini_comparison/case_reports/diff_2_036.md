### 생성 풀이 전체

주어진 방정식 $x^3 - 3x^2 - 9x + k = 0$을 $k$에 대하여 정리하면 다음과 같습니다.
$k = -x^3 + 3x^2 + 9x$

함수 $f(x) = -x^3 + 3x^2 + 9x$의 그래프와 직선 $y = k$가 만나는 점의 개수가 서로 다른 실근의 개수입니다. $f(x)$의 극값을 구하기 위해 미분하면,
$f'(x) = -3x^2 + 6x + 9$
$f'(x) = -3(x^2 - 2x - 3) = -3(x - 3)(x + 1)$

$f'(x) = 0$이 되는 $x$의 값은 $x = -1$ 또는 $x = 3$입니다.
각 지점에서의 함숫값을 구하면,
- $x = -1$일 때: $f(-1) = -(-1)^3 + 3(-1)^2 + 9(-1) = 1 + 3 - 9 = -5$ (극솟값)
- $x = 3$일 때: $f(3) = -(3)^3 + 3(3)^2 + 9(3) = -27 + 27 + 27 = 27$ (극댓값)

방정식 $f(x) = k$가 서로 다른 두 실근을 가지려면, 직선 $y = k$가 함수 $f(x)$의 극댓값 또는 극솟값과 만나야 합니다.
즉, $k = 27$ 또는 $k = -5$일 때 서로 다른 두 실근을 갖게 됩니다.

따라서 구하는 모든 실수 $k$의 값의 합은 $27 + (-5) = 22$입니다.
