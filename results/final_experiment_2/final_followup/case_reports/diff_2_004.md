## 문제 원문

두 이차함수 $f (x)$, $g (x)$가
$\lim_{x \rightarrow \infty} \frac{f \left( x \right)}{g \left( x \right) - x^{2}} = 1$, $\lim_{x \rightarrow 3} \frac{g \left( x \right) - f \left( x \right)}{x - 3} = 8$
을 만족시킬 때, $g (5) - f (5)$의 값을 구하시오.


## 원본 정답·해설

원본 정답: $20$

[정답] $20$

[해설]
두 이차함수 $f (x)$, $g (x)$의 $x^{2}$의 계수를 각각 $a$, $b \quad \left( a \ne 0 , b \ne 0 \right)$이라 하자.
$\lim_{x \rightarrow \infty} \frac{f \left( x \right)}{g \left( x \right) - x^{2}} = 1$이므로
두 다항식 $f (x)$와 $g (x) - x^{2}$의 차수는 $\mathrm{2}$이고
$\frac{a}{b - 1} = 1$, $a = b - 1$, $b - a = 1$이므로 $g \left( x \right) - f \left( x \right)$는 최고차항의 계수가 $\mathrm{1}$인 이차함수이다. $\lim_{x \rightarrow 3} \frac{g (x) - f (x)}{x - 3}$의 값이 존재하므로
다항식 $g \left( x \right) - f \left( x \right)$는 $x - 3$을 인수로 갖는다.
$g(x)-f(x)=(x-3)(x+k)\quad(k$는 실수$)$
$\lim_{x \rightarrow 3} \frac{g \left( x \right) - f \left( x \right)}{x - 3}$$= \lim_{x \rightarrow 3} \frac{\left( x - 3 \right) \left( x + k \right)}{x - 3}$
$= \lim_{x \rightarrow 3} \left( x + k \right) = 3 + k = 8$
$k = 5$이므로 $g \left( x \right) - f \left( x \right) = \left( x - 3 \right) \left( x + 5 \right)$
따라서 $g \left( 5 \right) - f \left( 5 \right) = 20$

두 이차함수 $f(x)$와 $g(x)$에 대하여 주어진 극한 조건을 차례대로 분석합니다.

**1. 첫 번째 조건 분석:**
$\lim_{x \rightarrow \infty} \frac{f(x)}{g(x) - x^2} = 1$
이 극한값이 1로 수렴하므로, $f(x)$와 $g(x) - x^2$은 최고차항의 계수가 같고 차수가 같은 이차식이어야 합니다.
$f(x) = ax^2 + bx + c$라 하면, $g(x) - x^2$도 $ax^2 + \dots$ 꼴이어야 하므로 $g(x) = (a+1)x^2 + dx + e$라고 할 수 있습니다.
극한값이 1이 되려면 $f(x)$와 $g(x) - x^2$의 최고차항 계수가 같아야 하므로, $a = a+1$이 성립해야 하는데 이는 모순입니다.
따라서 $g(x) - x^2$은 $f(x)$와 같은 이차항을 가져야 하므로, $g(x) = x^2 + f(x) + (\text{상수 또는 일차식})$ 형태가 아니라, $g(x) - x^2$이 $f(x)$와 같은 이차식이어야 합니다.
즉, $g(x) = x^2 + f(x) + h(x)$라 할 때, $\lim_{x \rightarrow \infty} \frac{f(x)}{f(x) + h(x)} = 1$이 되려면 $h(x)$는 $f(x)$보다 차수가 낮아야 합니다.
따라서 $g(x) - f(x) = x^2 + h(x)$ (단, $h(x)$는 일차 이하의 다항식)입니다.

**2. 두 번째 조건 분석:**
$\lim_{x \rightarrow 3} \frac{g(x) - f(x)}{x - 3} = 8$
이 식은 $h(x) = g(x) - f(x) - x^2$이라 할 때, $g(x) - f(x) = x^2 + h(x)$이므로
$\lim_{x \rightarrow 3} \frac{x^2 + h(x)}{x - 3} = 8$입니다.
분모가 $x \rightarrow 3$일 때 0으로 가므로, 분자도 $x \rightarrow 3$일 때 0이어야 합니다.
$3^2 + h(3) = 0 \implies h(3) = -9$
$h(x)$는 일차 이하의 다항식이므로 $h(x) = mx + n$이라 하면,
$3m + n = -9 \implies n = -9 - 3m$
$h(x) = mx - 9 - 3m = m(x-3) - 9$
이를 극한식에 대입하면:
$\lim_{x \rightarrow 3} \frac{x^2 + m(x-3) - 9}{x - 3} = \lim_{x \rightarrow 3} \frac{(x-3)(x+3) + m(x-3)}{x - 3} = \lim_{x \rightarrow 3} (x + 3 + m) = 6 + m$
이 값이 8이 되어야 하므로 $6 + m = 8 \implies m = 2$
따라서 $h(x) = 2(x-3) - 9 = 2x - 15$입니다.

**3. 최종 계산:**
$g(x) - f(x) = x^2 + h(x) = x^2 + 2x - 15$
우리가 구하고자 하는 값은 $g(5) - f(5)$이므로, 위 식에 $x=5$를 대입합니다.
$g(5) - f(5) = 5^2 + 2(5) - 15 = 25 + 10 - 15 = 20$
