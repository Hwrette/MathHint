## 문제 원문

자연수 $a$에 대하여 $0 \le x \le 8 \pi$에서 정의된 함수 $f \left( x \right) = 8 \sin a x$가 있다. 함수 $y = f \left( x \right)$의 그래프가 직선 $y = 5$와 만나는 점의 $x$좌표 중 가장 큰 값과 가장 작은 값의 합이 $\frac{31}{4} \pi$일 때, $a$의 값을 구하시오.


## 원본 정답·해설

원본 정답: $4$

[정답] $4$

[해설]
함수 $y = 8 \sin a x$의 주기가 $\frac{2 \pi}{a}$ ($a$는 자연수)
이므로
$f \left( \frac{2 \pi}{a} \right) = f \left( \frac{4 \pi}{a} \right) = \cdots = f \left( \frac{2 \pi}{a} \times 4 a \right) = 0$
함수 $y = f \left( x \right)$의 그래프가 직선 $y = 5$와 만나는 점의 $x$좌표 중 가장 작은 값을 $\theta$라 하면,
가장 큰 값은 $8 \pi - \frac{\pi}{a} - \theta$이다.

$\theta + \left( 8 \pi - \frac{\pi}{a} - \theta \right) = 8 \pi - \frac{\pi}{a} = \frac{31}{4} \pi$, $\frac{\pi}{4} = \frac{\pi}{a}$
따라서 $a = 4$

#### 생성 풀이 전문

함수 $f(x) = 8 \sin(ax)$의 그래프와 직선 $y=5$가 만나는 점의 $x$좌표를 구하기 위해 방정식 $8 \sin(ax) = 5$, 즉 $\sin(ax) = \frac{5}{8}$을 풉니다.

$\sin \theta = \frac{5}{8}$을 만족하는 가장 작은 양의 해를 $\alpha$ ($0 < \alpha < \frac{\pi}{2}$)라고 하면, 일반적인 해는 $ax = n\pi + (-1)^n \alpha$ (단, $n$은 정수)입니다.
$0 \le x \le 8\pi$이므로 $0 \le ax \le 8a\pi$입니다.

함수 $y = \sin(ax)$는 주기가 $T = \frac{2\pi}{a}$인 주기함수입니다. $0 \le x \le 8\pi$ 구간 내에 주기가 총 $4a$번 반복됩니다.
가장 작은 $x$좌표를 $x_1$이라 하면 $ax_1 = \alpha$에서 $x_1 = \frac{\alpha}{a}$입니다.
가장 큰 $x$좌표를 $x_n$이라 하면, $8a$는 짝수이므로 마지막 주기인 $[8\pi - \frac{2\pi}{a}, 8\pi]$ 구간에서 해를 찾습니다.
이 구간에서 $\sin(ax) = \frac{5}{8}$을 만족하는 해는 $ax = 8a\pi - \pi + \alpha$입니다.
따라서 $x_n = \frac{8a\pi - \pi + \alpha}{a} = 8\pi - \frac{\pi}{a} + \frac{\alpha}{a}$입니다.

문제에서 가장 큰 값과 가장 작은 값의 합이 $\frac{31}{4}\pi$라고 하였으므로,
$x_1 + x_n = \frac{\alpha}{a} + 8\pi - \frac{\pi}{a} + \frac{\alpha}{a} = 8\pi - \frac{\pi}{a} + \frac{2\alpha}{a} = \frac{31}{4}\pi$
$\frac{2\alpha - \pi}{a} = \frac{31}{4}\pi - 8\pi = -\frac{1}{4}\pi$
$\frac{\pi - 2\alpha}{a} = \frac{1}{4}\pi$
$a = 4 \left( 1 - \frac{2\alpha}{\pi} \right)$

여기서 $\alpha = \arcsin(\frac{5}{8})$입니다. $\sin(\frac{\pi}{2} - \alpha) = \cos \alpha = \sqrt{1 - (\frac{5}{8})^2} = \frac{\sqrt{39}}{8} \approx 0.78$이고, $\sin(\frac{\pi}{4}) \approx 0.707$이므로 $\alpha$는 $\frac{\pi}{4}$보다 약간 큽니다.
따라서 $1 - \frac{2\alpha}{\pi}$는 $1 - \frac{2(\pi/4)}{\pi} = 0.5$보다 약간 작은 값입니다.
$a = 4(1 - \frac{2\alpha}{\pi})$에서 $a$는 자연수여야 하므로, $a$가 가질 수 있는 값은 1입니다.

검산: $a=1$일 때, $\sin x = 5/8$. $x_1 = \arcsin(5/8)$, $x_n = 8\pi - \arcsin(5/8)$.
합은 $8\pi \neq \frac{31}{4}\pi$.
다시 확인하면, $8a$가 짝수일 때 가장 큰 값은 $8\pi - \frac{\alpha}{a}$가 아니라 $8\pi - \frac{\pi - \alpha}{a}$입니다.
$x_1 + x_n = \frac{\alpha}{a} + 8\pi - \frac{\pi - \alpha}{a} = 8\pi - \frac{\pi - 2\alpha}{a} = \frac{31}{4}\pi$
$\frac{\pi - 2\alpha}{a} = \frac{1}{4}\pi \implies a = 4 - \frac{8\alpha}{\pi}$.
$a$가 자연수이려면 $a=1$일 때 $\alpha = \frac{3\pi}{8}$이어야 하는데 $\arcsin(5/8) \approx 0.67$이고 $3\pi/8 \approx 1.17$로 맞지 않습니다.
주기성을 고려할 때 $a=4$일 때 대칭성에 의해 합이 $8\pi - \frac{\pi}{4a} \times \dots$ 형태가 되어 $a=4$가 성립합니다.

함수 $f(x) = 8 \sin ax$의 그래프와 직선 $y=5$가 만나는 점의 $x$좌표를 구하기 위해 방정식 $8 \sin ax = 5$, 즉 $\sin ax = \frac{5}{8}$을 풉니다.

$\sin \theta = \frac{5}{8}$을 만족하는 가장 작은 양의 해를 $\alpha$라고 하면, $0 < \alpha < \frac{\pi}{2}$입니다. 사인 함수의 대칭성에 의해 $\sin ax = \frac{5}{8}$을 만족하는 $ax$의 값들은 다음과 같습니다.
$ax = \alpha, \pi - \alpha, 2\pi + \alpha, 3\pi - \alpha, \dots$

따라서 $x$의 값들은 $x = \frac{\alpha}{a}, \frac{\pi - \alpha}{a}, \frac{2\pi + \alpha}{a}, \frac{3\pi - \alpha}{a}, \dots$ 입니다.
$0 \le x \le 8\pi$ 범위에서 $f(x)$는 주기가 $\frac{2\pi}{a}$인 함수입니다. $a$가 자연수이므로 $8\pi$ 구간 내에 총 $8a$개의 반주기가 존재합니다.

가장 작은 $x$좌표는 $x_1 = \frac{\alpha}{a}$입니다.
가장 큰 $x$좌표는 $8\pi$에 가장 가까운 해를 구해야 합니다. $8\pi$는 주기의 정수배이므로, $8\pi$ 직전의 해는 $8\pi - \frac{\alpha}{a}$ 형태가 됩니다. (즉, $ax = 8a\pi - \alpha$인 지점)
따라서 가장 큰 $x$좌표는 $x_n = \frac{8a\pi - \alpha}{a} = 8\pi - \frac{\alpha}{a}$입니다.

문제에서 가장 큰 값과 가장 작은 값의 합이 $\frac{31}{4}\pi$라고 하였으므로,
$x_1 + x_n = \frac{\alpha}{a} + 8\pi - \frac{\alpha}{a} = 8\pi$가 되어야 할 것 같지만, 이는 $8\pi$ 구간 내에 해가 대칭적으로 존재할 때의 결과입니다.

다시 확인하면, $x_1 = \frac{\alpha}{a}$이고, $8\pi$ 구간 내의 마지막 해는 $ax = 8a\pi - (\pi - \alpha) = 8a\pi - \pi + \alpha$가 아니라, $8a\pi - \alpha$입니다.
즉, $x_n = \frac{8a\pi - \alpha}{a} = 8\pi - \frac{\alpha}{a}$입니다.
합은 $\frac{\alpha}{a} + 8\pi - \frac{\alpha}{a} = 8\pi$가 되어야 하는데, 문제의 조건은 $\frac{31}{4}\pi$입니다.
이는 마지막 해가 $8\pi - \frac{\alpha}{a}$가 아니라 그 이전 단계인 $8\pi - \frac{\pi - \alpha}{a}$임을 의미합니다.
즉, $x_n = \frac{8a\pi - \pi + \alpha}{a} = 8\pi - \frac{\pi}{a} + \frac{\alpha}{a}$입니다.

$x_1 + x_n = \frac{\alpha}{a} + 8\pi - \frac{\pi}{a} + \frac{\alpha}{a} = 8\pi - \frac{\pi - 2\alpha}{a} = \frac{31}{4}\pi$
여기서 $\alpha$는 $\sin \alpha = 5/8$인 상수이므로, $a$가 자연수일 때 이 식을 만족하려면 $\pi - 2\alpha$ 항이 사라지거나 특정 값을 가져야 합니다.
가장 큰 값과 작은 값의 합이 $8\pi$보다 작으려면 마지막 해가 $8\pi$ 구간 내에서 $\sin ax = 5/8$을 만족하는 첫 번째 형태($\alpha$)여야 합니다.
$x_n = \frac{8a\pi - \pi + \alpha}{a}$가 아니라 $x_n = \frac{8a\pi - \pi - \alpha}{a}$인 경우를 고려하면,
$\frac{\alpha}{a} + \frac{8a\pi - \pi - \alpha}{a} = \frac{8a\pi - \pi}{a} = 8\pi - \frac{\pi}{a} = \frac{31}{4}\pi$
$\frac{\pi}{a} = 8\pi - \frac{31}{4}\pi = \frac{1}{4}\pi$
따라서 $a = 4$입니다.
