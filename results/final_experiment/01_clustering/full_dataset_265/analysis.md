# 전체 265문항 탐색 결과와 직접 관찰

**실험 A(기존 분리)**는 185문항으로 중심과 대표 라벨을 정하고 별도 테스트 80문항을 평가했다. **실험 B(이 폴더)**는 전체 265문항으로 중심과 대표 라벨을 정하고 같은 265문항을 관찰한다. 따라서 B의 점수가 높더라도 새로운 문제에 대한 일반화 성능이 개선됐다는 뜻이 아니다.

## 실험 방법

기존 학습185·테스트80의 문제 BoW 행을 ID에 맞춰 합쳐 265×346 행렬로 사용했다. 새 토큰화·어휘 재학습은 없으며 실제 분류 라벨은 중심 갱신에 넣지 않았다. 고유 계층 경로 수로 k=2·8·25·70을 확인했다. 기존 알고리즘과 동일하게 시드42~46의 5개 실행 중 유클리드는 거리 제곱합, 구면 방식은 1−코사인 합이 최소인 실행을 골랐다. ARI·NMI로 초기화를 선택하지 않았다.

## 해석의 한계

- 현재265개를 한꺼번에 학습·평가한 탐색이다. 기존 테스트80 결과와 동일한 일반화 평가가 아니다.
- ARI와 NMI는 서로 다른 척도다. NMI는 우연 일치를 보정하지 않아 분류 수와 표본 수의 영향을 받을 수 있으므로, 유형 수준의 높은 NMI만으로 군집이 교육과정 유형을 잘 재현했다고 판단하지 않는다.
- 유형70개에 비해 전체265문항으로 유형별 사례 수가 적다. 단일 문항 군집은 높은 순도를 쉽게 보이므로 사례 선정에는 우선3문항 이상인 군집을 사용했다.
- 시드5개는 초기화 변동을 줄이는 장치이며 독립 데이터 반복 실험5회라는 뜻은 아니다. 최적화 목적함수의 값은 서로 다른 거리 간 직접 비교하지 않는다.
- BoW는 토큰 순서·수식 구조를 보존하지 않는다. 빈도와 문항 길이·표기 방식이 실제 교육과정 분류와 다른 군집을 만들 수 있지만 추가 검증 없이 인과를 확정하지 않는다.
