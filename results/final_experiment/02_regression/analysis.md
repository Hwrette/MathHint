# 회귀 모델 검증

기존 학습 185문항·테스트 80문항과 346→431차원 선형층을 유지했다. 최종 실험에서 재학습하지 않고 무결성을 검증한 기존 모델·예측·학습곡선을 재사용했다.

|방법|MSE ↓|MAE ↓|평균 코사인 유사도 ↑|
|---|---:|---:|---:|
|학습 평균 기준선|3.559432|0.484312|0.798630|
|원시 회귀 출력|3.356985|0.622918|0.820015|
|음수→0 보정|3.012478|0.485584|0.847980|

MSE는 큰 오차에 더 민감한 평균제곱오차, MAE는 평균절대오차다. 코사인은 벡터의 방향 유사도이며 퍼센트 정답률이 아니다. 음수 보정은 MSE·코사인을 개선했지만, MAE는 단순 평균 기준선보다 약간 크다. 이 지표만으로 LLM 풀이 개선을 결론낼 수 없다.

## 상위 20개 토큰의 일치

평균 공통 토큰 수는 **14.062개**, 평균 Precision@20은 **0.703125**다.
양의 빈도만 반올림 전 값으로 내림차순 정렬하고, 동률은 학습 어휘 인덱스 오름차순으로 처리한다. 20개 미만이면 양의 토큰 전부를 고르며 0으로 채우지 않는다. Precision@20은 공통 수/20, 추가 열 precision_at_available_k는 공통 수/실제 선택된 예측 토큰 수다. 후자의 분모가 0이면 null이다. 실제 상위 토큰 회수율의 분모는 실제 선택 수이며 0이면 null이다.
실제 양의 토큰이 20개 미만인 문항은 0개, 예측은 0개다.

## 소수점 처리와 자료 확인

실제 빈도는 정수로 보존한다. 원시 예측·음수 보정 예측과 MSE·MAE·코사인 평가는 실수 값을 그대로 사용하며 정수 반올림하지 않는다. Gemini는 양수 상위20개를 먼저 선택한 뒤 소수점 세 자리로 표시한다. 표시 반올림으로 0이 되면 기존 전송 정책상 생략될 수 있으며, 실제 전송 값·토큰 수는 prompt_audit에서 확인한다. 회귀 평가에는 이 표시용 반올림을 적용하지 않는다.

## 실제 토큰으로 보는 예측의 차이

`trig_2_016`은 상위20개 중 18개가 겹친다. 실제·예측 모두 sin, cos, sqrt, theta, frac와 괄호·숫자 등 여러 수식 조각을 포함한다. [실제·예측 빈도 그림](figures/top_tokens_high_cosine_trig_2_016.png)에서 같은 토큰의 빈도 크기는 여전히 다른 것도 확인할 수 있다.

반면 `trig_1_043`은 공통 토큰이 8개다. 실제 상위20개에는 pi가 13회 등장하고 theta·frac·숫자4와8이 포함되지만, 이 토큰들은 예측 상위20개에서 빠졌다. 예측에는 0이 13.236, cos가 9.763로 높게 나타났다. [이 문항의 빈도 비교 그림](figures/top_tokens_low_cosine_trig_1_043.png)으로 대조할 수 있다.

이 사례는 함께 등장하는 기호·표현의 빈도 구성은 일부 예측하지만, 문항별 수식 조각의 구성과 횟수에는 차이가 남는다는 관찰이다. 상위20개에서 빠졌다는 것은 전체 예측 벡터의 값이 0이라는 뜻이 아니다. 높은 빈도·상위토큰 일치와 수학적으로 중요한 풀이 원리의 예측을 같은 의미로 해석하지 않는다.

## 해석과 한계

확인한 사실: 보정 후 코사인은 기준선보다 높지만, 선형회귀의 MAE 개선은 나타나지 않았다. 단어 빈도는 순서와 수식 구조를 보존하지 않는다. 일반적인 연결어·기호의 높은 빈도를 예측하는 것과 문제별 풀이 원리를 예측하는 것은 다르다. 상위토큰 그림에서 차이를 직접 확인해야 한다.
학습 MSE와 테스트 MSE 차이는 일반화의 제한을 보여준다. 185개 학습·80개 테스트의 한 분할만 사용했다. 이전 테스트 결과를 본 뒤 분석을 설계했으므로 전혀 관찰하지 않은 독립 최종 평가라고 주장하지 않는다. 최종 테스트를 사용한 재학습·모델 선택·어휘 추가는 하지 않았다.
